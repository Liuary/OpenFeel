## B3 处置与裁定

### 3.1 `patch-inquirer.js` 真实用途与取舍（**须先读代码**）

- **用途**（`scripts/patch-inquirer.js`）：把 `@inquirer/core` 内 `import { styleText } from 'node:util'` 就地替换为局部等效函数，规避 Node 20 早期版本无 `util.styleText` 的报错。
- **关键事实（本轮核实）**：
  1. `util.styleText` 自 **Node 20.12.0** 起提供；`@inquirer/core@11.2.1` 的 `engines` 为 `>=23.5.0 || ^22.13.0 || ^20.17.0` → **允许的最低版本（20.17.0）已含该 API** → 补丁**在允许区间内无必要**；
  2. 补丁目标路径 `<pkgRoot>/node_modules/@inquirer/core/...`，在用户端依赖提升（扁平化）后位于 `<prefix>/node_modules/@inquirer/core/...` → **路径多一层**，实测「文件不存在，跳过」×2、EXIT 0 → **必然静默失效**；
  3. `patch-inquirer` 全仓引用仅 `package.json:17` 与脚本自身（`rg` 实测）。
- **取舍裁定：删除**（不改为显式 npm script）。理由：
  - ① 补丁在合法 engines 区间内**不再需要**（20.12+ 已有 `styleText`）；
  - ② 「就地改写第三方包」属反模式（升级后被覆盖、pnpm/yarn 不适用、随包发布无效）；
  - ③ 保留为显式脚本仍需文档与维护成本，收益为零 → **删除脚本 + 删除 postinstall**；若未来确需兼容，应改用 `overrides`/`patches`（pnpm/yarn）等生态机制，而非随包 postinstall。
- **对既有用户的影响**：删除 postinstall 后，用户端 `npm install openfeel` 不再执行该（已失效的）补丁 → **无功能回退**（补丁本就静默失败）；若用户在 Node 20.0~20.16，`engines` 收窄后 npm 会**明确告警**（优于「装上了但在交互命令崩溃」）。

### 3.2 `engine-strict` 评估裁定（**不做**）

- `.npmrc` 的 `engine-strict` 是**消费者侧**设置：**发布包内附带的 `.npmrc` 不会被消费者的 npm 采用**（npm 只读消费者自身项目/用户级 `.npmrc`）→ 在包内加 `engine-strict=true` **无法对用户生效**，属无效配置。
- 故**不新增** `.npmrc` / `engines-strict`；依赖 `engines` 声明（npm 默认 `EBADENGINE` 告警）+ `README`/`CHANGELOG` 说明 Node 最低版本。

## B4 处置与兼容性裁定

### 4.1 兼容性评估（**结论：非破坏性，删除而非同步**）

- `package.json` **仅声明** `exports: { ".": "./dist/index.js" }`；**无** `main`、**无** `types` → 无类型声明契约，下游只能拿到运行时 `export {}`（空）+ `VERSION`。
- `VERSION` 值**从未正确**（`0.1.0`；`1.1.1` 已发布版本同样携带）；全仓零引用（`rg VERSION src test bin scripts` 唯一命中该行）；CLI 真实版本来自 `src/cli/index.ts` 的 `require('../../package.json')`，与该导出无关。
- → **删除属修错而非破坏性变更**：无任何文档/类型/内部调用依赖它。
- **版本策略**：**不升主版本**；在 `1.1.2` 的 `CHANGELOG` **Fixed** 记录（非 Breaking）；若审查要求更保守，可在 CHANGELOG 标注「移除一个从未生效的占位导出」（**备选**，见待裁定点）。

### 4.2 精确改动点

#### 1. `src/index.ts:9-10`

- 现状：
  ```ts
  9:
  10: // 版本号标识
  11: export const VERSION = '0.1.0';
  ```
  （文件共 10 行：`:7 export {};`、`:9` 空行、`:10` 注释 + VERSION —— 以实测为准）
- 改后：**删除 VERSION 导出及其注释行**，仅保留：
  ```ts
  /**
   * OpenFeel 包主入口
   * 公共 API 导出点（后续阶段逐步填充）
   */

  // 占位：后续阶段将在此导出核心模块
  export {};
  ```
- **不同步为 1.1.2**：同步会引入一个此前无人使用的**公共 API 承诺**（需长期维护语义），而该文件定位为「占位导出点」。

#### 3. `CHANGELOG.md`（Fixed 条目）

- `- 移除 `src/index.ts` 中从未生效的死导出 `VERSION`（值恒为 `0.1.0`、全仓零引用；`exports["."]` 不再暴露错误版本号；CLI 版本仍取自 `package.json`）`
