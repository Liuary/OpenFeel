## 目标

在现有完整流水线（full）之外，新增**快速迭代（fast）模式**：减负以加快迭代、降低 token 消耗，但**仍以 CLI 为核心**（状态机/骨架/审计链完整保留）。

1. **双模式配置**：新增 `workflow_mode: full | fast`（默认 **fast**）；**作用域阶段级**（每阶段可选不同模式）；**记忆项目级**（用户为项目选过一次后，后续新阶段默认沿用「最后一次选择」）。
2. **快线 phase 链**：full 15 个 phase → fast 跳过 7 项（`plan_review` / `scheme_pending` / `scheme_review` / `scheme_passed` / `test_pending` / `test_failed` / `test_passed`），保留 `plan_pending → plan_passed → exec_running → review_pending → [review_failed ↺] → review_passed → archiving → done`；**保留 reviewer 单轮 + 失败回环重试**（质量底线，不可跳）。
3. **骨架全量铺 + 标记驱动**：`plan.md` / `ops/op-NNN.md` / `deps.yaml` / `status.md` 一律按**全量骨架**落盘（CLI 机械操作，不耗 Agent）；减负**只减 Agent 接力环节**（fast 跳过 schemer/tester 调度、reviewer 单轮、archiver/planner 轻量），靠 `workflow_mode` **标记分流**。
4. **标记双读者**：① CLI / flow-manager 读标记选 phase 转移表；② Agent（Feel 调度 + 各 subagent）读标记自知是否被调度 / 是否轻量化产出。
5. **单阶段切换**：允许单阶段以 `--workflow-mode full` **切回完整链**（覆盖 status.md 生效值）。
6. **部署级默认变更**：**新建项目/新部署默认 `auto_advance: enabled`**（`DEFAULT_CONFIG.auto_advance` 由 `disabled` 改为 `enabled`，**与 workflow_mode 无关**——full 与 fast 均默认开启）。

## 标记载体（三层，复用现有级联链）

```
config.yaml defaults.workflow_mode   ← 项目默认 / "最后一次选择"记忆
status.md「工作流模式」                ← 阶段级生效值（cascade 出口）
flow.json stages.{id}.workflow_mode  ← 可选冗余（不参与级联；读取权威恒为 status.md）
```

优先级：`status.md > config.yaml defaults > profile.yaml > 默认 fast`。

## 关键裁定

| 议题 | 裁定 |
|------|------|
| 模式作用域 | **阶段级**（每阶段可选）+ **项目级记忆**（最后一次选择写入 `config.yaml defaults.workflow_mode`） |
| 默认值 | builtin / 新部署默认 **fast**；本仓自举期显式 **full**（D-BOOT，见大计划 §三） |
| phase 枚举 | **零新增**——fast 链全部使用既有 15 phase 的子集 |
| 快线表 `review_failed` 出口 | `[review_pending, exec_running]`（回环重试含回执行修复） |
| 表选择单一权威 | `FlowManager` 按 stage 的 `workflow_mode` 选表；展示 / 校验 / 推进 / 路径 BFS **同源** |
| `pipeline.yaml` 覆盖 | 保持现状为 **full 表覆盖**；新增可选 `fast_transitions`（缺失 → 内置快线表）；本仓不增 |
| flow.json 冗余字段 | **可选**：写入但不参与级联（避免第二信源） |
| 存量阶段补字段 | 字段缺失 → **插入**（「自动推进」行后）；`stage set --workflow-mode` / `config set --sync-stages` 同口径 |
| 骨架 | **全量铺**，fast 不裁剪任何落盘结构 |
| `auto_advance` 默认 | `disabled` → **`enabled`**（full / fast 均默认开启） |
