1. **REV 闭环无例外**：`--force` 不可绕过 blocking REV 检查（仅降级警告级别），双路兜底（命令层 + FlowManager 层）。

3. **git commit 主辅机制**：Agent prompt 强化为主（executor.md），流水线 CLI 安全网为辅（`git status --porcelain` 警告）。
4. **骨架文件幂等性**：重复推进同一阶段同一 phase 时不重复创建骨架文件。
5. **中英文模板对称原则**：所有 Agent 提示词修改均同步 zh-CN + en + .opencode 三份文件。
