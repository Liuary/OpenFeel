## [HIGH] REV-001: postinstall 脚本不在 files 白名单，发布后安装将失败

- **优先级**：high
- **blocking**：true
- **来源 op**：op-004（npm 发布准备）

### 问题描述

`package.json` 配置 `"postinstall": "node scripts/patch-inquirer.js"`，但 `files` 字段为 `["dist", "bin", "schemas"]`，未包含 `scripts/` 目录。`npm pack --dry-run --json` 实测：产物 192 文件中 scripts 相关 0 个。

### 影响范围

发布到 npm 后，用户执行 `npm install openfeel` 时 npm 在包目录运行 postinstall，因 `scripts/patch-inquirer.js` 不存在于产物中，node 报 ENOENT 退出非 0，**安装中断失败**。属发布阻塞级功能缺陷。

op-004 自测仅核对 files 与产物一致及 dist/bin/schemas 齐全，未校验 postinstall lifecycle 脚本依赖文件是否被打包；`npm pack --dry-run` 不执行 lifecycle 脚本，CI 中 `npm ci` 因 checkout 全仓库能通过——三者共同掩盖缺陷。

### 其他审查结论

- REV-002（medium, non-blocking）：flow.json v1.0.0-stage-04 缺失 name 字段（历史遗留，op-003 自测盲区）
- REV-003（low, non-blocking）：ci.yml 缺少缓存优化与文件头注释

### 处理

流水线应设为 `review_failed`。待 Schemer 制定 postinstall 修正方案、Executor 修复并复审通过后推进。
