# op-004：init 命令双语语言选择

- **阶段**：v4.3-stage-03
- **前置**：op-005（hard — `ensureInfoJson` 需已支持 `lang` 字段持久化）、op-001（soft — `loadTemplate` 已在 template-loader.ts 中实现，REV-002 修复后使用）
- **对应 REV**：REV-002（init.ts AGENTS.md 模板加载联动语言选择）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

在 `openfeel init` 流程中增加中英双语语言选择提示，用户选择后持久化语言配置，并使用 `loadTemplate(lang, 'agents-md')` 生成对应语言的 AGENTS.md。

### 步骤 1：读取现状

- [ ] 1. 读取 `src/core/init.ts`（233 行）和 `src/commands/init.ts` 完整内容，理解当前 init 流程

### 步骤 2：语言选择交互

- [ ] 2. 在 `initProject` 函数中，调用 `ensureInfoJson`（第 92 行附近）之后增加语言选择步骤：
  - **交互模式**（`process.stdout.isTTY`）：
    - 输出中英双语提示：
      ```
      🌐 Select Agent prompt language / 选择 Agent 提示词语言:
        1. English (en)
        2. 中文 (zh-CN) [默认]
      ```
    - 使用 Node.js 内置 `readline` 模块读取用户输入
    - 解析输入：`1`/`en`/`english` → `en`；`2`/`zh`/`chinese` 或直接回车 → `zh-CN`
    - 将选择的语言写入 `.info.json`（更新 `lang` 字段）
  - **非交互模式**（`!process.stdout.isTTY`）：
    - 默认使用 `zh-CN`
    - 输出提示：`非交互环境，Agent 提示词语言默认设置为 zh-CN。使用 openfeel update --lang <zh-CN|en> 可修改。`

### 步骤 3：[FIX] REV-002 — 替换硬编码 AGENTS_MD_TEMPLATE 为 loadTemplate 调用

- [ ] 3a. 修改导入（当前第 19-23 行）：
  ```diff
  - import { DEV_CORE_TEMPLATE, CURRENT_TEMPLATE, AGENTS_MD_TEMPLATE } from './templates.js';
  + import { DEV_CORE_TEMPLATE, CURRENT_TEMPLATE } from './templates.js';
  + import { loadTemplate } from './template-loader.js';
  ```
  注意：`DEV_CORE_TEMPLATE` 和 `CURRENT_TEMPLATE` 不涉及语言切换，保留原导入。

- [ ] 3b. 修改 AGENTS.md 生成逻辑（当前第 122 行）：
  ```diff

  + const agentsMdContent = loadTemplate(selectedLang, 'agents-md');
  + const agentsMdResult = writeTemplateIfMissing(agentsMdPath, agentsMdContent);
  ```
  其中 `selectedLang` 为步骤 2 中确定的语言值（`'zh-CN'` 或 `'en'`）。

- [ ] 3c. 确保 `selectedLang` 变量在 `initProject` 函数作用域内可达第 122 行：

  - 若语言选择在 `initProject` 内部内联完成 → 变量自然可达
