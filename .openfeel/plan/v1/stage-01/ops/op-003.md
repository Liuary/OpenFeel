# op-003：update 收敛 + opencode-config instructions 调整 + state key remap

- **阶段**：v1.1.1-stage-01
- **前置**：op-001（hard——移除 core-instructions 调用点依赖 op-001 已删模板管线）；op-002（hard——`getGlobalAgentsMdPath` 依赖 op-002 新增）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标

`openfeel update` 职责收敛：拆除项目 AGENTS.md 部署逻辑；全局资产部署目标由 core.md 改为全局 AGENTS.md；`opencode-config.ts` 按 op-000 结论调整 `instructions`；存量全局 update_state.json 的 core.md key 迁移到全局 AGENTS.md key。

> 参见 kb/architecture.md #全局部署架构 / #控制区标记增量更新架构；kb/patterns.md #JSONC 深度合并模式 / #全局/项目双 state 路由模式；kb/architecture.md #存量项目迁移架构（remapLegacyKey 思路）。

## 关键设计决策

1. **update 收敛范围（REV-1903 修订）**：update **保留全局资产增量更新**（agent/skill/全局 AGENTS.md/全局 opencode.jsonc），**仅拆项目 AGENTS.md 部署**。存量全局资产无升级通道，故不彻底拆全局部署。

2. **core.md → 全局 AGENTS.md 部署**：update.ts 的「步骤 0 生成 core.md」（L1456-1462）改为：

   ```ts
   // 0. 生成全局框架约束 AGENTS.md（~/.config/opencode/AGENTS.md）
   const agentsMdPath = getGlobalAgentsMdPath();
   const agentsMdContent = loadTemplate(lang, 'agents-md');
   {
     const action = deployGlobalAsset(agentsMdPath, agentsMdContent, newGlobalState);
     pushAction(action, agentsMdPath, created, updated, skipped, appended);
   }
   ```

3. **移除项目 AGENTS.md 部署**：删除 update.ts L1386-1442 的 AGENTS.md 分支块（`agentsDirHasContent`/`agentsMdExists`/四种情况）与 `AgentsMdLangConflictError`（L44-53）及 commands/update.ts 中对应 import/catch。存量项目 AGENTS.md 不再由 update 管理（属用户项目约束，见 §五 兼容策略）。

4. **`buildGlobalOpencodeFrameworkObj` instructions 调整**（按 op-000 结论分支）：
   - **op-000 结论 = 自动加载 YES** → 移除 `instructions` 字段（全局 AGENTS.md 约定自动加载承载约束）：

     ```ts
     export function buildGlobalOpencodeFrameworkObj(): Record<string, unknown> {
       return {
         $schema: 'https://opencode.ai/config.json',
         default_agent: 'feel',
         agent: {
           'openfeel-vision': { model: 'deepseek/deepseek-flash' },
           'openfeel-reviewer': { model: 'zhipuai/glm-5.3-flash' },
         },
       };
     }
     ```

   - **op-000 结论 = 自动加载 NO** → 保留 `instructions: [getGlobalAgentsMdPath()]`（绝对路径，P2 机制）。
   - 无论哪种，**`mergeGlobalOpencodeJsonc` 须移除已废弃的 `getGlobalCoreMdPath()` 引用**（§五 #4）：见决策 5。

5. **`mergeGlobalOpencodeJsonc` 清理废弃 core.md 引用**（L108-112）：

   ```ts
   export function mergeGlobalOpencodeJsonc(raw: string): string {
     const base = parseJsonc(raw);
     const merged = deepMergeJsonc(base, buildGlobalOpencodeFrameworkObj());
     // 移除已废弃的 core.md instructions 引用（v1.1.1：core.md 已并入全局 AGENTS.md）
     if (Array.isArray(merged.instructions)) {
       const stale = getGlobalCoreMdPath();
       merged.instructions = merged.instructions.filter((p) => p !== stale);
       if (merged.instructions.length === 0) delete merged.instructions;
     }
     return JSON.stringify(merged, null, 2) + '\n';
   }
   ```

   （import 增加 `getGlobalCoreMdPath` 已在 opencode-config.ts L6 存在。）

6. **`getIncomingContent` 路由更新**（L1623-1656）：
   - L1627-1630：`getGlobalCoreMdPath()` 判断 → `getGlobalAgentsMdPath()`；返回 `loadTemplate(lang, 'agents-md')`。
   - L1649-1652：删除「项目 AGENTS.md」路由（`relativePath === 'AGENTS.md'`），因项目 AGENTS.md 不再部署。

7. **state key remap（REV-1910 修订，归属 op-003）**：
   - **全局 state 绝对路径 key**（`~/.config/opencode/openfeel/core.md` → `~/.config/opencode/AGENTS.md`）：在 update.ts 加载 globalState 后、部署前执行一次性重映射。
   - **migrate.ts `remapLegacyKey` 目标**：`.opencode/instructions/core.md` 分支（L342-345）由 `getGlobalCoreMdPath()` → `getGlobalAgentsMdPath()`。

### 步骤 3：`src/core/update.ts`——全局 state core.md key 重映射

在 `updateProject` 创建 `newGlobalState`（L1454）之后、步骤 0 部署（L1456）之前插入（REV-2003 修订）：

```ts
  // v1.1.1：存量全局 state 的 core.md key → 全局 AGENTS.md key（一次性重映射）
  // 说明：在 newGlobalState 创建后执行（newGlobalState = globalState ?? createGlobalUpdateState({})；
  // 非 null 时二者同引用，故直接改 globalState 即改 newGlobalState）。
  const staleCoreKey = getGlobalCoreMdPath();
  if (globalState && globalState.files[staleCoreKey] && !globalState.files[getGlobalAgentsMdPath()]) {
    globalState.files[getGlobalAgentsMdPath()] = globalState.files[staleCoreKey];
    delete globalState.files[staleCoreKey];
  }
```

（`globalState` 为 `UpdateState | null`。**REV-2003**：须用显式 `globalState &&` 守卫而非 `globalState?.`，因 TS 严格模式对 optional chaining 的 narrowing 不足，块内 `globalState.files[...]` 会报可能为 null。null 时跳过重映射，`saveGlobalUpdateState(newGlobalState)` 落盘。）

## 风险与注意

- **`getGlobalCoreMdPath` 保留**：op-003 仍需它做「清理废弃 core.md instructions 引用」（opencode-config.ts）与「state remap」（update.ts）；**勿删除**（op-004 migrate 清理旧 core.md 文件后仍作为检测函数引用）。
- **op-000 结论分支**：步骤 5 须严格按 op-000-findings.md 的「自动加载 YES/NO」结论落定 instructions，不得两分支都写。
- **state remap 幂等**：重映射须 `!globalState.files[getGlobalAgentsMdPath()]` 守卫，避免已有新 key 时覆盖。
- **`--force` option 去留**：项目 AGENTS.md 移除后 `--force` 语义弱化；若删除须同步删 i18n 键与 `update.test.ts` 断言，否则 CLI 兼容性问题。本 op 建议**保留 option**（向后兼容），仅移除冲突 catch。
