## 目标

新增 `src/core/i18n.ts`，提供运行时字符串查表函数 `t(key, lang?, vars?)` 和项目级语言解析函数 `getCliLang(projectPath)`。与 `template-loader.ts` 的「运行时按键查表」模式对齐，但更轻量：TS 常量直接导入，零构建脚本。

### 2. 实现字符串映射表导入与聚合

- [ ] 导入 `zh-CN.ts` 和 `en.ts` 中所有域导出
- [ ] 构建两个语言级 `Map<string, string>`：
```typescript
import { common as zhCommon, flow as zhFlow, init as zhInit, /* ... */ } from './i18n-data/zh-CN.js';
import { common as enCommon, flow as enFlow, init as enInit, /* ... */ } from './i18n-data/en.js';

/** 构建 zh-CN 字符串映射表 */
function buildZhMap(): Map<string, string> {
  const map = new Map<string, string>();
  const domains = [
    zhCommon, zhFlow, zhInit, zhUpdate, zhProject,
    zhStage, zhPlan, zhKnowledge, zhArchive, zhRoadmap, zhView, zhInstructions,
  ];
  for (const domain of domains) {
    for (const [_, entry] of Object.entries(domain)) {
      map.set(entry.key, entry.zh);
    }
  }
  return map;
}

/** 构建 en 字符串映射表 */
function buildEnMap(): Map<string, string> {
  const map = new Map<string, string>();
  const domains = [
    enCommon, enFlow, enInit, enUpdate, enProject,
    enStage, enPlan, enKnowledge, enArchive, enRoadmap, enView, enInstructions,
  ];
  for (const domain of domains) {
    for (const [_, entry] of Object.entries(domain)) {
      map.set(entry.key, entry.en);
    }
  }
  return map;
}

/** 语言→字符串映射表（模块级缓存，惰性初始化） */
const stringMaps: Record<string, Map<string, string>> = {};
function getStringMap(lang: string): Map<string, string> {
  if (!stringMaps[lang]) {
    if (lang === 'zh-CN') {
      stringMaps[lang] = buildZhMap();
    } else if (lang === 'en') {
      stringMaps[lang] = buildEnMap();
    } else {
      // 未知语言回退到 zh-CN
      stringMaps[lang] = buildZhMap();
    }
  }
  return stringMaps[lang];
}
```
- [ ] 使用惰性初始化模式（首次调用 `t()` 时才构建 Map），减少启动成本

### 3. 实现 `t()` 函数（核心查表）

- [ ] 函数签名：
```typescript
/**
 * 按语言和键名查表返回本地化字符串。
 * 支持变量插值：值中的 `{varName}` 会被 vars 中的对应值替换。
 *
 * @param key       i18n 键名，如 "flow.status.currentStage"
 * @param lang      语言标识（'zh-CN' | 'en'），默认 'zh-CN'
 * @param vars      变量替换映射表（可选）
 * @returns         本地化后的字符串。缺失时返回 `key` 本身 + 日志警告。
 */
export function t(key: string, lang: string = 'zh-CN', vars?: Record<string, string>): string
```
- [ ] 实现逻辑：
  1. 获取 `lang` 对应的 `Map<string, string>`
  2. 若 `map.has(key)` → 取模板字符串
  3. 若 `vars` 存在 → `template.replace(/\{(\w+)\}/g, (_, name) => vars[name] ?? `{${name}}`)`
  4. 若 `map` 中缺失 key：
     - `console.warn(`[i18n] Missing key: "${key}" for lang="${lang}"`)`
     - 回退到 `zh-CN` Map 再查一次
     - 仍缺失则返回 `key` 本身
- [ ] **语言回退策略**：
  1. 优先使用传入 `lang` 参数查找
  2. 缺失时回退到 `zh-CN`（兜底语言）
  3. 回退后仍缺失 → 返回原始 key 字符串（保证程序不崩溃）

### 4. 实现 `getCliLang()` 函数

- [ ] 函数签名：
```typescript
/**
 * 获取 CLI 输出应使用的语言。
 * 优先级：项目 .info.json lang > 全局 ~/.openfeel/config.json lang > 默认 'zh-CN'
 *
 * @param projectPath 项目根路径
 * @returns 'zh-CN' | 'en'
 */
export function getCliLang(projectPath: string): 'zh-CN' | 'en'
```
- [ ] 实现逻辑（参见 kb/patterns.md #双语 CLI 交互模式）：
  1. **读取全局配置**：调用 `getGlobalConfig()`（来自 op-003），取 `config.lang`
  2. **读取项目配置**：调用 `getLang(projectPath)`（来自 `workspace/identity.ts`），取项目 `.info.json` 的 `lang`
  3. **优先级合并**：项目 lang > 全局 lang > 默认 `'zh-CN'`
  4. **合法性校验**：使用 `VALID_LANGS` 验证，非法值回退 `'zh-CN'`
```typescript
import { getLang } from './workspace/identity.js';
import { getGlobalConfig } from './workspace/identity.js';  // op-003 产出
// 或从 global-config.ts 导入

export function getCliLang(projectPath: string): 'zh-CN' | 'en' {
  const projectLang = getLang(projectPath);
  const globalConfig = getGlobalConfig();
  const globalLang = globalConfig.lang;

  // 项目 .info.json 的 lang 字段优先
  if (projectLang && VALID_LANGS.includes(projectLang)) {
    return projectLang;
  }
  // 全局配置次之
  if (globalLang && VALID_LANGS.includes(globalLang)) {
    return globalLang;
  }
  // 兜底回退
  return 'zh-CN';
}
```
- [ ] **注意**：`getGlobalConfig()` 在 op-003 中实现，暂用内联 stub（返回 `{ lang: 'zh-CN', projects: {} }`）或延迟导入。
