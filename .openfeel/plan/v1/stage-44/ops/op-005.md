## 变更目标

新增/扩展测试断言，锁定权限模型修正：① 9 agent × zh/en 权威源 `permission` 均含 `external_directory`；② zh/en 键集一致；③ `utility` 键与 schema 对齐（依 op-001 结论）；④ `template-loader` 生成段（部署源）与自举实例 `.opencode/agents/*.md` 与权威源一致；⑤ 回归：`feel-tester` 的 `webfetch: "deny"` 未被破坏。

**需求映射**：`docs/phase-5/07-openfeel-permission-issue.md` §四建议 1 的**可验证性**；`plan.md §四 op-004` 验收要点；裁定 O1（保留内联块）/O2（`allow`）。
**测试 API（已核实存在）**：`loadAgentTemplate(lang, id): string`（`template-loader.ts:3559`）、`listAgentIds(lang)`（`:3576`）、`loadOpencodeAgentTemplate(lang, id)`（`:7452`）、`listOpencodeAgentIds(lang)`（`:7494`）；frontmatter 解析用 `splitFrontmatter`（`managed-region.ts`）。

> 参见 kb/patterns.md #i18n 键对称性校验模式（三向比对思路）、#控制区标记模式（生成标记断言）、#原子写模式。

## 关键设计决策

1. **双源断言**：既断言**权威源**（`loadAgentTemplate`）又断言**部署源**（`loadOpencodeAgentTemplate`）——二者为 build 双注入对象，须同时含键（防单侧漏改）。
2. **键集一致性**：对每个 agentId，比较 zh 与 en 的 `permission` 键集合**相等**（顺序无关，`sort()` 后比较）。
3. **值形式容错**：断言「`external_directory` 存在且其值为 `allow` 语义」——兼容单值 `"allow"` 与对象 `{ "*": "allow" }`（依 op-001 结论），实现为「字符串 `allow` **或** 对象的 `* === 'allow'`」。
4. **`utility` 条件断言**：op-001 确认 `write` 无效 → 断言含 `edit`、不含 `write`；否则断言含 `write`（保持现状）。
5. **自举实例断言**：`.opencode/agents/*.md`（9）文本含 `external_directory`，且仍含生成标记（kb 控制区/生成标记模式）。
6. **不新增测试文件**：扩展现有 `test/core/template-loader.test.ts` 与 `test/core/opencode-instance.test.ts`（均实测存在），降低碎片化。

## 精确改动点（文件:行号 → 现状 → 改后）

### 改动 1：`test/core/template-loader.test.ts`（扩展）

- 现状：已有 `listAgentIds` / `loadAgentTemplate` 相关 describe（`:16`、`:56`、`:84`）。
- 改后：新增 `describe('权限模型（stage-44）', ...)`，断言：
  ```ts
  import { loadAgentTemplate, listAgentIds, loadOpencodeAgentTemplate, listOpencodeAgentIds } from '../../src/core/template-loader.js';
  import { splitFrontmatter } from '../../src/core/managed-region.js';

  const LANGS = ['zh-CN', 'en'] as const;
  const isAllow = (v: unknown): boolean =>
    v === 'allow' || (typeof v === 'object' && v !== null && (v as Record<string, unknown>)['*'] === 'allow');
  const permKeys = (lang: string, id: string): string[] => {
    const fm = splitFrontmatter(loadAgentTemplate(lang, id))?.frontmatter ?? {};
    const perm = (fm.permission ?? {}) as Record<string, unknown>;
    return Object.keys(perm).sort();
  };

  it('9 agent × zh/en 权威源 permission 均含 external_directory（allow）', () => {
    for (const lang of LANGS) {
      expect(listAgentIds(lang)).toHaveLength(9);
      for (const id of listAgentIds(lang)) {
        const fm = splitFrontmatter(loadAgentTemplate(lang, id))!.frontmatter;
        const perm = fm.permission as Record<string, unknown>;
        expect(perm, `${lang}/${id}`).toHaveProperty('external_directory');
        expect(isAllow(perm.external_directory), `${lang}/${id} value`).toBe(true);
      }
    }
  });

  it('zh/en permission 键集一致', () => {
    for (const id of listAgentIds('zh-CN')) {
      expect(permKeys('zh-CN', id)).toEqual(permKeys('en', id));
    }
  });

  it('utility 键与 schema 对齐（依 op-001 结论）', () => {
    for (const lang of LANGS) {
      const keys = permKeys(lang, 'openfeel-utility');
      // op-001 确认 write 未识别时：
      expect(keys).toContain('edit');
      expect(keys).not.toContain('write');
      // 未确认时改为：expect(keys).toContain('write');
    }
  });

  it('feel-tester 保留 webfetch deny（回归）', () => {
    for (const lang of LANGS) {
      const fm = splitFrontmatter(loadAgentTemplate(lang, 'openfeel-feel-tester'))!.frontmatter;
      expect((fm.permission as Record<string, unknown>).webfetch).toBe('deny');
    }
  });

  it('部署源 OPENCODE_AGENT_TEMPLATES 与权威源一致（双注入）', () => {
    for (const lang of LANGS) {
      expect(listOpencodeAgentIds(lang).sort()).toEqual(listAgentIds(lang).sort());
      for (const id of listOpencodeAgentIds(lang)) {
        const src = loadAgentTemplate(lang, id);
        const dep = loadOpencodeAgentTemplate(lang, id);
        // 生成段与权威源同源：permission 键集一致 + 含 external_directory
        const srcPerm = (splitFrontmatter(src)!.frontmatter.permission ?? {}) as Record<string, unknown>;
        const depPerm = (splitFrontmatter(dep)!.frontmatter.permission ?? {}) as Record<string, unknown>;
        expect(Object.keys(depPerm).sort(), `${lang}/${id} deploy`).toEqual(Object.keys(srcPerm).sort());
        expect(depPerm).toHaveProperty('external_directory');
      }
    }
  });
  ```
