## 目标

新增 `openfeel setup` 命令（纯全局部署：全局 AGENTS.md + 9 agent + 16 skill + 全局 opencode.jsonc，不建项目 .openfeel/）；`openfeel init` 拆掉全局部署（只做 .openfeel/ 工作区 + 项目 opencode.jsonc）；新增 `openfeel init --workspace-only --non-interactive` 非交互轻量子命令供 feel 空白项目自动搭建。

> 参见 kb/architecture.md #全局部署架构 / #存量项目迁移架构；kb/patterns.md #JSONC 深度合并模式 / #全局/项目双 state 路由模式 / #原子写模式 / #建议性文件锁模式；kb/patterns.md #命名前缀统一与子串陷阱处理。

## 关键设计决策

1. **setup 职责 = 纯全局部署**：复用 stage-39 `deployGlobalAsset`（受管区三态 + hash 兜底，幂等可重跑）+ 全局锁 + 原子写。部署目标：全局 AGENTS.md（`getGlobalAgentsMdPath()`，内容 `loadTemplate(lang, 'agents-md')`）、9 agent、16 skill、全局 opencode.jsonc（`mergeGlobalOpencodeJsonc`）。**不建立项目 .openfeel/**。与 update 共用 `deployGlobalAsset` 语义（plan §四）。

2. **`getGlobalAgentsMdPath()`**（global-paths.ts 末尾追加）：

   ```ts
   /** 全局 AGENTS.md 路径（~/.config/opencode/AGENTS.md；框架约束唯一权威，v1.1.1） */
   export function getGlobalAgentsMdPath(): string {
     return join(getOpencodeGlobalDir(), 'AGENTS.md');
   }
   ```

3. **init 拆分**：`deployOpencode` / `promptOpencodeDeploy` / 步骤 7b（deployOpencode 调用）/ 步骤 8（AGENTS.md 骨架）/ 步骤 10（重启提醒）全部从 `initProject` 移除；项目 opencode.jsonc 部署从 `deployOpencode` 抽出到 `initProject` 直接调 `buildProjectOpencodeJsoncObj()`（REV-1905）。`initProject` 现仅：工作区创建 + 项目 opencode.jsonc + package.json vitest 检测。

4. **workspace-only 子命令**：抽 `initWorkspaceCore(projectPath, lang): {created, updated}`（原 `initProject` 步骤 1~7 的工作区创建部分），`initProject` 与 `initWorkspaceOnly` 共用；`initWorkspaceOnly` 非交互（`--lang` 或默认 zh-CN），不写 opencode.jsonc / AGENTS.md / 不检测 package.json（完成标准：仅创建工作区）。

5. **CLI 面**：
   - `openfeel setup [--lang <lang>]` — 纯全局部署，幂等。
   - `openfeel init [path] [--demo] [--lang <lang>] [--workspace-only] [--non-interactive]` — 新增 `--workspace-only` / `--non-interactive`。

### 步骤 2：新建 `src/core/setup.ts`

```ts
/**
 * setup 命令核心模块（v1.1.1）
 * 纯全局部署：全局 AGENTS.md + 9 agent + 16 skill + 全局 opencode.jsonc。
 * 不建立项目 .openfeel/；复用 deployGlobalAsset（受管区三态，幂等可重跑）。
 */
import { mkdirSync, existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { listAgentIds, loadAgentTemplate, loadTemplate } from './template-loader.js';
import { loadGlobalUpdateState, saveGlobalUpdateState, createGlobalUpdateState, updateFileHash, type UpdateState } from './update-state.js';
import { deployGlobalAsset, SKILL_DEFINITIONS } from './update.js';
import { mergeGlobalOpencodeJsonc } from './opencode-config.js';
import { getGlobalAgentsMdPath, getGlobalAgentsDir, getGlobalSkillsDir, getGlobalOpencodeJsoncPath } from './global-paths.js';
import { atomicWriteFileSync } from './fs/atomic-write.js';
import { withFileLock, globalLockPath } from './fs/file-lock.js';

/** setup 部署结果 */
export interface SetupResult {
  created: string[];
  updated: string[];
  skipped: string[];
  appended: string[];
}

/** 纯全局部署（首次全量，幂等）；不建立项目 .openfeel/ */
export function setupGlobalFramework(lang: 'zh-CN' | 'en' = 'zh-CN'): SetupResult {
  const created: string[] = [];
  const updated: string[] = [];
  const skipped: string[] = [];
  const appended: string[] = [];
  const push = (action: string, path: string) => {
    if (action === 'created') created.push(path);
    else if (action === 'updated') updated.push(path);
    else if (action === 'skipped') skipped.push(path);
    else appended.push(path);
  };

  const globalState: UpdateState = loadGlobalUpdateState() ?? createGlobalUpdateState({});

  // 1. 全局 AGENTS.md（框架约束唯一权威）
  push(deployGlobalAsset(getGlobalAgentsMdPath(), loadTemplate(lang, 'agents-md'), globalState), getGlobalAgentsMdPath());

  // 2. 9 agent → 全局 agents 目录
  const agentsDir = getGlobalAgentsDir();
  mkdirSync(agentsDir, { recursive: true });
  for (const id of listAgentIds(lang)) {
    const p = join(agentsDir, `${id}.md`);
    push(deployGlobalAsset(p, loadAgentTemplate(lang, id), globalState), p);
  }

  // 3. 16 skill → 全局 skills 目录
  const skillsDir = getGlobalSkillsDir();
  mkdirSync(skillsDir, { recursive: true });
  for (const [name, content] of Object.entries(SKILL_DEFINITIONS)) {
    mkdirSync(join(skillsDir, name), { recursive: true });
    const p = join(skillsDir, name, 'SKILL.md');
    push(deployGlobalAsset(p, content, globalState), p);
  }

  // 4. 全局 opencode.jsonc：深度合并（保留用户字段），加全局锁 + 原子写
  const jsoncPath = getGlobalOpencodeJsoncPath();
  const merged = withFileLock(globalLockPath('global-opencode-jsonc'), () => {
    const current = existsSync(jsoncPath) ? readFileSync(jsoncPath, 'utf-8') : '{}\n';
    let out: string;
    try {
      out = mergeGlobalOpencodeJsonc(current);
    } catch (err) {
      console.warn(`[setup] 全局 opencode.jsonc 解析失败，跳过合并保留原文件: ${(err as Error).message}`);
      out = current;
    }
    atomicWriteFileSync(jsoncPath, out);
    return out;
  });
  updateFileHash(globalState, jsoncPath, merged);

  // 5. 写盘全局 state + 记录已部署 hash
  for (const p of [...created, ...updated, ...appended]) {
    if (existsSync(p)) updateFileHash(globalState, p, readFileSync(p, 'utf-8'));
  }
  globalState.last_update = new Date().toISOString();
  saveGlobalUpdateState(globalState);

  return { created, updated, skipped, appended };
}
```

> 说明：setup 与 migrate 的全局部署段（migrate.ts L459-498）语义一致，仅「core.md → 全局 AGENTS.md」。（REV-2004/2005 修订：agent/skill 循环改用与 update/migrate 一致的 `loadAgentTemplate`/`listAgentIds` + `Object.entries(SKILL_DEFINITIONS)`，`SKILL_DEFINITIONS` 从 update.ts 导入；已删除未用的 `getOpenfeelVersion` import。）

### 步骤 3：新建 `src/commands/setup.ts`

```ts
/**
 * setup 命令注册
 * openfeel setup [--lang <lang>] — 纯全局部署（全局 AGENTS.md + agent + skill + opencode.jsonc），不建项目 .openfeel/
 */
import { Command } from 'commander';
import { setupGlobalFramework } from '../core/setup.js';
import { t, getCliLang } from '../core/i18n.js';

export function registerSetupCommand(program: Command): void {
  program
    .command('setup')
    .description('部署全局 OpenFeel 框架配置（全局 AGENTS.md + agent + skill + opencode.jsonc），不建立项目 .openfeel/')
    .option('--lang <lang>', 'Agent 提示词语言（zh-CN 或 en），默认 zh-CN')
    .action((options: { lang?: string }) => {
      const lang = getCliLang(process.cwd());
      const deployLang = (options?.lang === 'en' || options?.lang === 'zh-CN') ? options.lang : 'zh-CN';
      const r = setupGlobalFramework(deployLang);
      if (r.created.length) { console.log(t('setup.created', lang)); for (const f of r.created) console.log(`  + ${f}`); }
      if (r.updated.length) { console.log(t('setup.updated', lang)); for (const f of r.updated) console.log(`  ~ ${f}`); }
      if (r.appended.length) { console.log(t('setup.appended', lang)); for (const f of r.appended) console.log(`  ⚠ ${f}`); }
      console.log(t('setup.complete', lang));
      console.log(lang === 'en' ? 'Restart opencode to load the new global configuration.' : '请重启 opencode 以加载新的全局配置。');
    });
}
```

## 风险与注意

- **`getGlobalAgentsMdPath` 与 `getGlobalCoreMdPath` 并存**：op-002 保留 `getGlobalCoreMdPath`（migrate 兼容检测仍引用，op-004 处理其清理）；勿在本 op 删除 `getGlobalCoreMdPath`。
- **setup 首次部署 base 为空不受影响（REV-2005）**：`mergeGlobalOpencodeJsonc` 首次运行时 `readFileSync(jsoncPath)` 走 `'{}\n'` 兜底，deepMerge 以 `buildGlobalOpencodeFrameworkObj()` 为准，无旧 core.md instructions 可清理，结果正确；过渡期内若已存在含旧 core.md instructions 的全局 opencode.jsonc，setup 二次运行的清理依赖 op-003 将废弃 core.md 过滤逻辑合入 `mergeGlobalOpencodeJsonc`（op-003 决策 5），本 op 不自行处理。
- **init 移除 deployOpencode 后旧测试断裂**：`test/core/init.test.ts` / `test/commands/init.test.ts` 可能断言 deployOpencode/AGENTS.md，须 op-005 同步调整；本 op 仅保证 build 绿。
- **workspace-only 与 initProject 共用 `initWorkspaceCore`**：抽函数时勿遗漏 `writeLang`（语言写入 .info.json）与 dev_core/current/decisions/kb 模板，否则 feel 空白项目缺 dev/kb 骨架。
- **`--non-interactive` 是语义标记**：workspace-only 本身已非交互（不 promptLanguage、不 ensureGlobalConfig 交互），`--non-interactive` 仅显式声明，避免 Commander 无意义 option 告警（可考虑不加该 option，仅 `--workspace-only` 隐含非交互——若 plan 要求显式则保留）。
