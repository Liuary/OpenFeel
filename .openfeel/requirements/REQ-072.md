## 摘要

1.6.4 收口时确认两个问题：① `node scripts/release.mjs --dry-run` 被 guard 按「高风险 node 脚本正文不可判定」class1 拒绝，导致文档里的发布预演命令 agent 无法执行（真实发布参数应继续拒绝）；② 全量 npm test 在负载下出现 flaky（首跑 RPC timeout、migrate.test 的全局 opencode.jsonc 用例偶发失败，单跑全绿）。两者都不影响已发布功能，留到 1.6.5 处理。

## 目标与验收

### 目标

修复两处稳定性/可用性问题：① guard 允许 `node scripts/release.mjs --dry-run` / `--skip-build` 在 `exec_running` 执行（真实 `--publish` 仍拒并留审计）；② 让全量测试在全局配置隔离层稳定，并把 runner 层并发超时如实登记为已知环境问题。

### 验收

- A72.1 guard 对 wrapper 目标为「项目根下 `scripts/release.mjs`」且参数只含 `--dry-run`/`--skip-build`（不含 `--publish`/`--commit-archive`/`--tag`/`--push` 及未知 flag）时按 class 4 warn 放行并审计；TEMP/仓外同名脚本、真实发布参数仍 class 1 拒绝。
- A72.2 新增 ≥5 条 guard 用例（dry-run 放行、skip-build 组合放行、--publish 拒绝、组合语句负向、TEMP 同名拒绝），`dsh/test/guard.js` 全绿（198/198）。
- A72.3 **全局文件零写入隔离**：`migrate.test` / `update.test` 涉及全局配置的用例改为 mock homedir + `HOME`/`USERPROFILE`/`CLAUDE_CONFIG_DIR` 指向临时目录并逐键恢复；afterEach 断言真实用户 4 个全局文件 sha256 前后不变；两个文件单跑与并发运行为绿。
- A72.4 **全量与已知 flaky 的如实取证**：全量 `npm test` 至少 1 次 0 failed（实测 2732 passed）；连续 3 次 0 failed 作为目标，实测 4 次中 3 次因 runner 层 RPC/5000ms 超时（`onTaskUpdate`、`update/setup/templates` 等）失败，根因**未复现**；不得通过放宽超时或禁用并行掩盖；实测数据与结论写入阶段计划 §七 与 `dsh/ADAPTER.md`。
- A72.5 版本 1.6.5（root/dsh lockstep、`requiresCli >=1.6.5`），随本批次一次性发布；不手动 publish。
- A72.6 不改既有 guard 对真实发布/提交的拒绝语义；不改测试断言之外的业务行为。
