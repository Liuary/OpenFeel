## 实施步骤

- [ ] 1. `structure.ts`：拆分 `CORE_DIRS = ['plan','kb','dev','log']` 与 `LAZY_DIRS = ['code_review','bugs','users','tmp','manual','update_conflicts']`；`createWorkspace` 只建 core + dev 子目录（`note`/`current_archive`）；导出 `ensureLazyDir(projectPath, name)`（幂等 mkdir）与 `LAZY_WORKSPACE_DIRS` 常量。
- [ ] 2. 惰性目录的写路径逐点补 `ensureLazyDir`（**只补真正会写且未自建目录的路径**）：逐个 grep `code_review|bugs|users|tmp|manual|update_conflicts` 的写点，确认 `atomicWriteFileSync`/现有 `mkdirSync` 已覆盖者不改（例：`tmp` 由 `backupStatus` 自建、`checkpoints` 由 `saveCheckpoint` 自建、`update_conflicts` 由 update 自建）；仅补真空洞，并在 op 文件「修正记录」登记。
- [ ] 3. `plan stage add` 成功输出追加实际目录：`已创建阶段: <stageId>（目录：.openfeel/plan/<series>/<stageDir>/）`；新增 i18n 键 `plan.stage.createdDirTmpl`（zh/en），`--json` 不涉及。
- [ ] 4. `docs/commands.md` 新增小节「阶段 ID 与 plan 目录映射」：
  - 归一化规则表：`stage-NN` → `v1.0.0-stage-NN`（短名默认系列 v1 / 默认版本 v1.0.0）；`vX-stage-NN` / `vX.Y.Z-stage-NN` 原样；非法值 → 建议名规则；

- [ ] 5. README.zh-CN / README.en 各加 1 段（3~5 行）指向 `docs/commands.md` 的小节（历史节不改）。
- [ ] 6. 测试：

  - 触发一次 `stage add`（用 `tmp` 备份路径）与 `knowledge add`、`flow advance`（checkpoint）→ 无缺目录错误；
  - `plan stage add` 输出含实际目录；
  - `docs/commands.md` 含两张表的关键行（静态断言，防回退）。
