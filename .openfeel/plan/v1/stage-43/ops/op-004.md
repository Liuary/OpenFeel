## 关键裁定

1. **N4 单点隔离**：与 `test/core/setup.test.ts:11-14` / `update.test.ts:10-13` 同构——`vi.mock('node:os')` 使 `homedir()` 返回临时目录（`global-paths.ts` 为唯一 homedir 消费点，一处 mock 隔离全部全局路径）。
2. **禁止「保存/恢复」伪隔离**：删除 `savedConfig` 逻辑——即便内容被 `afterEach` 恢复，mtime 已被改写，且进程中途被强杀会残留测试条目（BUG-004 影响表）。
3. **守护用例只读**：仅用 `vi.importActual('node:os')` 取**真实** homedir，记录真实 `~/.openfeel/config.json` 的 `mtimeMs` + SHA-256，`afterAll` 断言不变；**不写不建**。
4. **455 条死映射**：裁定**不自动清理、不新增 CLI**（操作用户真实环境不可逆、属历史残留、非发布阻塞；根因 `update.test.ts` 缺 mock 已不存在）→ 仅**文档化安全清理步骤**。

### 3. `test/core/workspace/identity.test.ts` 新增「隔离守护」describe（文件末尾）

```ts
describe('隔离守护（BUG-004：本文件不得触碰真实 ~/.openfeel）', () => {
  let realConfigPath = '';
  let beforeMtime = 0;
  let beforeHash = '';

  beforeAll(async () => {
    // 取真实 os 模块（绕过本文件 mock），仅读不写
    const actualOs = await vi.importActual<typeof import('node:os')>('node:os');
    realConfigPath = join(actualOs.homedir(), '.openfeel', 'config.json');
    if (existsSync(realConfigPath)) {
      beforeMtime = statSync(realConfigPath).mtimeMs;
      beforeHash = createHash('sha256').update(readFileSync(realConfigPath)).digest('hex');
    }
  });

  afterAll(() => {
    if (!existsSync(realConfigPath)) { return; }  // 运行前不存在 → 不产生新文件即为通过
    expect(statSync(realConfigPath).mtimeMs).toBe(beforeMtime);   // mtime 未被改写
    expect(createHash('sha256').update(readFileSync(realConfigPath)).digest('hex')).toBe(beforeHash);
  });
});
```
- **局限声明（写入注释）**：守护用例覆盖「**本文件**运行前后」真实文件不变；vitest 多文件并行时其他文件不在本守卫范围（各自 N4 隔离已覆盖）。
