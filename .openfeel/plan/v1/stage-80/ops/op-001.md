## 目标

新增全仓唯一归档版本判定 helper `isArchivedVersionOf`（落 `src/core/plan/path.ts`，纯函数），并在两个 deps 校验点接入**同一判据**：`plan stage add --deps`（`plan.ts:90` 校验块）与 `flow stage set --deps`（`flow.ts:687` 校验块）——**显式版本前缀（全名格式）∧ 版本 ∈ `meta.archived_versions` → 视为已满足**（info 提示、不阻断）；**短名恒走「必须已注册」原路径**（REV-80-001）；负例（未注册且未归档）exit 1 **逐字不变**。

### 步骤 1：helper `isArchivedVersionOf`（`src/core/plan/path.ts`）

- [ ] 1.1 新增导出函数（建议置于 `normalizeStageId`（`:83-86`）之后、`StageIdValidation`（`:88`）之前）。**签名与判据（全仓唯一实现，禁第二套）**：
  - 签名：`export function isArchivedVersionOf(stageId: string, archivedVersions: readonly string[] | undefined): boolean`
  - 判据 1 —— **显式前缀门（探针法复用 `parseStageId`，零自写正则——REV-80-010）**：
    ```ts
    const parsed = parseStageId(stageId);
    // 短名输入经 parseStageId 归一化（fullStageId ≠ 原输入）→ 恒 false
    // （REV-80-001：短名归一产物 v1.0.0-* 属默认版本语义，不得作为「已归档」判据）
    if (!parsed || parsed.fullStageId !== stageId) {
      return false;
    }
    ```
  - 判据 2 —— **版本段派生**（剥离 `-{stageDir}` 后缀；与 `flow-archive/grouping.ts::versionOfStageId` 同源技术——`path.ts` **禁 import `flow-archive/*`**，反向依赖会成环，REV-80-005）：
    ```ts
    const suffix = `-${parsed.stageDir}`;
    if (!parsed.fullStageId.endsWith(suffix)) {
      return false; // 防御：parseStageId 产物恒满足（不可达分支，防未来漂移）
    }
    const version = parsed.fullStageId.slice(0, -suffix.length);
    return Array.isArray(archivedVersions) ? archivedVersions.includes(version) : false;
    ```
  - 中文 JSDoc（职责 / 参数 / 返回值 + 三点理由：短名恒 false〔REV-80-001〕、探针法零自写正则〔REV-80-010〕、与 `versionOfStageId` 同源且禁 import flow-archive〔REV-80-005〕）。
- [ ] 1.2 行为自检（先写测试后实现亦可）：`stage-01` / `stage-99` → false；`v1.0.0-stage-01` ∈ `['v1.0.0']` → true；`v4-stage-04` ∈ `['v4']` → true；`v1.0.0-stage-01` ∉ `['v1.1.7']` → false；**`v1.1.70-stage-01` ∉ `['v1.1.7']`（非前缀子串误伤）** → false；`undefined` / `[]` / `foo` / `v1` / 空串 → false。

  ```ts
  if (deps.length > 0) {
    const fmCheck = new FlowManager(projectPath);
    const fmData = fmCheck.isLoaded() ? fmCheck.getData() : undefined;
    // flow.json 未初始化时 registered 为空 → 任何 deps 均判无效（无阶段可依赖）

    // 已归档依赖（显式版本前缀 ∧ 版本 ∈ archived_versions）→ 视为已满足（info 提示，REV-80-001）；

    );
    const invalid = deps.filter(
      (d) => !known.has(normalizeStageId(d) ?? d) && !isArchivedVersionOf(d, fmData?.meta?.archived_versions),
    );
    if (archivedOk.length > 0) {
      console.log(t('plan.stage.archivedDepsTmpl', lang, { deps: archivedOk.join(', ') }));
    }
    if (invalid.length > 0) {
      // 原负例路径（`:92-96`）逐字不变：列出无效项与已注册阶段后退出码 1（零写盘）

        deps: invalid.join(', '),
        known: registered.length > 0 ? registered.join(', ') : t('common.none', lang),
      }));
      process.exit(1);
    }
  }
  ```
