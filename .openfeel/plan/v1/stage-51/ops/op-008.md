### N10-2（低）索引反映两套布局的共存（**不迁移历史**）

- **文件:行号**：`src/core/public-logger.ts:244-251`（`day_index.md` 生成）+ `:274-281`（根 `index.md` 生成；实测 `:281` 硬编码 `dayRelPath = ${yyyy}/${MM}/${dd}/day_index.md`）
- **现状**：根 `index.md` 生成**只认嵌套布局** → 历史扁平目录（`log/2026-08-07/`）中的日志在索引中**不可检索**。
- **改后**：
  1. **`updateRootIndex` 扩展扫描**（保持既有嵌套条目不变）：
     - 嵌套：`log/{yyyy}/{MM}/{dd}/`（既有路径，`dayRelPath` 不变）；
     - 历史扁平：`log/{yyyy-mm-dd}/`（`readdirSync` 过滤 `^\d{4}-\d{2}-\d{2}$` 的目录）；
     - 对每个扁平目录：若含 `day_index.md` → 以**相对路径**（`2026-08-07/day_index.md`）加入索引；若不含 → 仍以「**历史扁平目录（{date}）**」条目登记（可检索到该日存在日志）。
  2. **布局标注**：索引条目附带布局标记（如 `（嵌套）` / `（历史扁平）`）或按布局分组小节 → **两套布局均可见、可检索**（A7 要求）。
  3. **不迁移、不删除、不改写历史目录**：仅**读**历史目录生成索引。
  4. **`day_index.md`**：既有逻辑（嵌套当日）不变；若历史扁平目录中无 `day_index.md`，**不为历史目录补建**（A7：仅统一未来写入）。
  5. **索引正文说明（归归档官）**：`.openfeel/log/index.md` 与 `day_index.md` 的**「历史扁平目录与嵌套目录共存」说明文字**由归档官维护（本 op 提供要点并登记至 op-009 文档同步清单）；若索引文件由代码生成，则说明文字作为**生成模板的一部分**由本 op 落地（以 `read` 复核生成逻辑后决定归属，二者取其一，**不得重复维护**）。

### N11-1（低）`flow advance` git 警告降噪 + `--quiet`

- **文件:行号**：`src/commands/flow.ts:652-665`（实测 `:653-664` git 脏区警告**无条件**打印 `git status --porcelain` 结果非空时）；`advance` 选项定义 `:499-505`
- **现状**：每次 `advance` 都打印多行框式警告（正常中间态也被警告）→ 噪声。
- **改后**（**A8**）：
  1. `flow advance` 增选项 `--quiet`（`:505` 附近，描述「静默非错误输出」）；
  2. **git 警告打印条件**：`if (!options.quiet && (options.to === 'done' || archived))` → 打印；否则**完全跳过**（含跳过 `execSync('git status …')` 调用，省一次子进程）；
  3. `--quiet` → **完全静默**：不打印成功确认行（`:650` 的 `flow.advance.okTmpl`）与 git 警告；**错误路径仍输出 stderr 且 `exit 1`**（不受影响）；
  4. **不做**「源码变更」路径过滤（A8 明确排除，避免误判）。
- **行为变更**：**是**（默认降噪 + 新静默选项）。
- **兼容影响**：`--to done` 时行为不变（仍提示）；非 done 且未加 `--quiet` 时**警告消失**（期望）；依赖该警告做外部校验的脚本需改用 `git status` 自行判断；`--quiet` 下 stdout 为空（脚本不要依赖成功行）。
