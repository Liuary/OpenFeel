# op-003：实现全局语言配置存储（`~/.openfeel/config.json`）

- **阶段**：v4.4-stage-01
- **前置**：无（可与 op-001、op-002 并行）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

在 `src/core/workspace/identity.ts` 中新增全局配置读写函数，管理用户级 `~/.openfeel/config.json` 文件。提供 `getGlobalConfig()`、`setGlobalConfig()`、`isFirstUse()` 三个函数，与已有项目级 `getLang()` / `ensureInfoJson()` 形成两层配置体系（全局层 + 项目层）。

## 实施步骤

### 1. 定义数据类型

- [ ] 在 `src/core/workspace/identity.ts` 中新增接口定义（放在已有 `InfoJson` 接口下方）：
```typescript
/** 全局配置类型（~/.openfeel/config.json） */
export interface GlobalConfig {
  /** 用户全局默认语言偏好 */
  lang: 'zh-CN' | 'en';
  /** 项目路径→使用语言的 KV 映射（由 openfeel update 自动记录） */
  projects: Record<string, 'zh-CN' | 'en'>;
}

/** 全局配置默认值（首次使用时的初始配置） */
export const DEFAULT_GLOBAL_CONFIG: GlobalConfig = {
  lang: 'zh-CN',
  projects: {} as Record<string, 'zh-CN' | 'en'>,
};
```

### 2. 实现全局配置路径解析

- [ ] 新增 `getGlobalConfigPath()` 内部函数：
```typescript
import { homedir } from 'node:os';
import { join } from 'node:path';

/** 获取全局配置文件路径（~/.openfeel/config.json，跨平台兼容） */
function getGlobalConfigPath(): string {
  return join(homedir(), '.openfeel', 'config.json');
}
```
- [ ] 路径输出示例：
  - Windows: `C:\Users\{name}\.openfeel\config.json`
  - macOS/Linux: `/home/{name}/.openfeel/config.json`

### 3. 实现 `getGlobalConfig()` — 读取全局配置

- [ ] 函数签名：
```typescript
/**
 * 读取全局配置文件（~/.openfeel/config.json）。
 * 文件不存在时返回默认配置（DEFAULT_GLOBAL_CONFIG），不创建文件。
 * JSON 解析失败时返回默认配置并 console.warn。
 */
export function getGlobalConfig(): GlobalConfig
```
- [ ] 实现逻辑：
  1. 构造路径 `getGlobalConfigPath()`
  2. `existsSync` 检查文件是否存在
  3. 存在 → `readFileSync` 读取 + `JSON.parse` → 合并默认值（用展开运算符保证缺失字段兜底）
  4. 不存在 → 返回 `DEFAULT_GLOBAL_CONFIG`（深拷贝）
  5. `JSON.parse` 异常 → `console.warn('[i18n] 全局配置 JSON 解析失败，使用默认值')` → 返回默认值
- [ ] **向后兼容**：对 `config.json` 中的 `lang` 字段做合法性校验，非法值回退 `'zh-CN'`

### 4. 实现 `setGlobalConfig()` — 写入全局配置

- [ ] 函数签名：
```typescript
/**
 * 写入全局配置文件（~/.openfeel/config.json）。
 * 自动创建父目录（~/.openfeel/）。
 * 写入失败时 throw Error。
 */
export function setGlobalConfig(config: GlobalConfig): void
```
- [ ] 实现逻辑：
  1. 构造路径 `getGlobalConfigPath()`
  2. `mkdirSync(dirname(path), { recursive: true })` 确保目录存在
  3. `writeFileSync(path, JSON.stringify(config, null, 2) + '\n', 'utf-8')`
  4. 若写入失败 → `throw new Error('无法写入全局配置: ' + err.message)`
- [ ] **原子性**：如需保证原子性，先写入 `.tmp` 文件再 rename（可选，非必须）

### 5. 实现 `isFirstUse()` — 首次使用检测

- [ ] 函数签名：
```typescript
/**
 * 检测是否为首次使用 OpenFeel（全局配置文件不存在）。
 * @returns true 表示首次使用，需要语言选择提示
 */
export function isFirstUse(): boolean
```
- [ ] 实现逻辑：
  1. 构造路径 `getGlobalConfigPath()`
  2. `return !existsSync(path)`
- [ ] **注意**：仅检查文件存在性，不读取内容（性能敏感）
