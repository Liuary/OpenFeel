### 4. 按功能域分类与键名分配

#### 命名规范

- **格式**：`{domain}.{module}.{name}`（全部小写，层级用 `.` 分隔）
- **domain**：9 大功能域 —— `common`、`flow`、`init`、`update`、`project`、`stage`、`plan`、`knowledge`、`archive`、`roadmap`、`view`、`instructions`
- **module**：子模块名，如 `flow` 域下的 `status`、`overview`、`advance`、`wizard` 等
- **name**：语义化名称，如 `title`、`errorNoInit`、`selectStage` 等
- **动态字符串**：含变量插值的字符串，key 末尾加 `Tmpl` 后缀区分（如 `flow.advance.okTmpl`），值中使用 `{varName}` 占位符

#### 功能域层次结构

- [ ] **`common`**：跨命令共享字符串（如 `common.error` → "错误" / "Error"、`common.cancel` → "取消" / "Cancel"）
- [ ] **`flow`**：flow 命令组所有输出（status/overview/current/metrics/advance/attempt/log/review/retry/repair/migrate/health/recover/wizard）
  - submodules: `status`、`overview`、`current`、`advance`、`attempt`、`log`、`review`、`retry`、`repair`、`migrate`、`health`、`recover`、`wizard`
- [ ] **`init`**：init 命令输出
- [ ] **`update`**：update 命令输出
- [ ] **`project`**：project overview 命令输出
- [ ] **`stage`**：stage 命令组输出（status/set/task）
- [ ] **`plan`**：plan 命令组输出（stage/scheme）
- [ ] **`knowledge`**：knowledge 命令组输出（list/add/search/index）
- [ ] **`archive`**：archive 命令输出
- [ ] **`roadmap`**：roadmap 命令组输出（create/show）
- [ ] **`view`**：view 命令组输出（list/add/accept）
- [ ] **`instructions`**：instructions 命令输出
