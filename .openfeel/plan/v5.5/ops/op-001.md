# op-001: 修复 v5 验证发现的两个 high 缺陷（AGENTS.md 部署传播 + autoCommitOnDone 时序）

## 目标

修复 v5 验证遗留的 2 个 high 缺陷：

1. **AGENTS.md 部署不传播**：`updateProject` 判断语言相同时直接跳过 AGENTS.md（`src/core/update.ts` L1387-1390），不比较内容。导致模板已更新（补齐 4 节）但用户运行 `openfeel update` 时部署不传播。
2. **autoCommitOnDone 时序错误**：`advanceStagePhase` 内部执行 git commit 时（`src/core/flow-manager.ts` L1030），flow.json 尚未 save（save 在命令层 `src/commands/flow.ts` L462），导致 commit 不含本次 phase 变更，每次 done 后必然脏区。

## 实施步骤

- [x] 步骤1：修改 `src/core/update.ts` —— 情况 2 语言相同分支（L1387-1390）与情况 3 无 --lang 分支（L1391-1393），从"直接跳过"改为"读取目标 AGENTS.md 与 `loadTemplate(lang, 'agents-md')` 模板内容对比，内容不同则覆盖部署（updated），相同则跳过（skipped）"
- [x] 步骤2：修改 `src/core/flow-manager.ts` —— 从 `advanceStagePhase` 的 done 分支（L1027-1031）移除 `autoCommitOnDone` 调用，改为返回"是否触发 done 归档"标记；将 `autoCommitOnDone` 改为 public 方法
- [x] 步骤3：修改 `src/commands/flow.ts` —— 两处调用点（L456/L462 命令层与 L1099/L1100 wizard）：`advanceStagePhase` 返回归档标记后，`mgr.save()` **之后**再执行 `mgr.autoCommitOnDone(stage)`
- [x] 步骤4：更新 `test/core/update.test.ts` —— 新增用例：语言相同但模板已更新（内容不同）时应覆盖部署 AGENTS.md；无 --lang 时内容不同也覆盖；内容一致时跳过
- [x] 步骤5：更新 `test/core/flow-manager.test.ts` —— 新增用例：`advanceStagePhase` 推进到 done 返回归档标记 true；非 done 返回 false；已是 done 再推进返回 false
