### 4. `.github/workflows/ci.yml`（版本一致性 + `lint i18n`，**两 job 各一处**）

- **`build-and-test`**：在 `- run: npm run build`（`:18`）之后、`npm test`（`:19`）之前插入：
  ```yaml
        - name: Version consistency guard
          run: |
            CLI_VERSION=$(node bin/openfeel.js --version)
            PKG_VERSION=$(node -p "require('./package.json').version")
            echo "CLI=$CLI_VERSION package.json=$PKG_VERSION"
            if [ "$CLI_VERSION" != "$PKG_VERSION" ]; then
              echo "::error::版本不一致：CLI=$CLI_VERSION package.json=$PKG_VERSION"; exit 1
            fi
        - run: node bin/openfeel.js lint i18n
  ```
- **`publish`**：在 `- run: npm run build`（`:45-46`，带 `if: steps.version.outputs.changed == 'true'`）之后、`- run: npm publish`（`:47`）之前插入**同款**版本断言（**保留同一 `if:` 条件**）：
  ```yaml
        - name: Version consistency guard
          if: steps.version.outputs.changed == 'true'
          run: |
            CLI_VERSION=$(node bin/openfeel.js --version)
            PKG_VERSION=$(node -p "require('./package.json').version")
            if [ "$CLI_VERSION" != "$PKG_VERSION" ]; then echo "::error::版本不一致 CLI=$CLI_VERSION pkg=$PKG_VERSION"; exit 1; fi
  ```
- **本地可验证性**：YAML 语法自检 + 断言脚本本地可跑（`node bin/openfeel.js --version` 与 `package.json` 同源）；GH Actions 行为**推送 PR 后由 CI 实测**（交接说明）。

### 5. H9 结论记录（**不做**）

- `bin/openfeel.js` **不新增**「全局旧版告警」：理由（R5）——① 每次启动做全局探测 = 额外 IO + 跨平台/权限不确定性（`AppData`/`~/.npm`/pnpm/yarn 路径各异）；② 告警易误报（多版本管理器/容器）；③ 主要风险已由**文档口径统一（H7）+ CI 版本门禁（H8）**覆盖。记录于本 op 产出 + plan R5。
