## 回滚/风险
- **回滚**：T9 与 T10 分两次提交（`dsh/lib/index.js` 与 `prompt.js` 归 T10），可单独 revert；工具数三处断言必须与工具定义**同批**回滚，否则 contract/integration 会红。
- **风险（R4 `post-execute` 不可用）**：以 spike 先行为准，降级 1 已确认存在；不可用时 A10 只保留「体积 + `nextAction`」两项，并在 §5.3 与 §10 记录（§9.2 回写规则 3）。
- **风险（副本分叉复发）**：只改 `prompt.js` 不改四份副本会重演分叉 → parity 测试为硬判据。
- **风险（guard 名单结构写错）**：名单是 `{match,segments,hint}` 而非 `{path,kind}`，写错会静默失效 → `dsh/test/guard.js` 的 deny 用例兜底。
- **风险（计数不同批）**：`contract.js:126-128` / `verify.js:232-234` / `integration.js:25-39/:229` 三处任一漏改即红。
- **风险（提示预算误算）**：1200 是含 Free Mode 附录的渲染后总数（余量 80 而非 200），只测 enabled 态会漏判 → 两态各测。
- **风险（越界写 R1）**：`feel_*` 走全局安装的 CLI，改源码不生效会让 A7/A9 取证失真 → 在 T13 显式记录所用路径并按需 `npm run build` + `npm i -g .`。
