# op-001：修复 v5.8 部署验证发现的三项缺陷

- **阶段**：exec_running
- **最多重试**：3

## 目标

修复 v5.8 部署验证发现的三项缺陷：
1. （HIGH）`autoCommitOnDone` 失效：`mapPhaseToStageStatus` 将某些 phase 映射为 `done`（如 `test_passed`），导致 `autoRepairInconsistency` 截断 test_passed→archiving 正常推进路径。
2. （MEDIUM）AGENTS.md 模板缺"版本管理"节：agents-md 模板未同步 v5.6 新增的"版本管理"节。
3. （MEDIUM）init 不创建 `manual/` 目录：`WORKSPACE_DIRS` 缺少 `.openfeel/manual/`。

## 实施步骤

- [ ] 步骤1：创建 op-001.md 方案文件（本文件）
- [ ] 步骤2：阅读 `src/core/flow-manager.ts`，定位 `mapPhaseToStageStatus` 与 `autoRepairInconsistency` 实现
- [ ] 步骤3：修复缺陷 1 —— 使 status=done 成为 phase=done 的专属状态，test_passed/archiving 返回中间状态（testing/archiving），确保 test_passed→archiving→done 路径畅通
- [ ] 步骤4：对比项目根 `AGENTS.md` 的"版本管理"节，追加到 `src/core/templates-data/agents-md/zh-CN.md` 与 `en.md`（英文翻译）
