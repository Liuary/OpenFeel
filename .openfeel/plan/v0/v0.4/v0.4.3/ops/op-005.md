# op-005：语言配置存储 — `ensureInfoJson` 增加 `lang` 字段 + 回退逻辑

- **阶段**：v4.3-stage-03
- **前置**：无
- **负责 Agent**：Executor
- **最多重试**：2

## 目标

修改 `src/core/workspace/identity.ts` 的 `ensureInfoJson` 函数，增加 `lang` 字段支持（`zh-CN` | `en`，默认 `zh-CN`），并实现回退逻辑：读取 `.info.json` → `lang` 字段不存在或为空 → 默认 `zh-CN` → 补充写入。

## 实施步骤

- [ ] 1. 读取 `src/core/workspace/identity.ts` 完整内容，理解当前逻辑
  - 当前：`ensureInfoJson` 仅检查文件存在性，不存在则创建 `{ user: ... }`
  - 问题：已有 `.info.json` 不会更新 `lang` 字段

- [ ] 2. 修改 `ensureInfoJson` 函数：
  - 若 `.info.json` 不存在 → 创建 `{ user: userName, lang: 'zh-CN' }`
  - 若 `.info.json` 存在 → 读取内容 → 检查 `lang` 字段：
    - `lang` 不存在或为空 → 写入默认值 `zh-CN` → 返回（**补充写入**）
    - `lang` 已存在且有效 → 保留原值不变（**向后兼容**）
  - 注意：不覆盖已有的 `user` 值

- [ ] 3. 新增工具函数 `getLang(projectPath: string): 'zh-CN' | 'en'`：
  - 读取 `.openfeel/.info.json` 中的 `lang` 字段
  - 若 `lang` 不存在或值不是 `zh-CN` 或 `en` → 返回 `'zh-CN'`（**回退逻辑**）
  - 不在此函数中补充写入（读写分离，补充写入仅在 `ensureInfoJson` 中）
  - 导出供其他模块（init.ts、update.ts）使用

- [ ] 4. 更新 TypeScript 类型（可选但推荐）：
  - 在 `identity.ts` 中或新建 `types.ts` 定义 `InfoJson` 接口：`{ user: string; lang: 'zh-CN' | 'en' }`
  - 注意：项目原无集中类型文件，可在 identity.ts 内部定义
