### 2. `.github/workflows/ci.yml`（环境守卫，遗留 #12）

- 现状：`build-and-test` job（`:6-19`）steps = checkout / setup-node / `npm ci`（`:17`）/ `npm run build`（`:18`）/ `npm test`（`:19`）。
- 改后：在 `npm test` **前后**各加一步快照比对（R2：目录不存在→不存在视为通过）。
  ```yaml
        - name: Env snapshot (before test)
          run: |
            snapshot() {
              for d in "$HOME/.openfeel" "$HOME/.config/opencode" "$HOME/.config/openfeel"; do
                key=$(echo "$d" | tr '/' '_')
                if [ -e "$d" ]; then
                  find "$d" -type f -print0 2>/dev/null | sort -z | xargs -0 sha256sum 2>/dev/null | sort > "$RUNNER_TEMP/snap_before_$key"
                else
                  echo "ABSENT" > "$RUNNER_TEMP/snap_before_$key"
                fi
              done
            }
            snapshot
        - run: npm test -- --reporter=verbose
        - name: Env guard (after test — must be unchanged)
          run: |
            fail=0
            for d in "$HOME/.openfeel" "$HOME/.config/opencode" "$HOME/.config/openfeel"; do
              key=$(echo "$d" | tr '/' '_') ; f="$RUNNER_TEMP/snap_after_$key"
              if [ -e "$d" ]; then
                find "$d" -type f -print0 2>/dev/null | sort -z | xargs -0 sha256sum 2>/dev/null | sort > "$f"
              else
                echo "ABSENT" > "$f"
              fi
              if ! diff -u "$RUNNER_TEMP/snap_before_$key" "$f" >/dev/null; then
                echo "::error::环境被测试改动：$d"; diff -u "$RUNNER_TEMP/snap_before_$key" "$f" || true; fail=1
              fi
            done
            exit $fail
  ```
- **本地可验证性结论**：GH Actions 无法本地实跑；采用 ① `node -e "require('yaml').parse(require('fs').readFileSync('.github/workflows/ci.yml','utf8'))"` **语法自检**；② 将守卫脚本抽为 `.openfeel/tmp/env-guard.sh` 用 bash 本地跑一遍（仅校验脚本语法与逻辑，不模拟 runner）；③ **推送到 PR 后由 CI 实测**（交接说明）。
