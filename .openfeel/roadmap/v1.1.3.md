## 目标

1. **修正回归**：`resolveTargetEncoding` 第⑤步在 `win32 && !isTTY` 时不再按 `chcp` 映射为 GBK，改为直接返回 `utf8`，对齐 Node 默认与 UTF-8 管道/CI 消费者。
2. **显式逃生阀**：GBK 仅经 `--encoding gbk` 或 `OPENFEEL_ENCODING=gbk` 生效；`--json` 恒 UTF-8 与 5 步优先序不变。
3. **清理死代码**：删除随第⑤步失效的 `chcp` 探测与代码页映射实现。
4. **版本收口**：`1.1.2` → `1.1.3`，全链路载体同步。
