## 四、步骤 ③ — 备份 `~/.config/opencode/`（仓库外）

```powershell
$globalDir = Join-Path $env:USERPROFILE ".config\opencode"
$backupDir = Join-Path $env:TEMP "opencode\stage56-global-backup"
$manifest  = Join-Path $env:TEMP "opencode\stage56-global-backup.sha256"

if (Test-Path $backupDir) { Remove-Item -Recurse -Force $backupDir }
Copy-Item -Recurse -Force $globalDir $backupDir
# SHA256 清单
Get-ChildItem -Recurse -File $backupDir | Get-FileHash -Algorithm SHA256 |
  ForEach-Object { "$($_.Hash)  $($_.Path)" } | Set-Content -Encoding UTF8 $manifest
```

- **判据**：`Test-Path $backupDir` = **True** 且 `(Get-ChildItem -Recurse -File $backupDir).Count` > 0（对照 stage-55 约 3689 文件）。
- **失败即停**：备份未成 → **不得进入步骤 ④**。
- **可选**：如需省时可排除 `node_modules`，但**须记录**排除项。

### ⑤-主判据 — skill 正文逐行比对（**权威源正文 vs 全局受管区正文**）

- **「权威源正文」定义** = `SKILL.md` 去 YAML frontmatter（首个 `---` … 第二个 `---`）后全文；
- **「全局受管区正文」定义** = 全局副本 `<!-- openfeel:begin -->` 与 `<!-- openfeel:end -->` 之间内容；
- **归一化** = CRLF→LF 统一 + 剥离 markers + 去首尾空行；
- **期望** = 输出 **`CONTENT-EQUAL`**。
