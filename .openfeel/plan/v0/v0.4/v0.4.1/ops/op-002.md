# op-002：构建产物一致性校验

- **阶段**：v4.1-stage-01
- **前置**：op-001（hard — 必须有注入锚点和生成逻辑后方可校验）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

在 build.js 末尾（`npm run build` 的 TypeScript 编译成功之后）增加校验步骤：自动对比三类模板注入值与源文件内容，不一致时 `exit(1)` 并输出具体差异，确保 CI 环境下可自动捕获模板同步断链。

## 知识库参考

- kb/patterns.md #CLI 原子管理模式
- kb/troubleshooting.md #Agent prompt CLI 命令引用应预先验证存在性 — 校验逻辑应实测验证

## 实施步骤

- [x] **步骤 1**：read 本方案文件完整内容
- [x] **步骤 2**：在 `build.js` 末尾（`npx tsc` 编译成功后）增加校验函数 `validateTemplates()`，校验三类模板：
  - `validateCoreInstruction()`：读取 `templates.ts` 中 Base64 值 → 解码 → 对比 `.opencode/instructions/core.md` 源文件
  - `validateAgentDefinitions()`：读取 `update.ts` 中 AGENT_DEFINITIONS 内容 → 逐条目对比 `.opencode/agents/*.md` 源文件
  - `validateSkillDefinitions()`：读取 `update.ts` 中 SKILL_DEFINITIONS 内容 → 逐条目对比 `.opencode/skills/*/SKILL.md` 源文件
- [x] **步骤 3**：`validateCoreInstruction()` — 逻辑：
  1. 读取 `src/core/templates.ts`，用正则从注入锚点之间提取 Base64 字符串
  2. `Buffer.from(b64, 'base64').toString('utf-8')` 解码
  3. 读取 `.opencode/instructions/core.md` 源文件
  4. 逐字符对比（或逐行对比，忽略行尾 CRLF/LF 差异）：不一致时输出前 5 处差异位置和内容
  5. 不一致 → `console.error(...)` + `process.exit(1)`
- [x] **步骤 4**：`validateAgentDefinitions()` — 逻辑：
  1. 读取 `src/core/update.ts`，提取 AGENT_DEFINITIONS 锚点间内容
  2. 遍历 `.opencode/agents/*.md`，逐个对比内容（需与生成时相同的转义处理后再比对）
  3. 检查：
     - 源文件数量与模板条目数量一致
     - 每个条目内容（经相同转义后）与源文件内容一致
     - 不存在多余的模板条目（源文件已删除但模板残留）
  4. 任一检查不通过 → 输出差异文件名和差异摘要 → `exit(1)`
- [x] **步骤 5**：`validateSkillDefinitions()` — 逻辑：
  1. 读取 `src/core/update.ts`，提取 SKILL_DEFINITIONS 锚点间内容
  2. 遍历 `.opencode/skills/*/SKILL.md`，逐个对比
  3. 同样检查数量一致性、内容一致性、无残留条目
- [x] **步骤 6**：输出校验通过摘要（绿色 ✓ 标记），格式：
  ```
  ✓ 模板一致性校验通过 (3/3)
    ✓ core.md (Base64) — 一致
    ✓ Agent 定义 (7 个) — 一致
    ✓ Skill 定义 (8 个) — 一致
  ```
- [x] **步骤 7**：运行 `node build.js` 验证校验可正常通过（源文件与模板一致时）
- [x] **步骤 8**：手动修改 templates.ts 中 Base64 值（模拟不一致场景），再次 `node build.js`，确认校验捕获差异并 exit(1)
- [x] **步骤 9**：运行 `npm run build` 完整构建 + 校验通过
- [x] **步骤 10**：运行 `npm test` 确保测试通过
