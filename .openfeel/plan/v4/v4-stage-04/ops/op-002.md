# op-002：Agent 性能指标模块

- **阶段**：v4-stage-04
- **前置**：无（批次内独立 op）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

新增 `src/core/metrics.ts` 模块，记录每个 Agent 的执行时间、成功率、重试次数，为流水线性能分析提供数据基础。

## 实施步骤

- [ ] 步骤1：`read` 本方案文件完整内容
- [ ] 步骤2：新建 `src/core/metrics.ts`，实现以下结构：
  - `AgentMetrics` 接口：`{ agentName, totalRuns, successfulRuns, failedRuns, totalRetries, totalDurationMs, avgDurationMs }`
  - `MetricsStore` 类（单例），内嵌 `Map<string, AgentMetrics>`
  - `recordRun(agentName, durationMs, result, retries)` 方法 → 更新累计数据
  - `getAgentMetrics(agentName?)` → 返回单个或全部 Agent 指标
  - `summary()` → 人类可读的性能摘要字符串
- [ ] 步骤3：数据持久化到 `.openfeel/metrics.json`（与 flow.json 同级），提供 `load()` / `save()` 方法
- [ ] 步骤4：在 `src/commands/flow.ts` 中新增 `flow metrics` 子命令，调用 `MetricsStore.summary()` 展示性能数据
- [ ] 步骤5：确保新模块通过 TypeScript 编译，无未使用变量
