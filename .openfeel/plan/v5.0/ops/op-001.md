# op-001：全局 profile 数据结构 + 读写方法
- **阶段**：v5.0
- **前置**：无
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

在 `src/core/config.ts` 中定义全局用户画像 `Profile` 的 Zod Schema、TypeScript 类型，并实现 `readProfile()` / `writeProfile()` 读写方法，路径为 `~/.config/openfeel/profile.yaml`。

## 背景

v5.0 建立框架级两层记忆体系：全局画像（跨项目共享偏好）+ 项目记忆卡片（dev_last.md）。本 op 实现第一层：全局 profile 的数据结构与持久化。参见 `.openfeel/plan/v5.0/plan.md`，kb/patterns.md #YAML Document API 增量修改模式。

## 实施步骤

### 步骤 1：定义 Profile Zod Schema

在 `src/core/config.ts` 中（`ConfigSchema` 之后、工具函数之前）新增以下 Schema 和类型：

- [ ] 1.1 新增 `ProfileUserSchema`：`{ name: z.string().optional(), lang: z.enum(['zh-CN', 'en']).optional() }`
- [ ] 1.2 新增 `ProfilePreferencesSchema`：`{ auto_advance: z.enum(['enabled','disabled']), review_mode: z.enum(['full','skip_small_changes']), communication: z.enum(['concise','detailed']), confirm_threshold: z.enum(['low','medium','high']) }`，全部 optional
- [ ] 1.3 新增 `ProfileHistorySchema`：`{ last_project: z.string().optional(), recent_projects: z.array(z.string()).optional() }`
- [ ] 1.4 新增 `ProfileSchema`：组合 `{ user, preferences, history }`，全部 optional，`.passthrough()` 允许扩展
- [ ] 1.5 新增 TypeScript 类型导出：`Profile`、`UserProfile`、`Preferences`、`History`（基于 Zod inferred 类型）

### 步骤 2：实现 readProfile()

- [ ] 2.1 新增 `getProfilePath()` 内部函数：使用 `join(homedir(), '.config', 'openfeel', 'profile.yaml')` 构造路径
- [ ] 2.2 实现 `readProfile()`：若文件不存在则返回默认 Profile（空用户名、zh-CN、disabled、full、concise、medium、空数组）。若存在则用 `yaml.parse()` 解析 + `ProfileSchema.parse()` 校验，返回带默认值的完整 Profile
- [ ] 2.3 默认 Profile 常量 `DEFAULT_PROFILE`：所有字段使用安全默认值，遵循 kb/patterns.md #向后兼容的可选配置字段模式

### 步骤 3：实现 writeProfile()

- [ ] 3.1 实现 `writeProfile(profile: Profile)`：先确保父目录存在（`mkdirSync(dirname(path), { recursive: true })`），再将 Profile 序列化为 YAML 写入
- [ ] 3.2 序列化方式：使用 `yaml.stringify()` 将 Profile 对象转为 YAML 字符串（保留块结构可读性），参考 kb/patterns.md #YAML Document API 增量修改模式（本次使用 `stringify` 因 profile 不存在注解保留需求——首次写入无需保留结构）
- [ ] 3.3 添加 JSDoc 中文注释说明各方法用途、参数和返回值

### 步骤 4：更新导出

- [ ] 4.1 在 `src/core/config.ts` 末尾确保 `readProfile`、`writeProfile`、Profile 相关类型已通过 `export` 对外暴露
- [ ] 4.2 确认 `src/index.ts` 或合适的 barrel 文件已重新导出新增方法（若无自动重导出，需手动补充）
