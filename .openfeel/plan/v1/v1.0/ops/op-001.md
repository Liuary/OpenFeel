## 背景分析

- **引用性质**：L577 位于「新增 Agent 全链路更新清单模式」清单表格（序号 2 行），描述"新增 Agent 时应创建 `.opencode/agents/new-agent.md` 部署定义"。该路径是**文档模板示例**（说明未来创建动作），并非真实文件引用，也非已废弃条目——不应标记 `[-]` 或删除，应保留文档语义。
