# v1.6.3 发布说明

- **来源阶段**：v1.6.3-stage-136
- **需求**：REQ-070

## 变更摘要

- **opencode agent 模板去 `model`（A70.1）**：`templates-data/opencode/agents/{zh-CN,en}/openfeel-{executor,explorer,reviewer,utility,vision}.md` 删除 frontmatter `model: deepseek/deepseek-flash`（10 份）；注入副本（`template-loader.ts`）与部署副本同步零 `^model:`，用户 global / project 设置不再被框架默认遮蔽。
- **框架不再注入 agent 模型（A70.2）**：`buildGlobalOpencodeFrameworkObj()` 只剩 `$schema` / `default_agent`，不再向用户 `opencode.jsonc` 补 `openfeel-vision` / `openfeel-reviewer` 的 `{ model }`；用户既有 `agent.*.model` 由 `deepMergeJsonc` / `mergeAgentDefaults` 原样透传。
- **`openfeel model` 两层语义（A70.3）**：`set --scope default` 明确拒绝（`model.set.defaultRemoved`，exit 1，提示改用 global / project）；`get --scope default` 返回 `model:null,source:null`；生效链 `project > global > 平台默认`；`byScope.default` 键与 `inconsistent` 字段保留以稳住 JSON 契约。
- **skills 去预设（A70.4）**：`openfeel-model-check` / `openfeel-model-config` / `openfeel-agent-model-check` / `openfeel-cli-usage` 不再把 deepseek 系列当默认 / 主力 / 异种；`openfeel-cli-usage` 正文改两层叙述（frontmatter 定长 2766 零改动）。
- **模板正文去厂商名（A70.7）**：`agents-md` ×2 与 `claude/constraint` ×2 的视觉行改「多模态模型（由平台提供）」/「Multimodal model (platform-provided)」；8 处 agent 正文「（如 DeepSeek V4 Pro）」→「（例如你选择的模型）」/`(e.g., the model you choose)`。
- **DSH 适配器（A70.5）**：`feel_model` 的 `scope` 枚举去掉 `default`，description / 示例改两层；`dsh/docs/compat/commands.md` 同步；`dsh/ADAPTER.md` `requiresCli` → `≥1.6.3` + 新增 `## v1.6.3` 小节。
- **文档与版本**：README×2 / `docs/commands.md` / `docs/json-contract.md` / `docs/VERSIONS.md` 的三层级误述改为两层链；两包 lockstep 1.6.3、`requiresCli >=1.6.3`。

## 语义

OpenFeel **不指定 Agent 模型**：模型由平台 / 会话选择，或由用户按需用 `openfeel model --scope global|project` 配置；框架不再在模板 frontmatter、`opencode.jsonc` 注入或约束层文案里写死任何厂商模型。

## 升级与验证

- **升级**：`npm i -g openfeel@v1.6.3`（本地开发：`npm run build` 后用 `node bin/openfeel.js`）
- **验证**：`npx tsc --noEmit` → `npm test` → `npm run build`（两遍幂等）→ `cd dsh && node test/contract.js && node test/verify.js && node test/guard.js && node test/integration.js` → `node bin/openfeel.js lint i18n` → `node scripts/release.mjs --dry-run --skip-build`

## 发布流程

- 发布走 CI 自动发布（唯一标准路径）：push 到 master 且 `package.json` 版本与 npm 已发版本不同 → CI 的 publish job 自动 `npm publish`（`openfeel` + `openfeel-dsh`）；不需要手动 `npm publish`，也不必打 tag。
- 版本号 lockstep：`package.json` / `dsh/package.json` = 1.6.3、`openfeel.requiresCli` = `>=1.6.3`。
