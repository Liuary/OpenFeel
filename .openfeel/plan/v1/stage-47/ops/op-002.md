## 精确改动点（文件:行号 → 现状 → 改后）

### 1. `src/core/archive/merge.ts:85`（唯一读取点）

- 现状（`:85`）：`` `- **依赖阶段**：${stage.deps.length > 0 ? stage.deps.join(', ') : '无'}` ``
- 改后：
  ```ts
  `- **依赖阶段**：${Array.isArray(stage.deps) && stage.deps.length > 0 ? stage.deps.join(', ') : '无'}`
  ```
- **裁定**：**最小修复**（仅此读取点加守卫）；**不做**加载路径全量归一化（会改变写回内容，范围更大，留观察）。实测该处为 `deps` 的**唯一读取点**（`rg -n "deps.length\|依赖阶段" src/core/archive/`）。

### 2. `src/core/flow-manager.ts:339`（`save()` 入口守卫）

- 现状：`this.data.meta.updated = new Date().toISOString();`（`:339`，位于 `save()` 内；缺 `meta` 的存量 flow.json 在此抛 TypeError）
- 改后：在 `:339` **之前**插入（与 `defaultFlowData`(`:250`) 字段一致）：
  ```ts
  // 存量 flow.json 可能缺 meta（REV-41 REV-008）：就地补齐，避免 save() 抛 TypeError
  this.data.meta ??= { version: '1.0', project: '', updated: '', revision: 0 };
  this.data.meta.updated = new Date().toISOString();
  ```
- **注意**：`??=` 仅补**整体缺失**；不覆盖既有 `meta` 字段。
