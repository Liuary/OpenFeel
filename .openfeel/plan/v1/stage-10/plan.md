# v1.5.22-stage-10 计划：openfeel-dsh 页面以 OpenFeel 为主

## 背景
用户指出：`openfeel-dsh` 只是 OpenFeel 的 DSH 适配，页面应主要介绍 OpenFeel 本身，并说明「这是 OpenFeel 在 DeepSeek Harness 上的适配版本」；适配细节放后面，前面讲用途。

## 步骤
1. `dsh/README.md` 开头改成：
   - OpenFeel 是什么（记录本 + 工作流程）；
   - 它解决的两个问题；
   - 两个体系（版本与阶段 / 待办清单）；
   - 两种模式（自由 / 流程）；
   - 记录在哪；
   - 然后一句「本页面是 OpenFeel 在 DeepSeek Harness 上的适配版本」，说明装它之后 DSH 里的 AI 能读到这些记录并按流程走。
2. 安装章节精简为「装上之后怎么用」，技术章节（工具面 / 命令面 / 系统提示 / 门禁 / 验证 / 目录）保留在后面作为「适配细节」，明确标注"给需要深入的人"。
3. 版本 1.5.22 收口（若用户确认发布），更新 market 索引。
4. 验证后请用户确认是否发布 1.5.22（npm 页面才会更新）。

## 验收
- [ ] 页面开头不再先讲适配器机制，而是 OpenFeel 的用途
- [ ] 明确「这是 OpenFeel 的 DSH 适配版本」
- [ ] 安装与细节在后，且不打断阅读
