# op 调度三问题复盘

> 时间：2026-07-02 | 阶段：v4-stage-01 批次 1 执行后

## 问题 1：Executor 没读方案文件

**现象**：6 个 Executor 收到 prompt（内含方案内容 + 部署参考路径），看到部署参考路径后直接复制整个文件，跳过了方案中的所有逐步骤要求。

**根因**：Feel 调度时将方案内容直接嵌入 prompt，Executor 走了"捷径"。op-009 改为只给路径时立即暴露（File not found）。

**改进**：
- [ ] Executor prompt 增加："第一条操作必须读取方案文件完整内容"
- [ ] Executor 增加："逐 checkbox 执行，逐条标记"

## 问题 2：op 文件名与调度路径断链

**现象**：Schemer 产出 `op-001_删除9个旧Agent.md`，Feel 拼接 `op-001.md`，找不到文件。

**根因**：Schemer 命名约定（带中文标题）与 deps.yaml key（仅编号）不一致，缺少映射文件。

**改进**：
- [ ] Schemer 规范：文件名用 `op-NNN.md`，中文标题写入内部 `#` 行
- [ ] deps.yaml 增加 `file` 字段声明实际文件名
- [ ] Feel 调度前 glob 校验文件存在性

## 问题 3：status.md checkbox 无人同步

**现象**：批次 1 全部执行成功，status.md 中 checkbox 仍为 `[ ]`。

**根因**：`update-stage-status` 技能只管阶段级元数据（状态/责任 Agent），不管任务级 checkbox。

**改进**：
- [ ] Feel 确认 Executor 成功后，自动同步对应 checkbox 为 `[x]`
