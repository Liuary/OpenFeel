## 精确改动点（新增文件 + build 重生成）

### 1. **新建** `src/core/templates-data/opencode/skills/openfeel-cli-usage/SKILL.md`

- **格式**：与既有 skill 一致（frontmatter 两字段 + `# 标题` + `## 节`）。参考 `openfeel-wizard/SKILL.md:1-12`：
  ```md
  ---
  name: openfeel-cli-usage
  description: OpenFeel CLI 命令用法参考：命令清单与关键参数、15 个 phase 枚举与转移表、stageId 命名与目录映射约定、本版本新增能力（flow phases、flow stage remove、plan stage add --deps、config effective、部署备份）。当需要查询 CLI 命令/参数/phase/阶段命名时加载。
  ---
  ```
  - **触发词（必须含）**：`CLI 命令`、`参数`、`phase`、`stageId`、`命名`（供自动发现）。
- **正文（建议大纲，内容取自实测 CLI 现状）**：
  1. `## 说明`：定位 = **查询型参考手册（只读，不自执行）**；与 `openfeel-wizard`（执行型交互向导）**边界**互引。**增总声明（REV-005③）**：
     `> 本文档为 v1.1.2 快照；命令/参数细节以 \`openfeel <cmd> --help\` 实时输出为准（CLI 演进后本文档可能滞后）。`
  2. `## 命令速查`：按命令组列 `flow` / `plan` / `stage` / `config` / `setup` / `init` / `update` / `migrate` / `model` / `lint` 的用途与关键参数；**重点标注本版本新增**：
     - `openfeel flow phases [--json]`（`--json` 含 `{ phases, transitions, advanceAccepted }`）
     - `openfeel flow stage remove <stageId> [--force] [--dry-run] [--purge]`（安全校验：ops 非空 / 当前活跃 / 被 deps 引用；`--purge` 于 `save()` 成功后删目录）
     - `openfeel plan stage add <name> [--deps <ids...>]`（完整入口，推荐）
     - `openfeel config effective [key]`（有效值 + 来源：`status.md > config.yaml > profile.yaml > builtin`）
  3. `## phase 枚举与转移表`：15 个 phase（`plan_pending` … `done`）+ 转移表（`from → [to…]`，组合 key 含 `|`）；注明「以运行时 `.openfeel/pipeline.yaml` 为准，`openfeel flow phases` 查看」。
  4. `## stageId 命名与目录映射`：三格式（`stage-NN` / `vX-stage-NN` / `vX.Y.Z-stage-NN`）、`series = v{MAJOR}`、目录 `.openfeel/plan/{series}/stage-{NN}/`、唯一性与 `(series, stageDir)` 冲突检测/建议名；**引用** `.openfeel/manual/core/plan-path.md`。
  5. `## 典型场景`：落地阶段（`plan stage add` + `flow advance`）、声明依赖（`--deps`）、纠错移除（`flow stage remove`）、查询有效配置（`config effective`）、部署前备份与 `update_infos.md` 的「备份」类提示（stage-46）。
  6. `## 权限模型要点`：agent 级 `permission` 覆盖顶层；`external_directory` 默认 `allow`；收紧走项目 `opencode.jsonc`（详 `.openfeel/manual/core/permission.md`）。
  7. `## 与 openfeel-wizard 的区别`：本 skill = 查手册；wizard = 跑向导（`openfeel flow wizard`）。
- **长度**：与既有 skill 同量级（避免过度膨胀；详版指向 `manual/**` 与 `docs/commands.md`）。
