# 查阅知识库

## 输入

无（自动按当前任务上下文推断阅读范围）

## 执行步骤

### 1. 读取总索引

读取 `.ai/kb/index.md`，获取所有分类文件的摘要和最近更新时间。

### 2. 匹配相关分类

根据当前任务特征，确定需要查阅的分类：

| 任务特征 | 优先查阅 |
|----------|----------|
| 新功能开发、架构变更 | `architecture.md` |
| 代码编写、重构 | `patterns.md` |
| 编译/运行报错 | `troubleshooting.md` |
| 环境搭建、依赖变更 | `setup.md` |
| 跨领域任务或不熟悉模块 | 全部 `index.md` 摘要 |

### 3. 提取相关条目

读取匹配的分类文件，提取与当前任务相关的 `[+]` 条目。不加载标记为 `[-]` 的已禁用条目。

### 4. 输出摘要

按以下格式输出：

```
📁 知识库查阅结果（{分类}）

[index.md 中的分类摘要]

相关条目：
- [architecture] "登录流程使用 OAuth2..." — 与当前任务相关：是
- [troubleshooting] "Module not found 时运行 npm ci" — 与当前任务相关：否
```

若无相关条目，输出：`知识库中暂无与当前任务相关的记录。`

### 5. 语义检索回退

当精确匹配未找到任何相关条目（无 `[+]` 条目或所有条目与当前任务无关）时：

1. **自动触发**：加载 `skills/search-kb/SKILL.md` 技能，以当前任务描述作为查询文本执行语义检索
2. **查询构建**：从当前任务上下文中提取关键词和需求描述作为 `query` 参数
3. **执行检索**：运行 `python scripts/search_kb.py "<query>" --top-k 10` 获取语义匹配结果
4. **输出结果**：按 `search-kb` 技能的输出格式展示语义检索结果，附加以下回退说明：

```
💡 精确匹配未找到相关条目，已自动回退到语义检索。

📎 语义检索结果（共 {N} 条）
...
```

5. **索引缺失处理**：若 `.ai/tmp/vectors/index.json` 不存在，输出：
```
💡 精确匹配未找到相关条目，语义检索的向量索引尚未构建。

   运行以下命令构建索引后再重试：
   pip install sentence-transformers
   python scripts/build_kb_index.py
```

6. **索引过期提示**：语义检索返回结果后，建议检查索引是否过期：
```
💡 如需确保索引为最新，可运行: python scripts/build_kb_index.py --dry-run
```
