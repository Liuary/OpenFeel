## 心得建议

1. **版本号重映射的边界判定**：plan/v5/ 系列目录名（v5.0~v5.11）作为"系列子目录"保留原名是合理的——它们是系列内组织单位，非版本号引用；而 flow.json stageId、索引文本、plan.md 标题则需 v0 化。Executor 在偏差记录 8 中准确区分了"目录名"与"版本号引用"，判定清晰。
2. **git 重命名检测的交叉匹配假象**：当多个源目录内容高度相似（如空模板 overview.md/status.md），git 会将同一目录的不同文件归到不同目标目录。审查时需以实际文件内容（标题/时间戳）为准，不能轻信 git diff 的重命名标注。
3. **kb 条目与规则升级的同步时点**：规则升级（如版本号语义）发生在 exec 阶段，但 kb 更新在归档阶段。两者存在时间差，审查时需识别"待归档同步"的 kb 条目，避免误判为执行缺陷。
