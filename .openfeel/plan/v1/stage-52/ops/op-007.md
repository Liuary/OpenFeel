## 一、变更目标

落实遗留 L5：将**硬编码中文 `console.warn`** 迁移到 i18n（命令层）或以「无语言前缀稳定标记 + 英文」处理（无 `lang` 上下文的 core 站点），消除 `lang=en` 模式下的中文泄漏，同时**不改变 warn 语义**（何时告警、告警内容）。

---

## 二、L5 子项清单（实测命中位点）

### L5-1（低/中）命令层 warn i18n 化（**有 `lang` 上下文 → 走 `t()`**）

- **文件:行号**（实测命中）：
  | # | 位置 | 现状（代码路径） |
  |:--:|------|------|
  | 1 | `src/commands/flow.ts:673` | Git 脏区警告（多行框式） |
  | 2 | `src/commands/flow.ts:727-729` | advance 相关警告（3 行） |
- **改后**：新增 i18n 键（zh/en 对称），改为 `console.warn(t('<key>', lang, { … }))`；`lang` 取命令层既有 `getCliLang(process.cwd())`（各 action 已具备）。
- **注意**：Git 警告的**多行框式**外观应保留（拆为多个键或单键内嵌换行）；**文案内容与触发条件不变**。

### L5-2（低/中）core 层 warn 处理（**无 `lang` 上下文 → 判定后分流**）

- **文件:行号**（实测命中）：
  | # | 位置 | 备注 |
  |:--:|------|------|
  | 1 | `src/core/flow-manager.ts:605` | `FlowManager` 持有 `this.projectPath` → **可取 lang** |
  | 2 | `src/core/flow-manager.ts:1469` | 同上 |
  | 3 | `src/core/flow-manager.ts:1478` | 同上 |
  | 4 | `src/core/flow-manager.ts:1500` | 同上 |
  | 5 | `src/core/flow-manager.ts:2164` | 同上（autoFix 相关） |
  | 6 | `src/core/config.ts:287` | 函数多数有 `projectPath` 参数 → **可取 lang** |
  | 7 | `src/core/config.ts:320` | 同上 |
  | 8 | `src/core/update-infos.ts:165` | 判定是否具备 projectPath/路径上下文 |
  | 9 | `src/core/workspace/identity.ts:161` | 同上 |
  | 10 | `src/core/flow-manager.ts` 其余同类（以 `rg` 复核补全） | — |
  | 11 | `src/commands/flow.ts` 其余同类（以 `rg` 复核补全） | — |

- **改后（分流规则，写死；避免改多处签名）**：
  1. **具备项目路径上下文者**（如 `FlowManager` 内部的 `this.projectPath`；或函数参数含 `projectPath`）→ 复用 `src/core/i18n.ts` 的 `t()` + `getCliLang(projectPath)`：
     ```ts
     console.warn(t('<key>', getCliLang(this.projectPath), { … }));
     ```
     **不新增** i18n 之外的新机制（core 侧 `i18n.ts` 已可 import）。
  2. **确无路径/lang 上下文者** → 改为**稳定前缀 + 英文短句**：`console.warn('[WARN] …')`，**移除中文**（消除 en 泄漏；标记 `[WARN]` 保证可 grep），并在该处补中文注释说明「无 lang 上下文，使用英文中性文案；如需本地化请注入 projectPath」。
  3. **一律不改变**：告警触发条件、告警数量、是否阻断流程。
- **复核要求**：先 `rg` 全量列出候选（不止上表），**逐处落实**；op-010 门禁以 `rg` 断言「目标位点无硬编码中文」。

### L5-3（低）i18n 键与对称性

- 命令层键（示例，最终键名以既有 `flow.*`/`config.*` 命名风格为准）：`flow.advance.gitDirtyWarn*`（框式行）、`flow.advance.warnTmpl`×N；
- core 层若走 `t()`：键名前缀与所属模块一致（如 `flow.manager.warn*`、`config.warn*`）；
- `zh-CN.ts` 与 `en.ts` **同键同序**；`lint i18n` problems = 0（**R1：退出码非 0 即失败**）。
