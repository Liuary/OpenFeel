# op-006：update 命令新增 `--lang` 参数

- **阶段**：v4.3-stage-03
- **前置**：op-001 (hard — 英文 Agent 模板就绪)、op-002 (hard — 英文 AGENTS.md + core-instructions 模板就绪，合并后覆盖原 op-002+op-003)、op-005 (hard — `getLang` 可读取 .info.json 的 lang 字段)
- **对应 REV**：REV-005（update.ts 中 B64 直解→loadTemplate 替换点行号标注）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

修改 `openfeel update` 命令，增加 `--lang <zh-CN|en>` 参数。未指定时读取 `.openfeel/.info.json` 的 `lang` 字段（通过 op-005 的 `getLang` 回退逻辑保证总能获得有效值）。update 流程根据语言选择调用模板加载器加载对应模板目录。

## 实施步骤

- [ ] 1. 读取以下文件完整内容：
  - `src/commands/update.ts`（命令注册层）
  - `src/core/update.ts`（核心逻辑层）
  - `src/core/workspace/identity.ts`（`getLang` 函数）

- [ ] 2. 修改 `src/commands/update.ts`：
  - 在 Commander command 定义中增加 `.option('--lang <lang>', 'Agent prompt language (zh-CN or en)')`
  - 在 action 回调中解析 `options.lang`：
    - 若指定了 `--lang` → 校验值为 `zh-CN` 或 `en`，非法则报错退出
    - 若未指定 → 调用 `getLang(targetPath)` 获取持久化的语言配置
  - 将最终确定的 `lang` 值传递给 `updateProject()`

- [ ] 3. [FIX] **REV-005** — 修改 `src/core/update.ts`，精确标注替换点：
  - **3a. 导入变更**：
    - 移除 `CORE_INSTRUCTIONS_TEMPLATE_B64` 导入（如存在）
    - 新增 `import { loadTemplate } from './template-loader.js'`（如尚未导入）
    - 新增 `import { getLang } from './workspace/identity.js'`（如尚未导入）
  - **3b. 第 1246 行 `const lang = 'zh-CN'`**：
    - 替换为从函数参数获取 lang 值：`const lang = langParam`（`langParam` 来自 `updateProject` 签名）
  - **3c. 第 1242 行 `Buffer.from(CORE_INSTRUCTIONS_TEMPLATE_B64, 'base64').toString('utf-8')`**：
    - 替换为：`loadTemplate(lang, 'core-instructions')`
    - 说明：op-001 的 REV-013 已在 `loadTemplate` 内部处理 B64→UTF-8 解码，此处无需手动解码
  - **3d. Agent 部署环节**：通过 `loadAgentTemplate(lang, agentId)` 按语言加载模板
  - **3e. AGENTS.md 部署环节**：通过 `loadTemplate(lang, 'agents-md')` 加载对应语言模板
  - **3f. 确保 Skill 定义语言不受影响**（Skill 文件仅存一份，不按语言区分）
  - **3g. 确保部署文件名保持一致**（如始终部署为 `feel.md`，不因语言而变文件名）

- [ ] 4. `updateProject` 函数签名增加 `lang: 'zh-CN' | 'en'` 参数：
  - 在 Agent 部署、AGENTS.md 部署、core instructions 部署三个环节使用该参数
  - 检查所有调用方（目前仅 `commands/update.ts`），确保全部传入 lang 参数
