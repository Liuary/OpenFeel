## 目标

- **做什么**：删除 opencode 适配器 10 份 agent 模板 frontmatter 的 `model:` 默认（executor / explorer / reviewer / utility / vision × 双语）、删除 `opencode-config.ts` 的框架默认注入（vision / reviewer 的 `{ model }`）、把 `openfeel model` 的 `default` 层语义改为「已移除」（`get --scope default` 返回 unset；`set --scope default` 明确拒绝并提示 global / project），解析优先级改为 **project > global > 平台默认**；并把 4 个 skill 里「deepseek 是默认/主力/异种」的表述改为「不预设，按需配置 / 平台选择」；**再把残留厂商名清掉（A70.7）**：`agents-md` / `claude/constraint` 的 vision 行「多模态模型 (deepseek-flash)」→「多模态模型（由平台提供）」，opencode agent 正文 8 处「（如 DeepSeek V4 Pro）」→「（例如你选择的模型）」。
- **为什么**：模型由用户平台/会话选择（DSH 选 deepseek-flash、Claude 选 sonnet）。框架模板写死 `model` 会在部署时把框架默认值变成 opencode 的解析最高层（frontmatter 覆盖 jsonc），实际遮蔽用户自己的 global/project 设置，与「用户选什么就用什么」冲突；约束层与 agent 正文点名具体厂商模型，则把「默认」从配置面搬到了文案面。
- **事实锚点（实测 2026-11-25）**：10 份模板带 `model: deepseek/deepseek-flash`（均在 frontmatter 第 4 行）；`opencode-config.ts:15-26` 注入两处；default 层实现 `model-config.ts:191-329`（读 frontmatter + 读 opencode-config.ts），生效链 `:392-409` 为 `default > project > global`；基线 `model get --scope default --json` → `deepseek-flash`/`source:default`；`templates-data/agents-md/{zh-CN:103,en:103}` 与 `claude/constraint/{zh-CN:105,en:105}` 写「多模态模型 (deepseek-flash)」；opencode agent 正文 8 处「（如 DeepSeek V4 Pro）」；注入副本由 `build.js` 生成（`template-loader.ts` 6 锚点 + `update.ts` `SKILL_DEFINITIONS`，自带三重一致性校验），`templates-migration.test.ts:50` 逐字节锁源。版本现状 1.6.2 lockstep → 目标 1.6.3。
