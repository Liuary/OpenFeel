# 2026-08-08 Liuary-001 公共日志

## Vision Agent 模型配置排查与修复

- **时间**：2026-08-08
- **操作人**：Feel（总统领）
- **类型**：环境配置修复

### 问题现象

调度 Vision Agent 时报错：`Model not found: Alibaba(China)/qwen3.7-plus`

### 排查过程

| 步骤 | 操作 | 发现 |
|------|------|------|
| 1 | 读取 `opencode.jsonc` | provider 配置 `"id": "Alibaba(China)"` 覆盖了内置 key，vision 模型为 `qwen3.7-plus`（纯文本模型） |
| 2 | 查阅 OpenCode 官方文档 | 模型引用格式为 `provider_id/model_id`，内置 provider key 为 `alibaba` |
| 3 | 查阅 Models.dev Alibaba 模型列表 | `qwen3.7-plus` 不支持图像输入；视觉模型为 `qwen3-vl-plus` |
| 4 | 首次修复：移除自定义 provider，模型改为 `alibaba/qwen3-vl-plus` | 重启后仍报错：`Model not found: alibaba/qwen3-vl-plus` |
| 5 | 检查 `~/.local/share/opencode/auth.json` | 实际 provider key 为 `alibaba-cn`（非 `alibaba`） |
| 6 | 二次修复：模型改为 `alibaba-cn/qwen3-vl-plus` | ✅ 连接成功 |

### 根因分析

两个配置错误叠加：

1. **Provider key 不匹配**：`opencode.jsonc` 中自定义了 `"id": "Alibaba(China)"`，但 `auth.json` 中实际注册的 key 是 `alibaba-cn`。模型引用必须与 `auth.json` 中的 key 一致。
2. **模型不支持视觉**：`qwen3.7-plus` 是纯文本模型，Vision Agent 需要多模态模型 `qwen3-vl-plus`。

### 修复结果

```jsonc
// opencode.jsonc（修复后）
{
  "agent": {
    "vision": {
      "model": "alibaba-cn/qwen3-vl-plus"
    }
  }
}
```

- 移除了多余的 `provider` 自定义配置块
- Vision 模型从 `Alibaba(China)/qwen3.7-plus` → `alibaba-cn/qwen3-vl-plus`

### 经验沉淀

- **模型引用格式**：`{auth.json中的key}/{模型ID}`，不是 `provider.name` 也不是 `provider.id`
- **排查顺序**：报错信息 → `auth.json` 确认实际 key → Models.dev 确认模型是否支持目标能力（视觉/文本）
- **重启要求**：`opencode.jsonc` 修改后必须重启 opencode 才能生效
