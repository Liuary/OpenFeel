## 目标

- [ ] 2.1 **i18n 双表 · op-002 段**：消息 **21 键**（`req` 域）+ help **18 键**（`help` 域），双表成对（清单见「i18n 键清单 · op-002 段」）。
- [ ] 2.2 **`claim <id> [--owner <name>]`**（写命令，无 `--json`）：
  1. 未初始化守卫；`isValidReqId(id)` 守卫（非法 → `req.invalidIdTmpl` exit 1）。
  2. **`--owner` 缺省链（REV-82-012，S-82-7）**：`options.owner === undefined` 时 `const resolved = getUserName(process.cwd());`——`resolved === '' || resolved === 'unknown'`（`identity.ts` 三级链**末端哨兵**）→ `console.error(t('req.claim.ownerUnresolvedTmpl')) + exit 1`（**拒绝并提示显式 `--owner`；禁硬编码用户名**）；否则 `owner = resolved`。显式 `--owner ""` **不**走链（直通引擎 → `invalid_field`——零校验）。
  3. `const r = claimRequirement(data, id, owner);`——**返回码分流（命令层仅映射，零校验）**：
     - `not_found` → `req.err.notFoundTmpl`
     - `already_claimed` → `req.err.alreadyClaimedTmpl`（**数据零变更零审计**；含「须先 release」指引）
     - `invalid_field`（owner 空串）→ `req.err.invalidFieldTmpl`
     - `invalid_status`（终态）→ `req.claim.terminalTmpl` {id, status: `getRequirement(data, id)?.status ?? ''`}（终态值经读 API 渲染——纯呈现）
     - 均 exit 1 零写盘。
  4. `r.changed === true` → `try { mgr.save(); } catch`：并发 → `handleConcurrentConflict`（exit 2）；其他 → `errorTmpl` exit 1。成功 → `req.claim.doneTmpl` {id, owner}。
  5. `r.changed === false`（同 owner 幂等）→ **不 save**（revision 不变）→ `req.claim.idempotentTmpl` exit 0。
- [ ] 2.3 **`release <id>`**（写命令）：
  1. 未初始化 + ID 格式守卫；`const r = releaseRequirement(data, id);`
  2. `not_found` → `req.err.notFoundTmpl` exit 1（release 唯一错误码）。
  3. `changed === true` → save（并发 exit 2）→ `req.release.doneTmpl` {id}；`changed === false`（未占用 no-op）→ **不 save** → `req.release.noopTmpl` {id} + **恒 exit 0**（REV-82-010；引擎口径 `:134`）。
- [ ] 2.4 **`set <id> [--status <s>] [--title <t>] [--target-version <v>] [--priority <p>]`**（写命令）：
  1. 未初始化 + ID 格式守卫。
  2. **无字段守卫（argument-shape，非业务校验）**：四选项全 `undefined` → `req.set.noFieldsTmpl` exit 1。
  3. `const r = updateRequirement(data, id, { status: options.status as RequirementStatus | undefined, title: options.title, target_version: options.targetVersion, priority: options.priority as RequirementPriority | undefined });`——**命令层零校验：白名单 / 值域 / 流转全由引擎单点判定**（REV-82-003）。
  4. 分流：`not_found` → `req.err.notFoundTmpl`；`invalid_field` → `req.err.invalidFieldTmpl`；`invalid_status` → `req.err.invalidStatusTmpl` {id, to: options.status ?? '', current: `getRequirement(data,id)?.status ?? ''`, targets: `getAllowedNextStatuses(current).join(', ')`}（**合法目标取自引擎导出——零硬编码**）。均 exit 1 零写盘。
  5. `changed === true` → save（并发 exit 2）→ `req.set.doneTmpl` {id}；`changed === false`（同值 / 全等）→ 不 save → `req.set.noopTmpl` {id} exit 0。
- [ ] 2.5 **`link --stage <stageId> (--requirement <id> | --unlink)`**（写命令）：
  1. 未初始化守卫；`.requiredOption('--stage <stageId>')`（缺 → commander 报错）。
  2. **互斥守卫（argument-shape）**：`(options.requirement !== undefined) xor (options.unlink === true)` 不成立（both / neither）→ `req.link.exclusiveTmpl` exit 1。
  3. **归一单点（REV-82-006，S-82-8）**：`const stageKey = normalizeStageId(options.stage) ?? options.stage;`——**仅此一次归一；禁自写解析、不做双键回退、不读 status.md**；阶段存在性**以引擎 `stage_not_found` 为唯一门**。
  4. `--requirement <id>` 径：`isValidReqId` 守卫（非法 → `req.invalidIdTmpl` exit 1）→ `const r = linkRequirement(data, stageKey, id);`；`--unlink` 径：`const r = linkRequirement(data, stageKey, null);`。
  5. 分流：`stage_not_found` → `req.err.stageNotFoundTmpl` {stage: stageKey}；`not_found` → `req.err.notFoundTmpl`；`invalid_status`（终态需求拒绝关联）→ `req.link.terminalTmpl` {id, status}；`already_linked` → `req.err.alreadyLinkedTmpl` {stage: stageKey}（**exit 1 零写盘 + 「须先解绑」提示含完整命令**——REV-82-001；**无覆盖/替换语义**）。均 exit 1。
  6. `changed === true` → save（并发 exit 2）→ `req.link.doneTmpl` {stage, id}（关联径）/ `req.link.unlinkDoneTmpl` {stage}（解绑径）；`changed === false`（同值关联 / 未关联解绑）→ 不 save → `req.link.noopTmpl` {stage} exit 0。
- [ ] 2.6 **`advance <id> --to <status>`**（写命令）：
  1. `.requiredOption('--to <status>')`；未初始化 + ID 格式守卫。
  2. `const before = getRequirement(data, id)?.status;`（供成功文案 from 与失败 targets 渲染——纯读，非校验）。
  3. `const r = advanceRequirement(data, id, options.to as RequirementStatus);`——**命令层零校验**（合法目标 + done 门均在引擎单点——REV-82-003；裁定 M）。
  4. `invalid_status` → `req.err.invalidStatusTmpl` {id, to: options.to, current: before ?? '', targets: `getAllowedNextStatuses(before).join(', ')`}（**「列合法目标」= 引擎导出派生；禁命令层硬编码枚举**）exit 1；`not_found` → `req.err.notFoundTmpl` exit 1。
  5. `changed === true` → save（并发 exit 2）→ `req.advance.doneTmpl` {id, from: before ?? '', to: options.to}；`changed === false`（同值）→ 不 save → `req.advance.noopTmpl` {id, to} exit 0。
  6. **不设 `--force`**（done 门不可绕过——裁定 M）。
