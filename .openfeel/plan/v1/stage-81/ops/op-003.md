## 设计要点

- 正交断言照 `test/core/flow-archive.test.ts` 隔离节（@ `:574-583`）既有范式：`readFileSync(new URL('../../src/core/req/{file}', import.meta.url), 'utf-8')` 直读源文件做静态串断言——**这是「测试断言形式固化」的既有先例**，禁引入新工具链。
- 门禁基线（阶段起点实测，本 op 复跑核对）：测试 **68 文件 / 1408 用例**（stage-80 门禁登记值）；`lint i18n` = **829**（本阶段**不新增键**，复现：`OPENFEEL_LOG=0 node bin/openfeel.js lint i18n`）；`lint kb` = 0 过期；`npx tsc --noEmit` = 0。
- **防假绿前置断言**：读到的源文件内容须非空（`length > 0`）+ **正控**三断言（各文件独有符号 `toContain`）——证明读取路径真实有效，防负向断言空转。
