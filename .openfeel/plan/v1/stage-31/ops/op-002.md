## 目标

将 `flow wizard` 无阶段时的静默退出行为改为交互式创建首个阶段，创建完成后自动重新进入向导主循环。

## 知识库参考

- kb/patterns.md #CLI 原子管理模式：通过 `FlowManager.addStage()` + `save()` 创建阶段，不直接编辑 flow.json

## 实施步骤

### 步骤 1：修改 flow.ts wizard 无阶段处理逻辑

**当前代码**（`src/commands/flow.ts` L1019-1022）：
```typescript
if (stages.length === 0) {
  console.log(t('flow.wizard.noStages', lang));
  return;
}
```

**修改为**：
```typescript
if (stages.length === 0) {
  console.log(t('flow.wizard.noStages', lang));

  const { select: sel, input: inp } = await import('@inquirer/prompts');
  const shouldCreate = await sel({
    message: t('flow.wizard.createPrompt', lang),
    choices: [
      { name: t('flow.wizard.createYes', lang), value: 'yes' },
      { name: t('flow.wizard.createNo', lang), value: 'no' },
    ],
  });

  if (shouldCreate === 'yes') {
    const stageId = await inp({
      message: t('flow.wizard.createInput', lang),
      validate: (val: string) => {
        if (!val.trim()) return t('flow.wizard.createEmpty', lang);
        return true;
      },
    });
    mgr.addStage(stageId.trim());
    mgr.save();
    console.log(t('flow.wizard.createdTmpl', lang, { stage: stageId.trim() }));
    continue; // 重新进入主循环，此时 stages 已非空
  } else {
    console.log(t('flow.wizard.createSkipped', lang));
    return;
  }
}
```

- [ ] 使用 `edit` 工具替换 L1019-1022 的代码块

> **关键细节**：
> - `continue` 而非 `return`——创建成功后重新进入 `while` 主循环，自动选择新阶段继续推进
> - `mgr.addStage()` + `mgr.save()` 创建 flow.json 条目，与 `flow stage add` 行为一致
> - 用户选择"否"时 `return` 退出向导，保持原有退出行为

## 风险说明

| 风险 | 概率 | 缓解 |
|------|------|------|
| `@inquirer/prompts` 的 `input` 导入失败 | 极低 | 与 `select` 同包，wizard 已有 try-catch 兜底 |
| 创建的 stage ID 重复 | 低 | `addStage()` 内部检测重复，异常被外层 try-catch 捕获 |
| `continue` 导致无限循环 | 极低 | 创建后 stages 非空，第二次循环走正常 `select` 逻辑 |
| 非交互环境（CI/CD）执行 wizard | 低 | wizard 本身为交互式命令，CI 环境不应调用；后续可增加 `--non-interactive` 模式（超出本 op 范围） |
