## 二、N9 子项清单

### N9-1（低/中）index.md 宽容解析与列数自适应

- **文件:行号**：`src/core/workspace/knowledge.ts:217-247`（`getKnowledgeIndex`）→ `:293-303`（`parseCategoriesTable`，实测 `:294` 硬匹配 `/## 分类概览\n\n([\s\S]*?)(?=\n## |$)/`）与 `:306-311`（`parseRecentUpdatesTable`，实测 `:307` 硬匹配 `/## 最近更新\n\n…/`）；`addKnowledgeEntry`（`:108-`）实测 `:144` `const sepLine = '|------|------|------|'`（硬编码 3 列）
- **现状**：段头匹配**大小写/空白/别名敏感**；表头与列数**假定固定**（分类概览 2 列、最近更新 3 列）；`add` **硬编码 3 列分隔行** → 下游自定义 index.md（不同段头或列数）必然降级或报错。
- **改后**：
  1. **段头宽容匹配**（`parseCategoriesTable` / `parseRecentUpdatesTable`）：
     - 正则改为「**行级**」匹配，容忍前后空白与中英别名，例如
       `/^##\s*(分类概览|Categories|Category Overview)\s*$/im`、`/^##\s*(最近更新|Recent Updates)\s*$/im`；
     - 段落截取改为「本段头行 → 下一个 `^## ` 行或文末」（不再要求 `\n\n` 紧邻）。
  2. **表头/列数自适应**：
     - 解析时按**实际表头列名**定位列索引（如「分类/名称」「条目数/Count」「日期/Date」「分类」「标题/Title」的中英别名），缺失列 → 空串；
     - 数据行 `split('|')` 后按列数**不等长容忍**（多余列忽略、缺失列补空）；
     - 完全无法识别表头 → 返回空数组（**降级不抛错**）。
  3. **`addKnowledgeEntry` 分隔行按实际列数生成**：删除 `:144` 硬编码，改为依据**目标表头列数**生成：`'|' + '------|'.repeat(cols)`；若表头缺失/不可识别 → 沿用既有 3 列（保持现行为）。
  4. **不改变返回结构**：`KnowledgeIndex` 类型不变（仅解析更宽容）。

### N9-2（低/中）新增 `openfeel knowledge dedup` 子命令（**A6**）

- **文件:行号**：`src/commands/knowledge.ts:18-`（`registerKnowledgeCommand`；现有子命令 `list`（:27）/`add`（:60）/`search`（:104）/`index`（:141））→ 新增 `dedup`；调用 `src/utils/kb-dedup.ts:157-184`（`findSimilarEntries`，**stage-50 T8 已加 `basePath?`**）
- **现状**：`utils/kb-dedup.ts` 的 `findSimilarEntries` **零 import**（仅模板文本提及），下游无法使用去重能力。
- **改后**：
  1. **命令签名**：
     ```
     openfeel knowledge dedup [content] [--project <path>] [--category <name>] [--threshold <n>]
     ```
     | 参数/选项 | 语义 | 默认 |
     |------|------|------|
     | `[content]` | 待归档内容文本（位置参数；未提供时从 **stdin** 读取，二者至少其一） | stdin |
     | `--project <path>` | 目标项目根（用于定位 `.openfeel/kb`） | `process.cwd()` |
     | `--category <name>` | 仅检查指定分类（`architecture\|patterns\|troubleshooting\|setup`）；未指定 → **遍历全部 4 分类** | 全分类 |
     | `--threshold <n>` | 相似度阈值（0~1，覆盖默认 0.8） | `0.8`（`shouldUpdate` 语义） |
  2. **路径注入（契约关键）**：命令层计算 `const basePath = resolve(projectPath, '.openfeel', 'kb')` 并**仅通过参数传入** `findSimilarEntries(content, category, basePath)`；**不得**修改 `kb-dedup.ts` 内部默认解析逻辑，也**不得**在命令层复制路径规则（单一来源）。
  3. **输出（只读建议，不改盘）**：对每个分类列出相似条目：`{title}（相似度 {pct}%）`；若 `similarity > threshold` 标注「**建议合并/更新**」；末尾固定一行「本命令仅输出建议，**不会修改** kb 文件」。
  4. **退出码**：正常（无论是否有相似条目）→ **0**；参数错误（阈值越界 / 分类名非法 / 无 content 且无 stdin）→ `1`。
  5. **`--content` 与 BUG-004 的耦合**：本子命令新增的 `[content]` 位置参数**必须同时补齐** `help.knowledge.dedup.argcontent`。BUG-004 修复清单因此为 **+1 处（本 op 4 处）**，并在 op-009 的运行时枚举复核中计入。
