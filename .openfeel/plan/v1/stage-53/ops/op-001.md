① **D1**：把两条设计目的（**保存核心信息便于恢复** / **避免无关信息污染上下文**）与「索引层 / 主题层 / 详情层」分层原则写入**全局框架约束层权威源**（`templates-data/agents-md/{zh-CN,en}.md`）。

- **改后**：替换为**规则块**（含内联新模板骨架）：
  ```markdown
  > .openfeel/dev/current.md

  **团队文件（用户级视图）**：记录**跨用户操作**与**整体信息**。
  - **仅个人提交时更新**（一次提交 = 一条记录）；
  - 只写**整体信息**（做了什么、处于什么状态）；**禁止** agent 细节；**禁止** `## @成员` 段（逐条流水改放 `dev_last` 主题文件）；

  - 归档文件名 `current-{yyyy-mm-dd}-{NNN}.md`（同日多份 NNN 递增）。

  ```markdown

  > {一句话整体进度}（整体信息，用户级视图）

  ## 近期提交记录（最多 5 条，最新在上）

  > 更早记录见 `.openfeel/dev/current_archive/`（每次提交自动归档最旧一条；本文件仅保留近期 5 份）。
  ```
  ```
  > **`@{username}` 说明（A5）**：记录内**保留单行内联 `@{username}`**（用于跨用户场景标识提交者，**不是**「@成员段」——行内标识 ≠ 分节）。**A5 为「planner 依据 + 待 Feel/用户确认」**，如用户要求去掉，删除该内联标识即可（不影响其余规则）。
