# op-003：三层级读写 + 校验 + 幂等测试

- **阶段**：v1.1.0-stage-40
- **前置**：op-001（hard——测试对象 `model-config.ts`）、op-002（hard——命令层测试对象 `commands/model.ts`）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标

为 `model-config.ts` 与 `commands/model.ts` 补单元测试：三层级读写、模型名校验、幂等、frontmatter 合并、生效值解析、REV-1504 非 TTY 确认。隔离 HOME + mock auth.json（REV-1505）+ 隔离 default 仓库源（REV-1506）。

> 参见 kb/patterns.md #测试隔离 HOME 模式（`vi.hoisted` + `vi.mock('node:os')` + `beforeEach` 换 tmp home，参照 migrate.test.ts / opencode-config.test.ts）。

## 关键设计决策

1. **HOME 隔离**：`vi.hoisted(() => ({ dir: '' }))` + `vi.mock('node:os')`，`beforeEach` 设 `mockHome.dir = mkdtempSync(...)`，隔离 `~/.config/opencode/opencode.jsonc`（global）与 `~/.local/share/opencode/auth.json`（REV-1505：mock 一处即隔离）。
2. **default 层仓库源隔离（REV-1506）**：将 `src/core/templates-data/opencode/agents/{zh-CN,en}/*.md` + `src/core/opencode-config.ts` 复制到 `mkdtempSync` 临时目录（保留 `src/core/...` 相对结构），`setAgentModel(..., { frameworkRoot: tmp })`，测试后 `rmSync` 清理，**不污染真实仓库源**。
3. **project 层隔离**：`setAgentModel(..., { projectPath: mkdtempSync })`，断言临时项目 `opencode.jsonc` 变更。
4. **命令层测试**：直接调用 `registerModelCommand` 注册到独立 `Command` 实例并 `parse`，或复用项目既有 commands 测试模式（参照 `test/commands/migrate.test.ts`），断言 stdout/stderr 与退出码。REV-1504 通过 `process.stdout.isTTY` 为 false（vitest 环境）自然触发。

/** 递归复制目录（复制仓库 templates-data 到 tmp） */
function copyDirSync(src: string, dest: string): void {
  mkdirSync(dest, { recursive: true });
  for (const name of readdirSync(src)) {
    const s = join(src, name);
    const d = join(dest, name);
    if (statSync(s).isDirectory()) { copyDirSync(s, d); } else { copyFileSync(s, d); }
  }
}

/** 建立隔离的框架源码根（含 src/core/templates-data/opencode/agents + src/core/opencode-config.ts） */
function setupFrameworkTmp(): string {
  const root = mkdtempSync(join(tmpdir(), 'model-config-fw-'));
  const srcCore = resolve(process.cwd(), 'src', 'core');
  copyDirSync(
    join(srcCore, 'templates-data', 'opencode', 'agents'),
    join(root, 'src', 'core', 'templates-data', 'opencode', 'agents'),
  );
  mkdirSync(join(root, 'src', 'core'), { recursive: true });
  copyFileSync(join(srcCore, 'opencode-config.ts'), join(root, 'src', 'core', 'opencode-config.ts'));
  return root;
}

  writeFileSync(p, JSON.stringify(Object.fromEntries(providers.map((k) => [k, { type: 'api', key: 'x' }]))));
}

/**
 * model 命令层测试（stage-40 / op-002）
 * 覆盖 set/get/list 输出、校验错误、REV-1504 非 TTY 确认、scope 非法。

import { describe, it, expect, afterEach, vi } from 'vitest';
import { Command } from 'commander';
import { registerModelCommand } from '../../src/commands/model.js';

/**
 * 执行 model 命令组并捕获退出码与输出（REV-1602 修订：完整实现，替代原桩代码）。
 * 说明：commander 的 configureOutput 只捕获 help/版本输出，不会捕获 action 内的 console.log/error，
 * 故用 vi.spyOn(console, 'log'/'error') 收集；退出码用 exitOverride() 将 process.exit 转为抛 CommanderError 捕获。
 */
function runModel(args: string[]): { stdout: string; stderr: string; exitCode: number } {
  const program = new Command();
  registerModelCommand(program);
  program.exitOverride();  // 将 process.exit 转为抛 CommanderError，避免测试进程真退出
  let stdout = '';
  let stderr = '';
  const logSpy = vi.spyOn(console, 'log').mockImplementation((...a: unknown[]) => { stdout += a.join(' ') + '\n'; });
  const errSpy = vi.spyOn(console, 'error').mockImplementation((...a: unknown[]) => { stderr += a.join(' ') + '\n'; });
  let exitCode = 0;
  try {
    program.parse(['node', 'openfeel', 'model', ...args], { from: 'user' });
  } catch (err) {
    exitCode = (err as { exitCode?: number }).exitCode ?? 1;
  } finally {
    logSpy.mockRestore();
    errSpy.mockRestore();
  }
  return { stdout, stderr, exitCode };
}

describe('openfeel model 命令', () => {
  afterEach(() => { vi.restoreAllMocks(); });

  it('set --scope default 非 TTY 无 --force/--build 拒绝（REV-1504）', () => {
    // vitest 下 process.stdout.isTTY === false，触发 REV-1504 拒绝路径
    const r = runModel(['set', 'openfeel-executor', 'deepseek/flash', '--scope', 'default']);
    expect(r.exitCode).toBe(1);
    expect(r.stderr).toBeTruthy();  // 拒绝文案（model.set.needConfirm，语言随 getCliLang）
  });

  it('set --scope 非法值报错 model.error.scope', () => {
    const r = runModel(['set', 'openfeel-executor', 'deepseek/flash', '--scope', 'bad']);
    expect(r.exitCode).toBe(1);
    expect(r.stderr).toBeTruthy();  // 非法 scope 报错（model.error.scope）
  });

  it('list 输出 9 个 agent', () => {
    const r = runModel(['list']);
    expect(r.exitCode).toBe(0);
    expect(r.stdout).toContain('模型列表');  // model.list.title（zh）；en 环境改为断言 agent 数量或非空
    // 可选更稳断言：stdout 中出现 openfeel- 前缀条目 ≥ 1（不依赖 i18n 语言）
  });
});

## 风险与注意

- **REV-1504 非 TTY 触发**：vitest 中 `process.stdout.isTTY` 恒为 false，所有 `--scope default` 命令测试须显式 `--force` 或 `--build` 才能走通写路径；否则只能断言拒绝分支。
- **default 层制造不一致的测试**：opencode-config.ts 读取是文件文本（非 import 函数），故「不一致」测试通过「改 frontmatter 后重新复制原 opencode-config.ts」制造，避免依赖 in-memory 函数（见步骤 1 测试 6）。
- **`--build` 副作用**：命令层测试**不要**触发真实 `npm run build`（重操作 + 污染源）；仅断言 `--build` flag 被透传/提示，不执行。若需验证 build 触发，用 `vi.mock('node:child_process')` mock `execSync`。
- **frontmatter 序列化差异**：断言用 `toContain('model: deepseek/new-model')` 而非整文件 `toBe`，避免 yaml.stringify 引号风格差异导致脆弱断言。
