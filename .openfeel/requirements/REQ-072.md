## 摘要

1.6.4 收口时确认两个问题：① `node scripts/release.mjs --dry-run` 被 guard 按「高风险 node 脚本正文不可判定」class1 拒绝，导致文档里的发布预演命令 agent 无法执行（真实发布参数应继续拒绝）；② 全量 npm test 在负载下出现 flaky（首跑 RPC timeout、migrate.test 的全局 opencode.jsonc 用例偶发失败，单跑全绿）。两者都不影响已发布功能，留到 1.6.5 处理。

## 目标与验收

### 目标

修复两处稳定性/可用性问题：① guard 允许 `node scripts/release.mjs --dry-run` / `--skip-build` 在 `exec_running` 执行（真实 `--publish` 仍拒并留审计）；② 消除全量测试的 flaky（`migrate.test` 的全局 `opencode.jsonc` 用例与 dsh 并发时 RPC timeout/失败），连续 3 次 `npm test` 0 failed。

### 验收

- A72.1 guard 对 wrapper 目标 `scripts/release.mjs` 且 argv 含 `--dry-run`/`--skip-build`、**不含** `--publish`/`--commit-archive`/`--tag`/`--push` 时按 class 4 warn 放行并审计；含任一真实发布/提交参数仍 class 1 拒绝。
- A72.2 新增 ≥4 条 guard 用例（dry-run 放行、skip-build 放行、--publish 拒绝、--commit-archive 拒绝），`dsh/test/guard.js` 全绿。
- A72.3 `migrate.test` 涉及全局 `opencode.jsonc` 的用例改为临时 HOME/隔离目录，不读写真实用户配置；与 dsh 测试并发运行时不再互相干扰。
- A72.4 全量 `npm test` 连续 3 次 0 failed（记录首次 flaky 名单：RPC timeout / migrate 全局配置用例），并在计划/日志登记已消除。
- A72.5 版本 1.6.5（root/dsh lockstep、`requiresCli >=1.6.5`），push master 后由 CI 自动发布；不手动 publish。
- A72.6 不改既有 guard 对真实发布/提交的拒绝语义，不改 test 断言之外的业务行为。
