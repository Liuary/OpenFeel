**需求映射**：`docs/phase-5/07-openfeel-permission-issue.md` **§四建议 2**（文档化覆盖语义）、**建议 3**（项目级入口 → 裁定 O3 仅文档化）、**建议 4**（保留自定义 → O4）、**§五**（镜像全量键的理由）；裁定 **O3 / O4 / O5**。

1. **主载体 = `templates-data/agents-md/{zh-CN,en}.md`**（部署为全局 AGENTS.md，自动加载）→ 新增 `## 权限模型（Agent permission）` 一节（zh/en 同结构、同含义）。

3. **详版 = `.openfeel/manual/core/permission.md`（新建）** + `manual/index.md` 登记（模块文档系统）。
4. **O3 严守**：只文档化 opencode 原生 `agent.<name>.permission`，**不新增任何 CLI/生成器**。
5. **不采纳项显式记录**：O5「只读放行/写入询问」——opencode `external_directory` 为**单一键**（无 read/write 粒度），文档注明「平台不支持该粒度」（避免用户重复提问）。

## REV-001 三点补强落实（硬性）

1. **① 镜像告警**：在「项目级收紧入口」处**显式标注**——若 opencode 对项目 `agent.<name>.permission` 采用「替换」语义，**仅写 `external_directory` 会丢失该 agent 原有 `bash/read/glob/...` 白名单**；**建议镜像全量键**（给出完整示例，对齐文档 07 §五）。由 op-001 场景 F 结论决定措辞强度（若确认为「深合并」则表述为「为兼容潜在替换语义，仍建议镜像」）。
2. **② O4 表述精确化**：明确「**勿手改全局 agent 文件 frontmatter 的 `permission`**——`openfeel update` 时 frontmatter 同名字段会被框架覆盖（浅合并 `{...existing, ...incoming}`，见 `src/core/managed-region.ts:185-190`；测试 `test/core/managed-region.test.ts:178-181` 已证 `permission` 嵌套对象**整体覆盖、非深合并**）；项目级 permission 自定义请走项目 `opencode.jsonc` 的 `agent.<name>.permission`」。
3. **③ `allow` 单值形式确证**：文档中的示例写法（单值 `"allow"` vs 对象 `{ "*": "allow" }`）**与 op-001 场景 B 结论一致**；在 manual 详版注明「值形式已实测（op-001-findings）」及实测版本号。

## 精确改动点（文件:行号 → 现状 → 改后）

### 改动 1：`src/core/templates-data/agents-md/zh-CN.md`（新增节）

- **插入位置**：`## 动态规则`（现 `:110`）**之前**（与「跨 Agent 工具使用约束」同层）。
- **改后（新增节，建议文案）**：
  ```md
  ## 权限模型（Agent permission）

  OpenFeel 的 9 个 agent 各自内联 `permission:` 白名单（部署于 `~/.config/opencode/agents/*.md`）。

  - **覆盖关系**：agent 级 `permission` 优先/覆盖项目与顶层 `permission`——项目里写 `"permission": "allow"` 对已内联白名单的 agent **不生效**。
  - **`external_directory`**：框架默认 `allow`（工作区外目录免询问）。若需收紧，在项目 `opencode.jsonc` 的 `agent.<name>.permission` 覆盖。
  - **项目级收紧/精细化（原生入口，无需 OpenFeel CLI）**：……
    ⚠️ 若实现为「替换」语义，**仅写 `external_directory` 会丢失原白名单**，请**镜像该 agent 的全部 permission 键**。
  - **勿手改全局 agent 文件 frontmatter**：`openfeel update` 会覆盖 frontmatter 同名字段（含 `permission`，浅合并）；项目级自定义请写项目 `opencode.jsonc`。用户正文自定义请写在受管区外。
  - **生效时机**：opencode 仅启动时读配置，改后需**重启**。
  - **不支持的能力**：`external_directory` 为单一键，**无「只读放行/写入询问」的读写分粒度**。
  ```
