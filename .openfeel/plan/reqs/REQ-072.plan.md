# REQ-072 计划：1.6.5 release dry-run 门禁白名单 + 全量测试 flaky 隔离

> 依据：`.openfeel/plan/v1/stage-138/plan.md` §一（**A72.1—A72.6**）与 §二 **R2**；本文件只做需求级拆解，**不改判据含义、不新增需求外任务**。边界：不 push / 不打 tag / 不 publish；不改 `flow.json` / `status.md` / `dist/**`；**不改** guard 对真实发布/提交的拒绝语义与 `npm run release` 的既有 class4 分类（A72.6）。

## 目标

- **做什么**：① guard 对**仓库自身**的 `node scripts/release.mjs` + 纯预演参数（`--dry-run`/`--skip-build`，且不含 `--publish`/`--commit-archive`/`--tag`/`--push`）按 **class 4 warn 放行 + 审计**（`detail.reason='release-dry-run-allowlisted'`），含任一真实发布/提交参数仍 **class 1 拒绝**；放行判定经 realpath **绑定含 `.openfeel/` 的项目根**（TEMP/仓外同名脚本一律拒绝）；新增 ≥5 条 guard 用例。② `test/core/migrate.test.ts` 的全局 `opencode.jsonc` 用例做**真隔离**（mock `node:os` 的 `homedir()` → 每测试临时目录 + 显式 `HOME`/`USERPROFILE`/`CLAUDE_CONFIG_DIR` + **真实文件哈希零变化**断言）；全量 `npm test` 连续 3 次 0 failed；根因复现不出只登记「未复现」。
- **为什么**：1.6.4 收口时文档里的发布预演命令被 guard 按「高风险 node 脚本正文不可判定」class1 拒绝，agent 无法执行预演；真实发布参数必须继续拒绝，因此只能做**逐参数白名单**而不是放宽 highRisk。flaky 让全量门禁结论不可信（首跑 RPC timeout、migrate 全局配置用例偶发失败），必须变成「重复 3 次稳定绿」。
- **关键事实与边界**：现有链路 `dsh/lib/guard.js:1856-1868`（node 包装器 `inspect:false`）→ `:1981-1985`（`scripts/**` 必读）→ `:2003-2031`（`highRisk:true`）→ 内容分类 `:3189-3249`（highRisk 不可判定→class1 `:3212-3230`）；`scripts/release.mjs:153-200` 的参数是闭集（既有 11 个 flag）、`--dry-run`/`--publish` 互斥。既有 A67.5 断言 `dsh/test/guard.js:3207-3217`（`--publish` deny + `reason='node-script-high-risk-undecidable'`）**零改动**：白名单只加「放行分支」，deny 落回原路径。**生效时机**：`dsh/lib/guard.js` 由宿主启动时加载，改文件后当前会话仍跑旧代码（`dsh/lib/adapters/guard-state.js:383-395` 的 `loaded_hash` 自证）→ 验收只用新进程测试。

## 风险

- **白名单变成后门**：必须闭合集合（只两个 safe flag）+ **realpath 绑定含 `.openfeel/` 的项目根 + 相对路径恰为 `scripts/release.mjs`**（TEMP/仓外同名脚本必拒，见用例 ⑥）+ `continue` 不 `return` + strict 仍 deny；组合语句/未知 flag/路径变体全部落在负向用例里；任何「按子串匹配参数」的实现直接否决。
- **flaky 根因未明**：`test/core/migrate.test.ts:8-13` 已 mock `node:os`、`:86-96` 已用临时 HOME，说明**只 mock 不够**；改为 mock homedir + `CLAUDE_CONFIG_DIR` 显式隔离 + 真实文件哈希断言；禁止「保存原内容再写回」（`kb/troubleshooting.md:656` 已裁定无效）。若失败实为 `withFileLock(globalLockPath('global-opencode-jsonc'))`（`src/core/migrate.ts:556`，5s/3s）或 Windows 原子写争用 → 改该用例（per-test 独立 lock 目录 / 直接断言 `mergeGlobalOpencodeJsonc`），**不放宽生产默认值**、不用 `--no-file-parallelism` 掩盖。**复现不出根因就只登记「未复现」，不得声称已解决。**
- **把会话行为当证据**：guard 改动重启宿主才生效，会话里 dry-run 仍被拦属预期；验收只用 `node dsh/test/guard.js` 新进程结果。
