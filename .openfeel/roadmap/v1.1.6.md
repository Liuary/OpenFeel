## 目标

OpenFeel 当前**仅适配 opencode**。本版本新增 **Claude Code 适配器**，与 opencode **并存**；Claude 侧**显式启用**（`--tools claude` 或交互勾选），**默认行为逐字不变**。

1. **模板管线多源化**：17 skills 迁**单一中立共享源** `templates-data/skills/`（零内容变更），供两 harness 共用；agents 与约束文件**每 harness 独立源**。
2. **Claude 内容适配**：`templates-data/claude/**`（**9×2 agents（含 `feel`）+ 约束×2**）+ build 注入/校验/单源断言 + `template-loader` 3 API。
3. **共享 skills 中立化**：4 重写（拆 `### opencode 适配器` / `### Claude Code 适配器` 分节，opencode 小节逐字保留）+ 3 轻改 + 6 个 Feel 措辞。
4. **部署编排与命令面**：`global-paths` 5 函数（尊重 `CLAUDE_CONFIG_DIR`）+ `setup/update` 双分支 + `--tools`（非法值 exit 1）+ **R-5 高危修复**（`filter(t=>t.enabled)`）+ i18n 761→768 + **D-CFG** 越界备份 fallback。
5. **`settings.json` 注入（一等能力）**：读-深合并-写回，注入 `agent:"feel"` + `permissions.defaultMode:"auto"`（automod=auto mode），**逐字保留用户既有键**；幂等/备份/卸载语义。
6. **文档与版本收口**：README×3 / GETTING_STARTED / commands / manual / skill + CI guard（`$HOME/.claude`）+ 版本 **1.1.6** 全链路（A/B/C/D/E）。

| D-STATE | **延后**；Q3 `rules/` **本期不用**；Q1/Q2 留 stage-69 实测 |
