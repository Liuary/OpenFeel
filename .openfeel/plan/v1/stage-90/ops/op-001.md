## 目标

把 `WORKFLOW_MODES` 从 2 值扩为 **3 值**（`full` / `fast` / `general`，展示命名 规划 / 快速 / 通用），使其**所有既有消费点**（status.md 正则 / 转移表 / 骨架初值 / 冗余字段 / 命令面 / help / health）经**单源派生**自动覆盖，并为 `general`（=「无流水线」）落下**载体制约束门**（阶段级 / 部署级写入面拒绝 + 明确引导）与 `flow advance` 显式错误（防御路径），配套值域面单测。**不改版本号 / 不动本仓模式值 / 不触碰 templates-data（零 build）**。
