# v1.6.0-stage-132

## 目标

把「流程可信度」从口头要求变成**结构性门禁**，修复四类一致性事故：

| 事故 | 现状证据 | 本阶段要交付 |
|------|----------|--------------|
| 空壳需求 | 本仓 54 份需求正文 **48 份**仍是 `（待补充）`；CulaHub 同样 | 需求正文可结构化写入 + 未写实不得认领/开始/推进 |
| 无计划执行 | 阶段级 `plan.md` 可缺失、可占位；`exec_running` 不看计划 | 需求级计划文件 + 执行前门禁 + 偏差回写判据 |
| 主会话包办 | feel_mode 仅「建议」用子代理；主会话上下文爆掉 | 派发记录 + 调度者/执行者边界硬约束（DSH 侧） |
| 模式逃逸 | `general` 模式转移表为空 = 无流水线；fast 语义模糊 | 全模式保留 plan → exec → review 强制链 |

目标不是「多写文档」，而是：**上下文清空后，仅凭 `.openfeel/` 内的持久化文件就能复原
「要做什么（需求）→ 怎么做（计划）→ 做到哪（执行/审查记录）」**。

## 关联需求

- **REQ-055**（P0）需求/阶段正文必须写实：空壳需求禁止流转
- **REQ-056**（P0）执行前必须有计划：需求级计划门禁与偏差回写
- **REQ-057**（P1）主会话只调度：子 Agent 分角色执行并记录派发
- **REQ-058**（P0）模式语义收紧：general/fast 也必须 plan→exec→review
- **REQ-059**（P0）开发账本持续更新：写操作即自动同步，`archiving→done` 前有硬门（`DEV_SYNC_STALE`）
- **REQ-060**（P0）DSH 提示词改造：压到 ≤1200 字符 / ≤25 行 + 每轮提醒 + 动作型 next

## 依赖

无（上一版本 v1.5.25 已归档；本阶段为 v1.6.0 首个阶段）。

## 开发节奏

1. **调研**（3 路并行）：需求正文链路 / 相位门与模式表 / DSH 派发与守卫能力边界 →
   摘要落 `.openfeel/tmp/stage-132/research/`。
2. **计划**（planner）：综合调研写成 `plan.md`（需求级拆解、判据、任务顺序），经计划审查。
3. **执行**（executor，按计划分段）：CLI 原语 → 门禁接线 → 模式表 → DSH 约束 → 迁移与文档。
4. **审查**（reviewer，独立）：逐条对照验收 A1~A6 取证，抽查空壳判据无绕过。
5. **收口**：需求逐个 review+verify 后 done；版本归档与发布等用户确认。

## 操作方案

- 计划文件：本阶段 `plan.md`（阶段级编排）+ 每个在办需求的 `REQ-NNN.plan.md`（需求级拆解）。
- 调研摘要：`.openfeel/tmp/stage-132/research/*.md`（只读输入，不进入门禁）。
- 实现边界：`src/core/req/`、`src/core/plan/`、`src/commands/{req,stage,flow,lint}.ts`、
  `src/core/config.ts`、`dsh/lib/**`、`test/**`、相关文档；其余不动。
- 模式：本阶段用 **full**（含方案/测试相位）验证「严格链」本身可用；fast/general 的语义改动
  由 REQ-058 落地后另测。

## 验收（阶段级）

- E1：四份需求正文与 `plan.md` 均为写实内容（自证：本阶段自身不再依赖会话记忆）。
- E2：空壳需求认领、无计划推进 `exec_running` 均被拒绝（有单测与实测记录）。
- E3：`general` 模式阶段可走通 plan → exec → review → done，且无计划不可 exec。
- E4：`npm test`、`npm run build`、`dsh/test` 全绿；既有 2400+ 用例无回归。
- E5：CLI 参考 / DSH ACTION-GUIDE / README 流程说明与实现一致。

## 风险

- **门禁过严伤小活**：以「目标 + 验收」为最小写实门槛，轻量档不要求长文；存量只在下一次流转拦截。
- **两层实现漂移**（CLI 校验 vs DSH guard）：判据单点放在 `src/core/`，guard 只做路径级拦截。
- **模式语义变更影响既有项目**：`general` 不再免流水线，需要迁移说明与 `--force` 之外的显式豁免路径（不默认开放）。
