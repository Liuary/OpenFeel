## 回滚/风险
- **回滚**：本 op 单独一个提交，`git revert` 即回退；`filled.ts` / `body-lint.ts` 是新增文件，删除回退后须同时还原 `flow-manager.ts:5231/:5239` 的本地常量与正则。
- **风险（REV-004 语义混用）**：若 `isTemplateEmpty` 误用逐行版正则，`plan.ts:489`、`flow.ts:1557` 的 `fill` 字段会退化 → 以 `filled.test.ts` 断言 ①②③ 兜底。
- **风险（计数锁三处不同批）**：doc 三行 + knowledge 计数 + json-contract 编号必须同批，否则 `input` 计数锁红；按步骤 4/5 顺序提交。
- **风险（越界写节）**：`writeRequirementBodySection` 若整文件重写会破坏其余 6 节 → 用 `git diff --stat` 断言单文件单节。
- **风险（i18n 重排）**：只在 `help.req.*`（:1089-1179）/`req.*`（:1332-1464）域末追加，禁重排既有条目（§6.1 :326）。
- **风险（REV-010 顺序倒置）**：若把 `findRequirementPlanPath` 留到 op-003 才建，本 op 的 `body-lint.ts` 会引用未定义符号 → 构建必红；以「只有本 op 产物的提交上 `npm run build` exit 0」为硬判据，回退时两处同退。
