## 回滚/风险
- **回滚**：本 op 单提交 `git revert`；若只想放松门，保留 `describeStagePlanGate` 但让 `advanceStagePhase` 只写审计不拒绝（审计字段先于拒绝逻辑落地，保证可回退到「只留痕不拦」）。
- **风险（自锁 R2）**：本阶段若缺 `plan.md` 会被自己的门拦住 → 本计划合入即满足 stage plan；不足时用 `--force`（留痕）。
- **风险（复位绕过）**：只改 `advanceStagePhase` 不改 `resetStagePhase` 会留后门 → T056.4 两态断言为硬判据。
- **风险（命令层冒充拦截）**：`--force` 在 `flow.ts:1134` 跳过 `findPhasePath`，命令层镜像可被绕过 → 拒绝逻辑必须在核心层（硬约束 1）。
- **风险（偏差门抢 done 门文案）**：顺序错了会让缺 review 的需求收到 `plan_deviation` → REV-001 断言为硬判据。
- **风险（写盘泄漏）**：拒绝路径若先盖章 `req.plan` 再判门，会产生"被拒但已写"→ A4 的 revision 不变断言兜底。
