# op-005：模板源与部署实例路径引用统一（双层模板 + skill 定义，双语）

- **阶段**：v1.0.0-stage-34

## 目标

将 Agent 模板与 skill 定义中残留的 `stages/` 或平铺 `plan/{stage}/` 引用统一为 `plan/{series}/{stage}/`，双层模板源 + `.opencode/` 部署实例逐字符同步，zh-CN + en 双语。

> **强制约束**：按 kb/troubleshooting.md #双层模板源发散「按节锚点定点编辑、禁止整文件复制」，用 `git diff --no-index` 验证（非 PowerShell diff）；kb/patterns.md #双语开发强制约束——所有模板改动 zh-CN + en 同步，否则 `npm run build` 一致性校验失败。
