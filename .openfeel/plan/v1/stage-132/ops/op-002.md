## 步骤
1. **改返回通道**：`RequirementErrorCode`（`requirement-ops.ts:20-27`）加 `'body_empty'`；`applyStatusChange` 返回型由 `boolean` 改为 `RequirementGateCode | null`，内部 5 处 `return false` 按 plan T4 影响面① 分别映射（`:530/:531/:534/:536` 仍为 `'invalid_status'`）；`:593` 改为 `const gate = applyStatusChange(...); if (gate) return { ok:false, code: gate };`。
2. **加门谓词**：新增 `requirementBodyBlocker(data, req, targetStatus): 'body_empty' | null`，调用 `isRequirementBodyFilled`（不新写判据）；在 `applyStatusChange` 内 `:536`（done 门）**之前**调用。触发集合写死：`targetStatus ∈ {scheduled, in_progress, done}` 且 `req.body_waiver === undefined`；`draft/blocked/cancelled/rejected` 不判；不按 `workflow_mode` 分支（general/零阶段同样生效）。
3. **加 claim 门（REV-003）**：`claimRequirement`（`:484-497`）在 `:491`（同 owner 幂等）**之后**、`:492`（`req.owner = name`）**之前**直接调同一谓词；不满足返回 `{ok:false, code:'body_empty'}`（零变更零审计）。
4. **加 force 通道**：`src/commands/req.ts` 的 `claim` / `advance` / `complete` 增 `--force`：claim 路径写 `req.body_waiver={at,by,reason:'claim-force'}` + `appendRequirementLog(data,'requirement_body_forced',{id,by,gate:'claim'})`；advance/complete 路径写 `body_waiver` + 同 action（`gate:'advance'`）。同族新增 `bodyGateMessage`（紧邻 `:116-126` 的 `doneGateMessage`），命令层映射表把 `body_empty` → envelope `REQ_BODY_GATE`。
5. **i18n 与测试**：`src/core/i18n-data/zh-CN.ts` + `en.ts` 在 `help.req.*` / `req.*` 域末追加新文案；扩 `test/core/req.test.ts`（`requirementBodyBlocker` 直测、claim 门、waiver 后放行、done 门三态不变）与 `test/commands/req.test.ts`（force 审计末条、`--json` 失败 envelope）。
6. **自检**：`grep -rn "isRequirementBodyFilled" src/` 命中 ≤3 处；`test/cli/error-envelope.test.ts` 增 `REQ_BODY_GATE`；`npm test` 全绿。

## 回滚/风险
- **回滚**：本 op 单提交 `git revert`；若只想关掉门，保留 `RequirementGateCode` 类型扩展并让 `requirementBodyBlocker` 恒返回 `null`（force 通道与审计字段可留存）。
- **风险（返回型改造漏点）**：`applyStatusChange` 5 处 `return false` 若漏改一处，TypeScript 会在 `RequirementGateCode | null` 上报错 → 以 `npm run build` 兜底，禁止用 `as any` 绕过。
- **风险（done 门文案回归）**：`:536` 仍必须返回 `'invalid_status'`，否则 `T027.1` 与命令层文案会变 → 步骤 1 中显式保留。
- **风险（claim 插入点错位）**：门若插在 `:491` 之前会拦掉幂等重认领 → A2c 的 `changed:false` 断言兜底。
- **风险（force 无审计）**：只放行不落 `flow.json.log` 会破坏裁定① → A2b 断言末条 `action`。
