# op-005：国际化 CLI 命令输出（11 个命令文件的 console.log/error 替换）

- **阶段**：v4.4-stage-01
- **前置**：op-001（i18n 字符串源文件）, op-002（i18n 运行时引擎）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

逐个命令文件封装国际化输出：将 `console.log()`、`console.error()`、`console.warn()` 中的硬编码中文字符串替换为 `t('key', lang)` 或 `t('key', lang, vars)` 调用。涉及 11 个命令文件 + `src/core/init.ts` 的 console 输出。确保输出语言由 `getCliLang()` 动态决定。

## 通用实施模式

### 每个命令文件的操作模式

```
1. 文件顶部新增 import: import { t, getCliLang } from '../core/i18n.js';
2. 在 action handler 入口获取语言: const lang = getCliLang(process.cwd());
3. 将 console.log('中文...') 替换为 console.log(t('key', lang))
4. 将 console.error('中文...') 替换为 console.error(t('key', lang))
5. 将 console.warn('中文...') 替换为 console.warn(t('key', lang))
6. 将 console.log(`包含${变量}的中文...`) 替换为 console.log(t('keyTmpl', lang, { var: 变量 }))
7. 纯变量输出（如 console.log(summary())）不替换——仅替换硬编码中文字符串
8. Commander 的 .description() 字符串暂不替换（plan.md 要求仅替换 console 输出）
```

### 动态字符串模板替换模式

```typescript
// 原:
console.log(`✓ 已推进: ${stage} → ${to}`);
// 替换为:
console.log(t('flow.advance.okTmpl', lang, { stage, to }));
// 对应的 i18n entry:
//   zh: '✓ 已推进: {stage} → {to}'
//   en: '✓ Advanced: {stage} → {to}'
```
