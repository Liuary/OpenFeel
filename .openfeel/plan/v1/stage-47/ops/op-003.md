### 1. `src/core/init.ts:178-206` `configExisted` 分支（BUG-002 语义修复）

  - `:180` `const configExisted = existsSync(configPath);`

- **改后**（`configExisted` 分支**整段替换**，`else` 分支保持不变）：
  ```ts
  const configPath = resolve(projectPath, '.openfeel', 'config.yaml');
  const configExisted = existsSync(configPath);
  if (configExisted) {
    // BUG-002 语义修复（stage-47）：已存在的用户配置不再覆盖（保留用户 defaults）。
  ```

### 4. `src/core/flow-manager.ts:1576-1580` `buildCascadeConfig` 画像层（BUG-003）

- **现状**：
  ```ts
  const profile = readProfile();
  if (profile.preferences?.auto_advance) {
    profileDefaults['auto_advance'] = profile.preferences.auto_advance;
  }
  ```
  （`readProfile()` 缺文件/解析失败回退 `DEFAULT_PROFILE`（`auto_advance='disabled'`）→ 未验「文件存在」与「显式声明」→ 来源误落 `profile.yaml`）
- **改后**（仅当**文件真实存在**且**原始 YAML 显式含** `preferences.auto_advance`）：
  ```ts
  // 最低优先级：全局画像 ~/.config/preferences.auto_advance（P2 兜底）
  // BUG-003（stage-47）：仅当画像文件存在且原始 YAML **显式声明**该键时兜底；否则落 builtin。
  const profilePath = getGlobalProfilePath();
  if (existsSync(profilePath)) {
    try {
      const raw = parseYaml(readFileSync(profilePath, 'utf-8')) as Record<string, unknown> | null;
      const explicit = (raw?.preferences as Record<string, unknown> | undefined)?.auto_advance;
      if (explicit === 'enabled' || explicit === 'disabled') {
        profileDefaults['auto_advance'] = explicit;
      }
    } catch {
      // 解析失败 → 不填 → 落 builtin（更贴近「无有效画像」）
    }
  }
  ```
  - **新增 import**：`import { getGlobalProfilePath } from './global-paths.js';`（`flow-manager.ts` 当前**未**导入 `global-paths`；`global-paths` 不依赖 `flow-manager`，无循环）。`readProfile` 不再使用 → 若变成未使用 import 则移除（`rg` 复核）。
  - `readProfile()` 自身降级行为不变（供其他调用方）。
