# op-003：知识库自动去重

- **阶段**：v4-stage-04
- **前置**：无（批次内独立 op）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

新增知识库去重模块：归档前检索现有条目，相似度 > 80% 时执行更新而非新增，避免 kb/ 中产生大量重复条目。

## 实施步骤

- [x] 步骤1：`read` 本方案文件完整内容
- [x] 步骤2：阅读 `.opencode/agents/archiver.md` 当前内容，理解归档流程
- [x] 步骤3：新建 `src/utils/kb-dedup.ts`：
  - 实现 `findSimilarEntries(target: string, category: string): KbEntry[]` — 读取对应 kb/ 分类文件，逐条目计算 Jaccard 相似度
  - 实现 `shouldUpdate(similarity: number): boolean` — 相似度 > 0.8 返回 true
  - 实现 `mergeEntry(existing: KbEntry, newContent: string): KbEntry` — 合并新旧内容
  - Jaccard 相似度算法：基于词袋（token 级）计算 `|A∩B| / |A∪B|`，阈值 0.8
- [x] 步骤4：在 `archiver.md` 的归档流程中注入去重步骤：
  - 「步骤2：检索现有条目」— 归档前必须先调用去重逻辑
  - 「步骤3：判断」— 相似度 > 80% → 更新现有条目；否则 → 新增条目
  - 更新条目时注明更新日期和变更摘要
- [x] 步骤5：确保去重逻辑考虑 `[+]` / `[-]` 标记不参与相似度计算（避免禁用标记变化影响匹配）
