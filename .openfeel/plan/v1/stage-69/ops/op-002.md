## T3 — 正文适配清单（统一替换规则 R1~R6 + 逐文件特殊点）

### 统一替换规则

- **R1 工具名 PascalCase**：`` `read`→`Read` ``、`` `glob`→`Glob` ``、`` `grep`→`Grep` ``、`` `edit`→`Edit` ``、`` `write`→`Write` ``、`` `todowrite`→`TodoWrite` ``、`` `bash`→`Bash` ``。**仅工具名语境**，勿误伤 `readProfile`/`withFileLock`/`README`/`git add` 等。
- **R2 `task` 口径（subagent 版）**：`task`/`task(explore)` **一律清除**，改为「由**主会话**经 **Task** 工具调度 `Explore`」；子任务跨界时用 `[HANDOFF: openfeel-x]` 标记由主会话解析。`subagent_type: openfeel-utility` → 「主会话经 Task 调度 `openfeel-utility`」。
- **R3 `skill()` 语法**：`skill("openfeel-x")` → 「加载 `openfeel-x` skill」（**Skill 工具语法**待 Q2/首 op 实测微调；本 op 用能力叙述，不用具体调用语法）。
- **R4 `question` 工具**：`question`/`通过 question 工具向 Feel 反馈` → 「**返回主会话，由其向用户确认**」。
- **R5 「Feel」→「主会话」**：subagent 模板中「Feel」首现 → 「主会话（Feel 角色）」，其后 → 「主会话」；**明确 subagent 不互调**（各 agent 仅经主会话被调度）。
- **R6 重启口径**：`重启 opencode` → 「Claude Code：agents/skills 热更新；首次创建 `~/.claude/{agents,skills}` 需重启/`/reload-skills`；`CLAUDE.md` 下次会话生效」。
- **`external_directory` 说明（8 文件「模型选择」节统一追加）**：「Claude Code 无 `external_directory` 对等概念；跨目录读写受会话权限与 tools 白名单共同约束，不模拟。」
