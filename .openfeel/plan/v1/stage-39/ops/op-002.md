# op-002：存量读取兼容收尾（P5 覆盖点验证 + update_state 旧格式降级补漏）

- **阶段**：v1.1.0-stage-39
- **前置**：无（hard 无；与 op-001 **并行**，op-001 对 op-002 为 **soft** 依赖——见 REV-1202 裁定）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标

确认 P5 读取兼容（`normalizeAgentName`）已闭环**不重复实现**，仅补强测试断言；补 `update_state` 旧格式加载降级的缺失项——新增旧 key 识别辅助函数 `isLegacyFrameworkKey`（供 op-001 migrate 拆分重键复用），并确认 `loadUpdateState` 对旧格式（混合 key）加载不丢记录。

> 参见 kb/patterns.md #P5 读取兼容模式（normalizeAgentName 已实现，本 op 仅验证）；kb/patterns.md #全局/项目双 state 路由模式（旧 key 识别是拆分的判据）；kb/troubleshooting.md #update_state.json 降级风险排查（schema 不匹配 → null → 全量覆盖的坑位）。

## 关键设计决策

1. **P5 已闭环，本 op 只补测不重写**：`normalizeAgentName`（flow-manager.ts L2814）+ `LEGACY_AGENT_NAME_MAP`（L2798，8 旧名）已接入 flow/view/metrics 全部展示 agent 名路径，`mapPhaseToAgent`（L1504）已返回新名。本 op 仅：全库 grep 确认无旧 assignee 硬编码残留 + 补强接入点断言。**不新增 `mapPhaseToAgent` 之外的任何读取兼容逻辑。**

2. **`isLegacyFrameworkKey` 落在 `update-state.ts`（非 migrate.ts）**：旧 key 识别属 update_state 领域职责，放 update-state.ts 供 op-001 的 `splitUpdateState` 复用（soft 依赖方向正确）。判据 = key 以 `.opencode/` 或 `.opencode\` 前缀（兼容 Windows 反斜杠）。

3. **旧格式降级不丢记录**：`UpdateStateSchema.files = z.record(z.string(), FileStateSchema)` 对 key **不校验值**（宽松兼容），旧 key（`.opencode/agents/planner.md`）不会触发 schema 校验失败 → 不会降级为 null → 不丢记录。本 op 补测试固化该行为（防未来收紧 schema 时回归）。

4. **REV-1202 依赖方向裁定**：op-002 为**验证性 + 小补漏** op，与 op-001 **并行**（无 hard 依赖）。op-001 的 `splitUpdateState` 依赖 `isLegacyFrameworkKey`（soft）：若 op-002 先行则该函数就绪；若并行则 op-001 先用等价内联判断，op-004 回归时统一 import。

## 实施步骤

### 步骤 1：`src/core/update-state.ts` 新增 `isLegacyFrameworkKey`（L36 常量区后）

在 `STATE_FILE` 常量（现 L40）之后追加：

```ts
/** 旧框架 key 前缀（旧项目 state 的 .opencode/... 相对路径条目） */
const LEGACY_STATE_PREFIX = '.opencode/';
const LEGACY_STATE_PREFIX_WIN = '.opencode\\';

/**
 * 检测项目 update_state 的 key 是否为「旧框架 key」（.opencode/... 相对路径）。
 * 供 stage-39 migrate 拆分重键使用（识别需移入全局 state 的框架条目）。
 * 项目资产 key（AGENTS.md / opencode.jsonc）不匹配本前缀。
 */
export function isLegacyFrameworkKey(key: string): boolean {
  return key.startsWith(LEGACY_STATE_PREFIX) || key.startsWith(LEGACY_STATE_PREFIX_WIN);
}
```
