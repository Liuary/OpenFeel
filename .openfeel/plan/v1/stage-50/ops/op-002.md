### T17（medium，**R1 已裁定：改为非 0 退出**）`lint i18n`/`lint kb` 发现问题仍 exit 0

- **文件:行号**：`src/commands/lint.ts:86-96`（i18n 汇总分支）、`:136-144`（kb 汇总分支）；命令注册 `.action()` 于 `:26`（i18n）、`:35`（kb）；对照 `src/commands/flow.ts:1085-1087`（health exit 1 范式）

- **改后**（**已裁定，直接实施，不再作为条件项**）：
  1. 两个函数**返回问题条数** `number`（`problems.length` / `stale.length`），打印逻辑不变（保持人读输出）。
  2. `.action()` 内：`const problems = runLintI18n(lang); if (problems > 0) { process.exitCode = 1; }`（kb 同理）。
