- **前置**: 无

## 目标

## 实施步骤

- [ ] **步骤1**: config.ts — 新增 `CONFIG_TEMPLATE_EN` 英文模板常量；修改 `writeDefaultConfig` 签名增加 `lang` 参数
- [ ] **步骤2**: templates.ts — 新增 `getDevCoreTemplate(lang)` 和 `getCurrentTemplate(lang)` 函数，中英双语版本按 lang 返回
- [ ] **步骤3**: init.ts — 将 `selectedLang` 传递给 `writeDefaultConfig`、改用双语模板函数；kb/index.md 和 status.md 内联字符串改为三元选择
- [ ] **步骤4**: 构建+测试全量通过
- [ ] **步骤5**: git commit
