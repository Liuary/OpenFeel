# op-007：README.md 双语化

- **阶段**：v4.3-stage-03
- **前置**：无
- **负责 Agent**：Executor
- **最多重试**：2

## 目标

在现有中文 README.md 基础上，为安装、快速开始、命令参考三节增加英文内容，实现在单文件中双语展示。

## 实施方案

在当前 README.md 中，为以下三节增加英文段落：每个中文段落后紧跟英文翻译，使用 `---` 分隔线区分中英文块，或在每节内采用中英对照格式。

### 推荐格式

```markdown
## 安装 / Installation

### 中文

npm install -g openfeel

要求：Node >= 20

### English

npm install -g openfeel

Requires: Node >= 20
```

以此类推覆盖三节。

## 实施步骤

- [ ] 1. 读取 `README.md` 完整内容（128 行），了解当前结构

- [ ] 2. 翻译并插入英文内容，覆盖以下三节：
  - **安装节**（第 15-20 行）：增加 English 子节
  - **快速开始节**（第 23-41 行）：增加 English 子节
  - **命令参考节**（第 42-55 行）：增加 English 子节（表格翻译）
  - 可选：核心概念节也添加简要英文描述

- [ ] 3. 保持文件整体结构不变，在现有中文内容后追加英文，不要删除中文原文

- [ ] 4. 翻译要点：
  - CLI 命令不翻译（如 `openfeel init`）
  - 文件路径不翻译（如 `.openfeel/`）
  - Agent 名称使用术语表英文称谓（如 Orchestrator 而非 Feel）
  - 技术术语保持英文（如 CLI、TypeScript、Agent）
