### 第 1 步 — 追加 T4.4 边界用例（`describe('边界（T4.4）')`）

在既有段之后追加（复用 makeData/makeStage/makeLog/makeArchiveFile 助手）：

1. **空 log + 空 reviews**：`makeData({ stages: { 'v1.7.0-stage-01': makeStage('done') } })`（reviews/log 空）→ `splitForArchive(data,'v1.7.0')`：archive 三段 = 1 阶段 / `[]` / `[]`；remainder 三段 = `{}` / `[]` / `[]`；不抛错。
2. **空 stages（版本不存在）**：`makeData({ log: [makeLog('v1.1.7-stage-73')] })` → `splitForArchive(data,'v1.1.7')`：archive.stages = `{}` 但 archive.log 长度 1；archive.counts = `{stages:0,reviews:0,log:1}`。
3. **单阶段版本**：stages 仅 `'v1.1.7-stage-77'` 一个 → archive.counts.stages = 1；`listArchivableCandidates` 该版本 `allDone === true`。
4. **版本不存在（完全无命中）**：`splitForArchive(data,'v9.9.9')` → archive 三段空全（counts 全 0），**不抛错**；remainder 三段 = 全量（键集 / 长度 / 内容断言：stages 键集深等原键集、reviews/log `toEqual` 原数组）。
