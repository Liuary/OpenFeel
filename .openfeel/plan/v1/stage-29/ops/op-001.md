# op-001：OpenCode 模板数据源化与构建管线

- **阶段**：v1.0.0-stage-29-01
- **前置**：无
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

将项目自身 `.opencode/` 完整配置纳入 `src/core/templates-data/opencode/` 模板体系，在 `build.js` 中新增 opencode 模板注入步骤，在 `template-loader.ts` 中新增 opencode 导出函数。

> **知识库参考**：kb/architecture.md #多语言模板数据管线（三步管线）、kb/patterns.md #构建脚本多语言循环生成模式、kb/patterns.md #新增 Agent 全链路更新清单模式

## 实施步骤

### 一、创建模板数据源目录

- [ ] **1.1** 创建 `src/core/templates-data/opencode/agents/{zh-CN,en}/` 目录，从 `.opencode/agents/*.md`（9 个）复制到对应语言子目录。文件名一致：`feel.md`, `planner.md`, `schemer.md`, `executor.md`, `reviewer.md`, `feel-tester.md`, `vision.md`, `archiver.md`, `utility.md`
  - 注意：当前 `.opencode/agents/` 9 个文件均为中文内容。英文版内容从 `src/core/templates-data/agents/en/` 中复用对应 Agent 的英文定义（同名文件），因为 `.opencode/agents/` 下的当前 Agent 定义本身来自 templates-data/agents/ 构建管线。若 `templates-data/agents/en/{agent}.md` 内容与 `.opencode/agents/{agent}.md`（中文）不同，以 `templates-data/agents/en/` 为准作为英文版；中文版直接复用 `.opencode/agents/` 当前文件内容。

- [ ] **1.2** 创建 `src/core/templates-data/opencode/skills/{14个子目录}/SKILL.md`，从 `.opencode/skills/{name}/SKILL.md` 逐目录复制。子目录名列表：`agent-model-check`, `bug-acceptance`, `check-kb`, `get-bugs`, `get-stage-status`, `health`, `model-check`, `model-config`, `recover`, `roadmap`, `search-kb`, `sync-status`, `update-stage-status`, `wizard`

- [ ] **1.3** 创建 `src/core/templates-data/opencode/instructions/{zh-CN,en}.md`：
  - `zh-CN.md`：来源于 `.opencode/instructions/core.md`（当前为中文内容）
  - `en.md`：来源于 `src/core/templates-data/core-instructions/en.md`（英文版 core instructions，作为 opencode 英文指令的基础）
  - 注意：两个文件的内容可能不完全对称——en.md 与 zh-CN.md 的节结构应保持一致，但实际内容语言各自的源文件即可。

- [ ] **1.4** 创建根级模板文件（`src/core/templates-data/opencode/` 下）：
  - **`opencode.jsonc`**：从项目根 `opencode.jsonc` 复制并改造为模板——`skills` 字段替换为占位锚点 `"SKILLS_PLACEHOLDER"`（build.js 扫描 skills 目录后自动注入完整列表），`name` 加入 `{项目名称}` 占位符（如 `"name": "{项目名称}"` 或等效的语义）。当前根级 `opencode.jsonc` 第 3 行 `"default_agent": "feel"` 保持不变。
  - **`ADAPTER.zh-CN.md`**：中文版适配器说明。当前 `.opencode/` 下无 `ADAPTER.md`（仅在 `kilo/ADAPTER.md` 和 `claude/ADAPTER.md` 中存在）。**困难点**：openCode 平台的适配器说明需从零编写。备选方案：A) 参考 `kilo/ADAPTER.md` 的结构编写 opencode 版本、B) 直接写一个简短的中文说明 "这是 OpenCode 平台适配器，包含 9 个 Agent 定义和 14 个 Skill。"——推荐 B（简洁），因为 opencode 适配器不同于 kilo/claude 的格式转换适配器，它是一个模板部署说明。
  - **`ADAPTER.en.md`**：英文版适配器说明（REV-006 双语要求），内容与 zh-CN 对称。
  - **`.gitignore`**：来源于 `.opencode/.gitignore`（当前内容：`node_modules`, `package.json`, `package-lock.json`, `bun.lock`, `.gitignore`）——注意部署到用户项目时 `.gitignore` 应保持这些忽略规则。
  - ⚠️ **不含 `package.json`**（REV-001）：不在模板数据源中创建 `package.json`。

### 二、更新构建脚本

- [ ] **2.1** 在 `build.js` 中新增常量声明（约在第 36 行 SKILLS_DIR 之后）：
  ```js
  const TEMPLATE_OPENCODE_DIR = resolve(TEMPLATES_DATA_DIR, 'opencode');
  const TEMPLATE_OPENCODE_AGENTS_DIR = resolve(TEMPLATE_OPENCODE_DIR, 'agents');
  const TEMPLATE_OPENCODE_SKILLS_DIR = resolve(TEMPLATE_OPENCODE_DIR, 'skills');
  const TEMPLATE_OPENCODE_INSTRUCTIONS_DIR = resolve(TEMPLATE_OPENCODE_DIR, 'instructions');
  ```

- [ ] **2.2** 新增 `generateOpencodeAgentTemplates()` 函数（插入在步骤 4 `generateSkillDefinitions()` 之后）：
  - 遍历 `templates-data/opencode/agents/{zh-CN,en}/` 下所有 .md 文件
  - 读取内容 → `escapeForTemplateString()` 转义
  - 生成 `OPENCODE_AGENT_TEMPLATES: Record<string, Record<string, string>>` 结构（与现有 AGENT_TEMPLATES 同构）
  - 注入 `template-loader.ts` 的 `AUTO-GENERATED-BEGIN: OPENCODE_AGENT_TEMPLATES` 锚点
  - 含连字符的键名（如 `'feel-tester'`）需加引号——复用现有 `formattedKey` 逻辑

- [ ] **2.3** 新增 `generateOpencodeSkillTemplates()` 函数：
  - 遍历 `src/core/templates-data/opencode/skills/` 子目录，读取各 `SKILL.md`
  - 生成 `OPENCODE_SKILL_DEFINITIONS: Record<string, string>` 结构
  - 注入 `template-loader.ts` 的 `AUTO-GENERATED-BEGIN: OPENCODE_SKILL_DEFINITIONS` 锚点
  - 注意：Skill 不含连字符的目录名直接用做键，`agent-model-check` 等含连字符的需加引号

- [ ] **2.4** 新增 `generateOpencodeConfigTemplates()` 函数：
  - 读取 `instructions/{zh-CN,en}.md` → 注入 `OPENCODE_CONFIG_TEMPLATES` 下 `[lang].instructions`
  - 读取 `opencode.jsonc` 模板 → 扫描 `templates-data/opencode/skills/` 目录获取 14 个 skill 名，替换模板中的 `"SKILLS_PLACEHOLDER"` 为实际 skills 列表（生成 `"skill-name": ".opencode/skills/skill-name"` 格式的 JSON 对象），然后再注入模板常量
  - 读取 `ADAPTER.{lang}.md` → 注入 `[lang].adapter`
  - 读取 `.gitignore` → 注入 `gitignore`（不区分语言）
  - 注入 `template-loader.ts` 的 `AUTO-GENERATED-BEGIN: OPENCODE_CONFIG_TEMPLATES` 锚点

- [ ] **2.5** 新增 `validateOpencodeTemplates()` 校验函数：
  - 从 `template-loader.ts` 提取 `OPENCODE_AGENT_TEMPLATES` 锚点内容
  - 逐语言、逐 Agent 与 `templates-data/opencode/agents/{lang}/{agent}.md` 源文件比对
  - 对 skills 和 config 同样做一一致性校验
  - 不一致时输出具体差异并 `exit(1)`

- [ ] **2.6** 在 `build.js` 主流程中串联调用——在现有的 `// ── 主流程 ──` 注释区域添加步骤：
  - 步骤 5：`generateOpencodeAgentTemplates()`
  - 步骤 6：`generateOpencodeSkillTemplates()`
  - 步骤 7：`generateOpencodeConfigTemplates()`
  - 在校验区添加：`validateOpencodeTemplates()`

### 三、更新 template-loader.ts

- [ ] **3.1** 在 `template-loader.ts` 末尾（`loadTemplate()` 导出之后、`AGENTS_MD_TEMPLATE` 兼容导出之前）新增三类 AUTO-GENERATED 锚点段：
  ```
  // AUTO-GENERATED-BEGIN: OPENCODE_AGENT_TEMPLATES
  // AUTO-GENERATED-END: OPENCODE_AGENT_TEMPLATES
  
  // AUTO-GENERATED-BEGIN: OPENCODE_SKILL_DEFINITIONS
  // AUTO-GENERATED-END: OPENCODE_SKILL_DEFINITIONS
  
  // AUTO-GENERATED-BEGIN: OPENCODE_CONFIG_TEMPLATES
  // AUTO-GENERATED-END: OPENCODE_CONFIG_TEMPLATES
  ```

- [ ] **3.2** 新增导出函数（在锚点段之后，遵循现有导出函数模式）：
  ```typescript
  /** 加载 opencode Agent 模板（用于部署 .opencode/agents/） */
  export function loadOpencodeAgentTemplate(lang: string, agentId: string): string {
    const langData = OPENCODE_AGENT_TEMPLATES[lang] ?? OPENCODE_AGENT_TEMPLATES['zh-CN'];
    const content = langData?.[agentId];
    if (content === undefined) {
      throw new Error(`Opencode agent template not found: agentId=${agentId} (lang=${lang})`);
    }
    return content;
  }
  
  /** 加载 opencode Skill 模板（不分语言） */
  export function loadOpencodeSkillTemplate(skillName: string): string {
    const content = OPENCODE_SKILL_DEFINITIONS[skillName];
    if (content === undefined) {
      throw new Error(`Opencode skill template not found: ${skillName}`);
    }
    return content;
  }
  
  /** 加载 opencode 配置类模板 */
  export function loadOpencodeConfigTemplate(lang: string, configName: string): string {
    const langData = OPENCODE_CONFIG_TEMPLATES[lang] ?? OPENCODE_CONFIG_TEMPLATES['zh-CN'];
    const content = langData?.[configName];
    if (content === undefined) {
      throw new Error(`Opencode config template not found: ${configName} (lang=${lang})`);
    }
    return content;
  }
  
  /** 列出所有 opencode Agent ID（用于部署时遍历） */
  export function listOpencodeAgentIds(lang: string): string[] {
    const langData = OPENCODE_AGENT_TEMPLATES[lang] ?? OPENCODE_AGENT_TEMPLATES['zh-CN'];
    return Object.keys(langData);
  }
  ```
