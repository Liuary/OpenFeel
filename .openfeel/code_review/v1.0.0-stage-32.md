## 心得建议

1. **三态逻辑是 hash 比对的核心**：将"全文相同→skip"作为快速路径（避免 hash 计算），将"hash 一致→安全覆盖"作为增量判定，将"hash 不一致→冲突"作为保护机制。三层递进清晰无歧义。

2. **AGENTS.md 的双重身份**：AGENTS.md 既是受管文件又是语言敏感文件，其独立的语言同步逻辑与新冲突检测存在架构张力。未来可考虑将语言判断作为冲突检测的前置层。

3. **降级策略的可见性**：降级路径（state 损坏/null）在设计文档中有明确声明，但在代码中建议添加注释说明保护缺口，降低后续维护者的理解成本。

4. **模板传播的自动化**：`openfeel update` 自动将模板变更传播到 `.opencode/agents/feel.md` 和 `template-loader.ts`，确保了源模板→构建产物→部署文件的三级一致性。
