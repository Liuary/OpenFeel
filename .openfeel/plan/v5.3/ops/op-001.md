# op-001: Checkpoint 快照 + 组合终止条件

## 目标

为 v5.3-stage-01 实现两项流水线增强：

1. **Checkpoint 自动快照**：每次 phase 推进时自动保存 flow.json 快照到 `.openfeel/checkpoints/`，支持回溯恢复。
2. **组合终止条件**：phase 转换支持 `|` 运算符组合条件（任一源 phase 满足即可推进），替代单条件硬切换，支撑多 Agent 并行场景。

## 实施步骤

- [x] 步骤1：在 `src/core/flow-manager.ts` 的 `advanceStagePhase` 中，phase 推进成功后调用新增 `saveCheckpoint(stageId, phase)`（创建 `.openfeel/checkpoints/` 目录、命名 `{stageId}-{timestamp}-{phase}.json`、保存完整快照、保留最近 20 个自动清理最旧、try-catch 包裹失败不阻塞）
- [x] 步骤2：在 `FlowManager` 中新增 `listCheckpoints(stageId?)` 与 `restoreCheckpoint(filename)` 方法（含文件名安全校验）
- [x] 步骤3：在 `src/commands/flow.ts` 新增 `flow checkpoint list [stage]` 与 `flow checkpoint restore <file> --force` 两个子命令
- [x] 步骤4：在 `src/core/i18n-data/zh-CN.ts` 与 `en.ts` 的 flow 域新增 checkpoint 相关中英双语键（含 help 域帮助键）
- [x] 步骤5：在 `src/core/pipeline-schema.ts` 扩展组合条件支持：新增 `TRANSITION_OR_SEPARATOR`、`parseTransitionKey`、`transitionKeyMatches` 等工具（transitions key 允许 `|` 组合）
- [x] 步骤6：在 `src/core/flow-manager.ts` 新增 `getValidTargets(fromPhase)`（组合 key 任一匹配即可达），并改造 `hasTransition` / `getAvailablePhases` / `canAdvance` 使用之（无 `|` 的 key 保持单条件原行为）
- [x] 步骤7：在 `getDefaultPipelineConfig` 的 transitions 表中增加组合条件示例（`test_passed|review_passed → archiving`，多 Agent 并行任一完成即推进）
