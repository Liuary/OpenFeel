## 经验与建议

- **「默认值来源」与「有效值级联」分离**：`resolveConfigDefaults` 只读 config defaults 作**骨架初值**，不做 effective 合并（不构成第二套 resolver）；`status.md > config > profile > builtin` 级联口径零触碰。
- **键归一到单一来源、归一先于校验**：`normalizeConfigKey` 置于 core，命令层入口归一后走原有白名单/枚举校验——归一等价与校验强度正交，新增受管键无需改命令层。
- **新建继承（默认）与存量同步（显式 `--sync-stages`）分工**：避免把批量同步设为默认行为而覆盖用户有意设置的阶段级覆盖。
- **测试零副作用**：`--exec-mode bogus` 断言「阶段目录不存在」、`--sync-stages` 同值 no-op 断言「文件逐字节 + mtime/MD5 不变」。
