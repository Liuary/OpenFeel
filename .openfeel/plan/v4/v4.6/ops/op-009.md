修复 Reviewer 在 v4.6-stage-01 审查中发现的 3 条 REV：

## 实施步骤

在 `.openfeel/kb/index.md` 的 `### architecture.md` 摘要表中追加一行：

```markdown

```

### 步骤 2：修复 REV-002 — 调整 permission 顺序

调整以下 3 个文件的 frontmatter permission 顺序为 `bash → read → glob → grep`（bash 在前）：
- `src/core/templates-data/agents/zh-CN/vision.md`
- `src/core/templates-data/agents/en/vision.md`
- `.opencode/agents/vision.md`

### 步骤 3：修复 REV-003 — 补充 bash 权限用途说明

在以上 3 个文件的「能力边界」节中补充 bash 权限用途说明：
- 中文："拥有 bash 权限但仅限于只读命令（如 cat、head、grep），不执行任何文件写入或修改操作。"
- 英文："Has bash permission but limited to read-only commands (e.g., cat, head, grep); does not perform any file write or modification operations."
