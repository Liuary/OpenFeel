# v1.6.2 发布说明

- **来源阶段**：v1.6.2-stage-135
- **需求**：REQ-069

## 变更摘要

- **默认配置不预设模型（REQ-069）**：`writeDefaultConfig` 的 ZH/EN 模板删除硬编码 `models:` 段（原 `default` = deepseek-v4-pro、`roles.fast` = deepseek-flash、`roles.cross_model` = glm-5.1），替换为「不预设模型」注释。
- **保留只读兼容**：`ModelsSchema`、`ConfigSchema.models`（可选）、`readConfig` 的 `models: null` 预处理零改动——存量含 `models` 的项目照旧解析。
- **规则登记**：`.openfeel/dev/dev_core.md` 与新建项目的 `DEV_CORE` 模板（ZH/EN）新增「不预设模型」条。
- **文档更正**：`README.zh-CN.md` / `README.en.md` / `docs/commands.md` / `docs/GETTING_STARTED.md` 的旧「默认模型配置 / init 自动检测模型」改为「不预设模型（由平台/会话选择）」。

## 语义

OpenFeel **不指定 Agent 模型**：Agent 使用打开平台（DSH / Claude 等）时用户所选的模型；`config.yaml` 的 `models` 段仅 Awareness 记录、**不生效**，可选、可自行添加。

## 升级与验证

- **升级**：`npm i -g openfeel@v1.6.2`（本地开发：`npm run build` 后用 `node bin/openfeel.js`）
- **验证**：`npx tsc --noEmit` → `npm test` → `npm run build` → `cd dsh && node test/verify.js` → `node bin/openfeel.js lint i18n`

## 发布流程

- 发布走 CI 自动发布（唯一标准路径）：push 到 master 且 `package.json` 版本与 npm 已发版本不同 → CI 的 publish job 自动 `npm publish`（`openfeel` + `openfeel-dsh`）；不需要手动 `npm publish`，也不必打 tag。
- 版本号 lockstep：`package.json` / `dsh/package.json` = 1.6.2、`openfeel.requiresCli` = `>=1.6.2`。
