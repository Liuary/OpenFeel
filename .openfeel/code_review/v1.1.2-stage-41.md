## 心得建议

1. **自描述命令的数据源必须与校验同源**：`flow phases` 只保证「转移表」同源，未覆盖「phase 合法性判定」（仍硬编码 `PIPELINE_PHASES`），自定义 `pipeline.yaml` 下即产生展示与校验不一致（→ `cli/BUG-001`）。
2. **破坏性命令的校验要有清单**：ops / current / deps 三维完整性校验 + `--force` 越权留痕 + `--dry-run` 复用同一只读校验 + 更重动作（`--purge`）双重确认 + 审计快照，缺一即留下失真路径。
3. **新增 i18n 键须校验引用**：`lint i18n` 只查 zh/en 对称性、不查键是否被调用，`common.stageDirConflictTmpl` 因此成为死键（→ `cli/BUG-002`）。
4. **事务顺序**：状态落盘（flow.json）与外部副作用（删目录）应保证「落盘成功后执行副作用」，否则失败时产生中间态（REV-009）。
