## 经验与建议

- **单一取表点 + mode 必传**：转移表选择收敛到 `getValidTargets`，`mode` 用**无默认值**从编译期封死「漏传落回某默认表」——是「单一信源 + 防漏传」的最简结构。
- **级联函数的 stage 形参决定其可复用性**：凡「任意阶段域」需求，先确认级联入口有 stage 形参；无则先扩形参，而非在被调用处另起一套解析（REV-74-001 的根因）。
- **默认值翻转的单一权威**：`DEFAULT_CONFIG` 与 `ConfigDefaultsSchema` 逐键默认**必须同键值**，否则「缺失键回退 schema 默认」与「级联 builtin」两条路径分叉（REV-74-011）。
- **模式标记分层承载、状态文件不冗余**：项目默认（config.yaml）→ 阶段覆盖（status.md）两层承载，`flow.json` **不写** mode/transitions（防陈旧第二信源）。
