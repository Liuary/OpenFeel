# op-001：修复 flow.json 日志上下文缺失 + 公域日志降噪

- **前置**：无
- **负责 Agent**：Executor

- **参考**：kb/patterns.md #REV blocking 标记模式、kb/patterns.md #CLI 原子管理模式、kb/troubleshooting.md #Agent prompt CLI 命令引用应预验证

## 目标

修复 flow.json 日志 `agent` 字段恒为 `'flow-manager'` 的问题，使其记录实际触发者；同步将公域日志的 `advance_stage_phase` 事件从"每次推进逐条写入"改为"阶段完成时批量聚合为一条里程碑记录"。

## 实施步骤

### A. flow-manager.ts：advanceStagePhase 新增 triggeredBy 参数

- [ ] A1. 打开 `src/core/flow-manager.ts`
- [ ] A2. 找到 `advanceStagePhase(stageName: string, phase: PipelinePhase)` 方法签名（约第704行）
- [ ] A3. 新增第三个参数 `triggeredBy?: string`，默认值 `'flow-manager'`：
  ```typescript
  advanceStagePhase(stageName: string, phase: PipelinePhase, triggeredBy?: string): void {
  ```
- [ ] A4. 在方法开头添加局部变量 `const actualTrigger = triggeredBy ?? 'flow-manager';`
- [ ] A5. 将 `appendLog` 调用中的 `agent: 'flow-manager'` 改为 `agent: actualTrigger`
- [ ] A6. **取消**直接调用 `this.publicLogger.logPhaseChange(...)`（不再每次推进都写公域日志）
  - 注释说明：`// REV-003: advance_stage_phase 改为 endStage 时批量聚合，取消逐条写入`

### B. flow-manager.ts：endStage 新增里程碑日志

- [ ] B1. 在 `endStage(stageId: string)` 方法中（约第545行），在记录耗时之后，新增调用：
  ```typescript
  // 公域日志：阶段完成时汇总写入一条里程碑记录
  this.publicLogger.logMilestone(`阶段 ${stageId} 完成`, {
    action: 'stage_completed',
    stageId,
    durationMs: stage.stats?.duration_ms ?? 0,
    finalPhase: stage.phase,
  });
  ```
- [ ] B2. 在 `endStage` 调用时实际写入公域日志

### C. public-logger.ts：新增 logMilestone 方法

- [ ] C1. 打开 `src/core/public-logger.ts`
- [ ] C2. 在 `LogEventDetail` 接口之后，新增 `MilestoneEvent` 接口：
  ```typescript
  /** 里程碑事件 */
  export interface MilestoneEvent {
    action: string;
    stageId?: string;
    durationMs?: number;
    finalPhase?: string;
    [key: string]: unknown;
  }
  ```
- [ ] C3. 在类公开方法区域（`logTestEvent` 之后），新增 `logMilestone` 方法：
  ```typescript
  /**
   * 记录里程碑事件（阶段完成、测试通过、归档完成等）
   * 此类重要事件逐条记录，不参与批量聚合
   */
  logMilestone(title: string, event: MilestoneEvent): void {
    this.writeLog('里程碑', { ...event, action: event.action } as LogEventDetail);
  }
  ```
- [ ] C4. 在 `getShortDesc` 函数中，新增 `stage_completed` case，返回 `阶段完成` 描述
