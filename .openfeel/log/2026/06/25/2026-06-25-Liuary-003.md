# stage-03 审查：REV-001 (high) advancePhase 日志 from 字段错误

- **时间**：2026-06-25 22:30
- **操作者**：ReviewWorker
- **阶段**：stage-03：工作区管理 + FlowManager

## 问题详情

src/core/flow-manager.ts 的 advancePhase() 方法中，先执行 `this.data.pipeline.phase = to;` 更新阶段，再构造日志条目时读取 `from: this.data.pipeline.phase`，此时 phase 已经是新值 `to`，导致日志中 `from` 与 `to` 始终相等。流水线的变更历史（"从哪个阶段推进到哪个阶段"）完全丢失。

## 影响范围

- `flow advance` 命令产生的日志条目中 `from` 字段始终等于 `to`，审计追踪功能失效
- `openfeel flow log` 命令无法正确展示阶段推进的变更路径
- 所有调用 advancePhase 的内部代码产生的日志记录同样受影响

## 修复建议

在更新 `this.data.pipeline.phase = to;` 之前保存旧值：

```typescript
const fromPhase = this.data.pipeline.phase;
this.data.pipeline.phase = to;
// ... checkpoint 更新 ...
this.appendLog({
  detail: { opId, from: fromPhase, to },
});
```

修复仅需在 `advancePhase` 方法开头增加一行变量声明，并修改 `appendLog` 调用中的 `from` 引用。
