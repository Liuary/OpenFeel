# REQ-069：默认配置不预设模型：删除模板 models 段，改为平台/会话选择

> 本文件为需求正文（人读副本，由 openfeel req 机械铺骨架）。**机读权威恒为 `.openfeel/flow.json` 的 `requirements` 条目**；两者不一致时以 flow.json 为准。下方状态为创建时快照，不追写实时状态。

## 状态

draft（创建时快照；以 flow.json 为准）

## 摘要

OpenFeel 默认配置模板目前硬编码了 models（default=deepseek-v4-pro、fast=deepseek-flash、cross_model=zhipu/glm-5.1），等于替用户预设 Agent 模型。但实际模型应由平台/会话决定（DSH 选的模型、Claude 的 sonnet 等），OpenFeel 不应特化；且 models 段本身不生效（仅 Awareness）。默认模板应改为「不预设模型」。

## 目标与验收

### 目标

默认配置模板不再指定任何模型（provider/model_name），Agent 使用打开 DSH/Claude 等平台时用户选择的模型；保留 models 段为可选 Awareness（读兼容），文档与规则写明「不预设模型」。

### 验收

- A69.1 `src/core/config.ts` 的默认配置模板（zh-CN 与 en 两处 `writeDefaultConfig` 文本）删除 `models:` 段，改为注释：「不预设模型：Agent 使用平台/会话所选模型（DSH/Claude 等）；如需 Awareness 记录可自行添加 models 段（不生效）」。
- A69.2 `openfeel init` 在临时项目生成的 `.openfeel/config.yaml` 不含 `model_name:`/`provider:` 默认值（夹具断言）。
- A69.3 旧项目 config 含 models 仍可解析（`readConfig` 不报错），models 保持可选、无默认值。
- A69.4 相关测试同步：删除/改写断言默认模板含 `deepseek-v4-pro`/`deepseek-flash`/`glm-5.1` 的用例；新增「默认模板无 models」断言；全量 `npm test` 0 failed。
- A69.5 规则登记：`.openfeel/dev/dev_core.md` 新增 `## [+] 不预设模型 (2026-11-25)`；`src/core/templates.ts` 的 `DEV_CORE_TEMPLATE_ZH/EN` 增加同义条（新项目自带）。
- A69.6 文档与版本：`docs/`（GETTING_STARTED/config 相关）、`README.zh-CN.md`/`README.en.md`、`docs/commands.md` 的 config 说明改为「不预设模型」；`CHANGELOG` 顶部 `## [1.6.2]`；root/dsh 版本 1.6.2（requiresCli >=1.6.2）；`openfeel --version` = 1.6.2。
