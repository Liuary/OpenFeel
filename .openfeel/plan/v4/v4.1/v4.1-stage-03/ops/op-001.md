# op-001：PipelineSchema 重构 — 全局 phase 迁移到阶段内部
- **阶段**：v4.1-stage-03
- **前置**：无（本阶段首个操作）
- **负责 Agent**：Executor
- **最多重试**：3

## 目标

将 `PipelinePhase` 枚举从全局 `PipelineMeta.phase` 字段移到 `StageData` 内部，新增 `MetaPhase`（`active/paused/done`）降级替代全局 phase。

## KB 参考

- 参见 kb/patterns.md #Phase Zod enum 硬化 — 新 MetaPhase 沿用 Zod enum 硬化模式
- 参见 kb/architecture.md #Feel 调度 + CLI 推进模型 — 新架构据此调整全局宏观状态语义

## 实施步骤

- [ ] 1. `read` 本方案文件完整内容（必做）
- [ ] 2. 打开 `src/core/pipeline-schema.ts`，在现有 `PIPELINE_PHASES` 定义之后新增 `META_PHASES` 常量：
  ```typescript
  /** 流水线全局宏观状态 */
  export const META_PHASES = ['active', 'paused', 'done'] as const;
  export const MetaPhaseSchema = z.enum(META_PHASES);
  export type MetaPhase = z.infer<typeof MetaPhaseSchema>;
  ```
- [ ] 3. 在 `StageData` 接口中新增 `phase: PipelinePhase` 字段（位于 `name` 之后、`status` 之前）：
  ```typescript
  export interface StageData {
    name: string;
    phase: PipelinePhase;  // 阶段当前流水线阶段
    status: string;
    deps: string[];
    ops: Record<string, Op>;
    stats?: StageStats;
  }
  ```
- [ ] 4. 在 `FlowData` 接口中，将 `pipeline` 的 `phase` 类型从 `PipelinePhase` 改为 `MetaPhase`：
  ```typescript
  pipeline: { phase: MetaPhase; current: { stage: string; op: string }; retry: number };
  ```
- [ ] 5. 在文件末尾追加 `/** 阶段级流水线阶段（从 PipelineMeta 移到 StageData 内） */` 注释，明确迁移意图
- [ ] 6. 运行 `npx tsc --noEmit` 验证类型系统无编译错误（预期大量 breakage，但 schema 自身应无错）
