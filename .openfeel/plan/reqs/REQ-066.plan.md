## 目标

- **目标**：把派发台账从「只记开始」补成闭环（finish 记录产物/耗时/失败），并实现可量化的遵守率报告，让「主会话只调度」从口头指标变成可观测数据。
- **现状证据**：`dsh/lib/adapters/dispatch-ledger.js` 只有 `appendDispatch`（`:194`）/`readDispatches`（`:131`）/`dispatchSummary`（`:277`）/`pruneDispatches`（`:229`），行 schema 无 `closing` 字段（`normalizeRecord` `:80-97`）；`dsh/lib/tools/index.js` 的 `feel_dispatch`（`:1946`，`action` 枚举 `:1951` = `['record','list']`）**没有 finish**；`feel_status.dispatch` 只有 `{required,total,sincePhase,missingRoles,records}`（`dispatch-ledger.js:277-293`），`missingRoles` 判据偏粗（有 record 即算）；`main_write_ratio`/`subagent_per_req`/`sync_gap`/`violation_rate` 全仓**零实现**（REQ-066 摘要）。
- **出口决定（REV-P03）**：A66.3 的「`openfeel verify adherence --json`（或 `feel_verify action=adherence`）」**选择后者**——`feel_verify` 已有工具（`dsh/lib/tools/index.js:1646`，`action` 枚举 `:1650`），加一个 action **不改工具数**（`dsh/test/contract.js` 计数保持），也**不新增 CLI JSON 出口**（阶段计划 §1.2 写死 50 成功/51 注册，`release` 与 `verify adherence` 均不进表）。
- **边界**：台账仍是**提示级观测**（用户裁定 ②：不做硬拦）；`.openfeel/dev/dispatch.jsonl` 仍在 `PROTECTED_OPENFEEL_PATHS`（`dsh/lib/guard.js:674`）里，只能经工具写；24h/200 行清理语义不变；**零外部依赖**（`dsh/package.json` 现无 `dependencies` 段）。

- **A66.2**：`feel_status.dispatch` 含 **`open[]`**（未完成派发：`closing` 缺失或 `status!=='done'`）与 **`closedRatio`**（`done` 数 / `total`，`total===0` → `null`）；**`missingRoles` 只包含没有 `closing.status==='done'` 记录的角色**（同一角色既有 `done` 又有 `failed` 记录时按「有 done 即不算 missing」）；既有 `required/total/sincePhase/records` 键保留（只增不改）。

## 风险

- **观测变门禁**：把 `adherence` 低值接进门禁会违反用户裁定 ②（只做台账 + 强提示）。规避——`feel_verify action=adherence` 与 `feel_status.adherence` 只读展示，不产生 deny；`dispatch.required` 仍恒 `true`。
- **原地补写破坏并发语义**：台账无文件锁（`dispatch-ledger.js:16-19` 已声明）。规避——沿用「整文件重写 + temp+rename」（`writeDispatches` `:159`），`finish` 走同一写函数，不新增第二通道。
- **`dispatchId` 失配**：finish 传入不存在的 id 若静默成功，闭环证据会失真。规避——返回 `{ok:false, code:'not_found'}` 且零写盘，`verify.js` 加负例。
- **`missingRoles` 口径回退**：仍按「有 record 即算」会让 A66.2 名存实亡。规避——`verify.js` 构造「有 record 无 closing」的行，断言该角色仍在 `missingRoles`；构造「closing.status='done'」的行，断言消失。
- **指标口径任意**：四个比率若无定义就会变成数字游戏。规避——每键带 `definition` 字符串，写进 `dsh/ADAPTER.md`；`verify.js` 断言 `definition` 非空且含分子/分母。
- **工具计数锁**：`dsh/test/contract.js:126-128` 与 `dsh/test/verify.js:232-234` 钉死工具数——`finish`/`adherence` **都不新增工具**，两处计数保持 15。
