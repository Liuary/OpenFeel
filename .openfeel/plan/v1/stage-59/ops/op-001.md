## 一、变更目标

修复 CI run #52（commit `cacbefb`）`Env guard (after test — must be unchanged)` **误报**，使 `build-and-test` 两 matrix job 转绿、`publish` job 不再被 skip，为 1.1.2 发布扫清障碍。**仅改 `.github/workflows/ci.yml` 单文件**，零实现语义变更。

**根因（已在真实 Linux 决定性复现，本方案据此设计）**：stage-58 令「运行日志默认开启」后，`bin/openfeel.js` 每次运行写 `~/.openfeel/cli/logs/*.log` + `~/.openfeel/locks/`（`installRuntimeLog()` → `runCli()` 首行 `runtimeLog('cli start')` → `mkdirSync` + `withFileLock` + `appendFileSync`）。而守卫窗口（`Env snapshot` → `Env guard`）内包含**两条非测试 bin 调用** `Version consistency guard`（`node bin/openfeel.js --version`）与 `lint i18n` → 干净 runner 上 `~/.openfeel` 由 `ABSENT` 变为「存在」→ diff 非空 → **误报**。**非测试污染**（只跑 `npm test` 零写盘，已实测）。

四项改动（M1~M6）：
1. **M1/M2/M3**：三处 bin 调用步骤注入 `env: OPENFEEL_LOG: '0'`（消除窗口内副作用）；
2. **M4**：`Env snapshot (before test)` 下移到 `lint i18n` 之后、`Test` 之前（防御性收紧窗口）；
3. **M5/M6**：守卫快照**三态化加固**（`ABSENT` / `EXISTS-EMPTY` / sha256 清单），两处逻辑逐字一致。

### 三.1 完整脚本内容（照此创建文件）

```bash
#!/usr/bin/env bash
# stage-59 WSL/Linux 守卫演练（S1/S2/S3）
#
# 三态判定逻辑逐字等价于 ci.yml M5/M6；快照命名 / 标记格式与 ci.yml 完全一致：
#   - 每路径分文件：$SNAP_DIR/snap_before_$key、$SNAP_DIR/snap_after_$key
#   - 标记为裸 ABSENT / EXISTS-EMPTY（无 key 后缀）；非空写 sha256 清单（printf '%s\n'）
# 期望：S1=PASS(空 diff) / S2=PASS(空 diff) / S3=FAIL(非空 diff，复现 CI #52)
set -u

REPO="/mnt/c/Users/Liuary/Dev/Mine/AI/OpenFeel"   # ← 按实际路径调整
cd "$REPO" || { echo "REPO 不存在: $REPO"; exit 2; }
export REAL_HOME="$HOME"
export SNAP_DIR="$(mktemp -d)"

# 四路径（与 ci.yml 逐字一致；config.yaml 用绝对路径便于隔离）
PATHS=("$HOME/.openfeel" "$HOME/.config/opencode" "$HOME/.config/openfeel" "$REPO/.openfeel/config.yaml")

# —— 与 ci.yml `Env snapshot (before test)`（M5）逐字等价的快照函数 ——
snapshot_before() {
  for d in "${PATHS[@]}"; do
    key=$(echo "$d" | tr '/.' '__')
    if [ -e "$d" ]; then
      manifest=$(find "$d" -type f -print0 2>/dev/null | sort -z | xargs -0 sha256sum 2>/dev/null | sort)
      if [ -n "$manifest" ]; then printf '%s\n' "$manifest" > "$SNAP_DIR/snap_before_$key"; else echo "EXISTS-EMPTY" > "$SNAP_DIR/snap_before_$key"; fi
    else
      echo "ABSENT" > "$SNAP_DIR/snap_before_$key"
    fi
  done
}

# —— 与 ci.yml `Env guard`（M6）逐字等价的守卫函数；返回 0=PASS / 1=FAIL ——
guard_after() {
  fail=0
  for d in "${PATHS[@]}"; do
    key=$(echo "$d" | tr '/.' '__') ; f="$SNAP_DIR/snap_after_$key"
    if [ -e "$d" ]; then
      manifest=$(find "$d" -type f -print0 2>/dev/null | sort -z | xargs -0 sha256sum 2>/dev/null | sort)
      if [ -n "$manifest" ]; then printf '%s\n' "$manifest" > "$f"; else echo "EXISTS-EMPTY" > "$f"; fi
    else
      echo "ABSENT" > "$f"
    fi
    if ! diff -u "$SNAP_DIR/snap_before_$key" "$f" >/dev/null; then
      echo "::error::环境被测试改动：$d"; diff -u "$SNAP_DIR/snap_before_$key" "$f" || true; fail=1
    fi
  done
  return $fail
}

# —— 干净隔离 HOME（双设 HOME/USERPROFILE + XDG，防漏写真实 HOME）——
clean_home() {
  export HOME="$(mktemp -d)"
  export USERPROFILE="$HOME"
  export XDG_CONFIG_HOME="$HOME/.config"
  PATHS=("$HOME/.openfeel" "$HOME/.config/opencode" "$HOME/.config/openfeel" "$REPO/.openfeel/config.yaml")
}

run_scenario() {
  local name="$1"; local fn="$2"
  clean_home
  rm -rf "$SNAP_DIR"; SNAP_DIR="$(mktemp -d)"
  "$fn"
  if guard_after; then
    echo "[$name] PASS (diff 空)"
  else
    echo "[$name] FAIL (diff 非空)  ← S3 出现此为预期；S1/S2 出现则为缺陷"
  fi
  export HOME="$REAL_HOME"   # 每个场景后复原真实 HOME
}

# S1（修复后）：--version / lint i18n 先跑（均 OPENFEEL_LOG=0），快照贴 Test 前，然后全量 npm test

  node bin/openfeel.js lint i18n

run_scenario S1 s1
run_scenario S2 s2
```
