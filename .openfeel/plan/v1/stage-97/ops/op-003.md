## 方案期裁定（T3/T4/T5 定稿）

- **D-97-03-01（关联阶段单点）**：`listLinkedStages(data, requirementId): {id, phase}[]` 放 `aggregate.ts` 并导出；`computeRequirementAggregate` 内部**改用**该函数（一次 filter），禁止命令层第二份 `requirement_id` 过滤。`stageIds` 与计数从同一结果派生；done 判定仍委托 `allLinkedStagesDone`。
- **D-97-03-02（`req list` 键序）**：`requirements[]` 元素 = `RequirementData` 原键序 + `linkedStages` + `progress`（末位）；`progress = {done: agg.doneCount, total: agg.stageCount}`；零关联 `linkedStages:[]` + `progress:{done:0,total:0}`。顶层仍为 `schemaVersion,requirements`。
- **D-97-03-03（`flow archive` legacy 键序）**：gate-rejected 顶层 = `schemaVersion,error,version,notDone,blockingOpen,eligible,unfinishedStages,blockingReviews,errorKind`；`error` 恒 string；既有前 5 键相对序不变，`errorKind` 恒末位。成功（dry-run 与非 dry-run）= `schemaVersion,version,stages,reviews,log,dryRun,eligible,unfinishedStages,blockingReviews`。
- **D-97-03-04（判据明细形态）**：`unfinishedStages[] = {id, phase}`（`phase` 取 `data.stages[id]?.phase ?? null`）；`blockingReviews[] = {id, title, priority}`；合格时两数组为 `[]` 且 `eligible:true`；不合格时 `eligible:false` + 明细 + exit 1。
- **D-97-03-05（`archive <stage>` 形态）**：`{schemaVersion,stage,archivePath,opsCount,reviewsCount,knowledgeExtracts}`；`stage` 为用户输入原值；`archivePath` 与人类输出同源（`join(process.cwd(),'.openfeel','log','archive-${stage}.md')`，绝对路径）；`null` → `ARCHIVE_FAILED`/refusal/1；异常 JSON → `INTERNAL_ERROR`/internal/3，人类保持 exit 1 文案。
- **D-97-03-06（非 dry-run 成功的写盘边界）**：成功 JSON 仅在 `mgr.save()` 成功后输出（既有顺序不变）；`--dry-run` 零写盘（不写归档文件、不 save、不 appendLog），新增字段不引入任何写盘。

### 1. `src/core/req/aggregate.ts`：`listLinkedStages` 单点

- [ ] 新增导出接口与函数（放在 `computeRequirementAggregate` 之前）：
  ```ts
  /** 需求关联阶段（data.stages 键序；phase 供聚合与适配器共用） */
  export interface LinkedStage { id: string; phase: PipelinePhase; }

  /**
   * 需求关联阶段单点过滤（唯一实现；命令层与聚合共用）。
   * requirement_id 缺省 / 空串 / null 一律视为未关联（与既有 `(s.requirement_id ?? null) === requirementId` 等价）。
   */
  export function listLinkedStages(data: FlowData, requirementId: string): LinkedStage[] {
    return Object.entries(data.stages ?? {})
      .filter(([, s]) => (s.requirement_id ?? null) === requirementId)
      .map(([id, s]) => ({ id, phase: s.phase }));
  }
  ```
- [ ] `computeRequirementAggregate` 改为：
  ```ts
  const linked = listLinkedStages(data, requirementId);
  const stageIds = linked.map((l) => l.id);
  const stageCount = stageIds.length;
  let doneCount = 0; let anyStarted = false;
  for (const l of linked) {
    if (l.phase === 'done') { doneCount += 1; }
    if (l.phase !== 'plan_pending') { anyStarted = true; }
  }
  ```
  `aggregate` 的 done 分支仍调用 `allLinkedStagesDone(data, requirementId)`（唯一原语，禁第二份 done 表达式）。返回结构 `{stageIds,stageCount,doneCount,aggregate}` **零变化**（既有测试 `toEqual` 全绿）。
