## 目标

在 `build.js` 建立 **Claude 内容注入管线**：新增 2 生成函数 + 2 校验函数（含必填字段与阴性门禁）+ 1 校验包装，扩展单源不一致断言（**键集 == 9，含 feel，不再 −1**），主流程 **6→8 步**；并在 `src/core/template-loader.ts` 新增 2 个 AUTO-GENERATED **锚点桩**（供注入，禁手改）。

> **为何本 op 也改 `template-loader.ts`**：`replaceBetweenAnchors` 在锚点缺失时 `process.exit(1)`，故 build 注入目标锚点必须**先存在**，本 op 的 `npm run build` 才能绿。op-004 仅新增**空对象锚点桩**；3 个 loader 导出函数归 op-005，loader 函数体手写在锚点段**之外**（不受 build 覆盖）。

```js
/**
 * 断言两组键值对象的键集一致（不比较内容）—— 用于 Claude（平台适配致内容不同）
 */
function assertKeySetsEqual(nameA, nameB, entriesA, entriesB) {
  const keysA = Object.keys(entriesA).sort();
  const keysB = Object.keys(entriesB).sort();
  if (JSON.stringify(keysA) !== JSON.stringify(keysB)) {
    return [`${nameA} 键集(${keysA.join(',')}) ≠ ${nameB} 键集(${keysB.join(',')})`];
  }
  return [];
}
```
