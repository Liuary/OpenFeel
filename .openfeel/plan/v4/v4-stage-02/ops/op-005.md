## 目标
在 Executor 的「前置校验」章节（由 op-004 创建）中追加 FlowManager 集成步骤，使 Executor 在执行前通过 CLI 命令或直接读取 `flow.json` 调用 `canAdvance` / `validate` 逻辑，确保 phase 流转合法。

## 背景
FlowManager（`src/core/flow-manager.ts`）提供了两个关键校验方法：
- `canAdvance(opId, to)`：检查从当前 phase 到目标 phase 的流转是否合法（基于 `pipeline.yaml` 中的 transitions 配置）
- `validate()`：检查 `flow.json` 的格式合法性（含 PipelinePhase 枚举校验、必填字段检查等），返回 `ValidationResult { valid, errors, warnings }`

Executor 在执行前需通过这两项校验，防止在非法 phase 下执行操作。
