## 风险与注意

- **版本 6 处遗漏风险**：`template-loader.ts` 生成段若忘记 build 重生成，则 `openfeel update` 部署的仍是旧版本声明——必须 `npm run build` 且确认生成段同步。
- **config.yaml 编码**：实测 UTF-8 无 BOM（stage-33/34 已确认），改动后保持编码，勿引入 BOM（否则 lint/解析报错）。
- **`/opfx:code`/`/opfx:test` 无对应 CLI 命令**：改写成 agent 名（openfeel-executor / openfeel-feel-tester），勿硬造 `openfeel code` / `openfeel test` 命令（D36-1 已定 code/test 改文字描述）。
- **`docs/commands.md` 过期**：本 op 不更新（M7 已定），仅在 README 加可选跳转提示；若 Feel 要求更新 commands.md，另立 op。
- **测试硬编码版本号**：优先动态读取 `getOpenfeelVersion()`，避免未来版本升级再改测试；若动态读取因模块依赖复杂不可行，回退为同步 `'1.1.0'` 并在完成说明记录。
- **版本发布**：仅 commit+push master 且 package.json version 变更才触发 CI npm publish，由 Feel 收尾统一提交，本 op 不 commit。
