- **阶段**：v4.4-stage-03
- **前置**：无（阶段内独立，但依赖 stage-01 已完成 i18n 基建 + 全局配置读写机制）

- **参考**：kb/patterns.md #双语 CLI 交互模式、kb/patterns.md #向后兼容可选配置字段模式、kb/patterns.md #CLI 原子管理模式、kb/patterns.md #CLI 国际化封装模式、kb/patterns.md #语言配置三级回退链

## 目标

新增 `openfeel config` 命令组，支持子命令 `get lang` / `set lang <zh-CN|en>` / `list projects`；在 `identity.ts` 中新增 `recordProjectLang()` 函数，供 `openfeel update` 完成后自动记录项目路径→语言映射到全局配置的 `projects` KV 表。

## 技术决策

> **i18n 域扩展**：现有 12 个功能域（common/flow/init/update/project/stage/plan/knowledge/archive/roadmap/view/instructions）需新增第 13 个域 `config`，在 `zh-CN.ts` 和 `en.ts` 中对称添加。参见 kb/patterns.md #CLI 国际化封装模式（键命名规范：`{domain}.{module}.{name}`）。
>
> **config 命令定位**：作为全局配置文件的 CLI 操作入口，遵循 kb/patterns.md #CLI 原子管理模式——不直接 `edit` 配置文件，统一通过 `openfeel config` 命令读写。

### B. 新增 `recordProjectLang()` 函数

- [ ] B1. 打开 `src/core/workspace/identity.ts`
- [ ] B2. 在文件末尾（`isFirstUse()` 函数之后）新增 `recordProjectLang()` 函数：
  ```typescript
  /**
   * 记录项目路径→语言映射到全局配置的 projects 表。
   * 由 openfeel update 完成后自动调用。
   * 若映射已存在且语言相同则跳过；语言不同则更新。
   * @param projectPath 项目绝对路径
   * @param lang 项目使用的语言
   */
  export function recordProjectLang(projectPath: string, lang: 'zh-CN' | 'en'): void {
    const config = getGlobalConfig();
    const existing = config.projects[projectPath];
    if (existing === lang) {
      // 映射已存在且语言一致，跳过写入
      return;
    }
    config.projects[projectPath] = lang;
    setGlobalConfig(config);
  }
  ```
- [ ] B3. 自检：`getGlobalConfig()` 和 `setGlobalConfig()` 已存在于本文件（由 stage-01 op-003 实现），无需新增导入。

- [ ] C4. 实现 `registerConfigCommand(program: Command)` 函数：

- [ ] C5. 添加 `get lang` 子命令：
  ```typescript
  const configCmd = program.command('config');
  
  configCmd
    .command('get lang')
    .description('显示全局默认语言')
    .action(() => {
      const lang = getCliLang(process.cwd());
      const config = getGlobalConfig();
      console.log(t('config.get.lang', lang, { lang: config.lang }));
    });
  ```
  > 说明：全局语言直接读 config.lang（非用 getCliLang 的三级回退），因为此命令的语义是"当前全局设置"，而非"当前项目使用的语言"。

- [ ] C6. 添加 `set lang <lang>` 子命令：
  ```typescript
  configCmd
    .command('set lang <lang>')
    .description('修改全局默认语言 (zh-CN 或 en)')
    .action((lang: string) => {
      const cliLang = getCliLang(process.cwd());
      if (lang !== 'zh-CN' && lang !== 'en') {
        console.error(t('config.set.invalidLang', cliLang, { val: lang }));
        process.exit(1);
      }
      const config = getGlobalConfig();
      config.lang = lang;
      setGlobalConfig(config);
      console.log(t('config.set.ok', cliLang, { lang }));
    });
  ```

- [ ] C7. 添加 `list projects` 子命令：
  ```typescript
  configCmd
    .command('list projects')
    .description('列出所有已记录的项目路径→语言映射')
    .action(() => {
      const lang = getCliLang(process.cwd());
      const config = getGlobalConfig();
      const entries = Object.entries(config.projects);
      console.log(t('config.list.title', lang));
      if (entries.length === 0) {
        console.log(t('config.list.empty', lang));
        return;
      }
      for (const [path, projLang] of entries) {
        console.log(t('config.list.item', lang, { path, lang: projLang }));
      }
    });
  ```
