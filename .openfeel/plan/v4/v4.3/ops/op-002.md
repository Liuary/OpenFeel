## Part A：英文 AGENTS.md 模板

### 翻译特殊要求

AGENTS.md 是项目级行为约束文件，翻译时需注意：

1. **行为准则语言切换**：
   - 中文版："你应当以中文思维思考问题…"
   - 英文版："You should think in English. At the start of a session, organize your analysis into concise information and output it in English."
2. **占位符保留**：`{项目名称}` 保持不变
3. **AGENTS.md 内部引用**：如引用 `AGENTS.md` 文件路径则保留原名
4. **中文开发注释**：涉及中文开发的条款需翻译为英文并保持语义

  - 逐段翻译，保持 markdown 结构和编号

  - 知识约束、操作规范、编码风格、注释规范各节完整翻译

## Part C：build.js 多语言 AGENTS_MD 注入

- [ ] C1. 修改 `build.js` 的 `generateAgentsMdTemplate()` 函数（当前约第 142 行）：
  - 当前：硬编码读取 `templates-data/agents-md/zh-CN.md`，生成 `{ 'zh-CN': ... }`
  - 改为：迭代 `templates-data/agents-md/` 下的所有 `.md` 文件，按文件名（不含扩展名）作为语言键构建 Record
  - 示例：`const TEMPLATE_AGENTS_MD_DIR = resolve(TEMPLATES_DATA_DIR, 'agents-md');`，读取所有 `*.md` → 按 `path.basename(f, '.md')` 取语言键
  - 使用 `readdirSync` 过滤 `.md` 文件，逐个读取内容并转义
  - 最终结构：`{ 'zh-CN': \`...\`, 'en': \`...\` }`

- [ ] C2. 同步修改 `validateAgentsMdTemplate()`（当前约第 312 行）适配多语言：
  - 当前：仅校验 `'zh-CN'` 键 → 单个源文件比对
  - 改为：遍历 `Record` 中所有语言键，对每个语言键：
    1. 从模板对象提取该语言的值
    2. 读取对应源文件 `templates-data/agents-md/{lang}.md`
    3. 比对内容一致性
  - 参见 REV-003：多语言适配需遍历 `Object.keys(templateRecord)`，逐语言执行 `compareTemplatePairs` 或逐对比对
  - 若某语言源文件不存在（如新增了 `'ja'` 键但无源文件），标记为错误

## Part D：build.js 多语言 core-instructions 注入

- [ ] D1. 修改 `build.js` 的 `generateTemplateFromCoreMd()` 函数（当前约第 94 行）：
  - 当前：硬编码读取 `core-instructions/zh-CN.md`，生成 `{ 'zh-CN': '<base64>' }`
  - 改为：迭代 `templates-data/core-instructions/` 下的所有 `.md` 文件，按文件名（不含扩展名）作为语言键
  - 每个文件：读取 → CRLF→LF 归一化 → Base64 编码 → 作为对应语言键的值
  - 示例结构：`{ 'zh-CN': '<b64>', 'en': '<b64>' }`
  - 注意：文件名可能为 `zh-CN.md`（含连字符），需要 `'zh-CN'` 引号语法
  - 注意：`TEMPLATE_CORE_MD_PATH` 常量需从单文件路径改为目录路径，函数内部遍历 .md 文件

- [ ] D2. 同步修改 `validateCoreInstruction()`（当前约第 272 行）适配多语言：
  - 当前：正则 `/ 'zh-CN':\s*'([^']+)' /` 仅匹配 `zh-CN` 键
  - 改为：从 section 中提取所有语言的 Base64 值，遍历每个语言键：
    1. 提取该语言的 Base64 字符串
    2. 解码 → CRLF→LF 归一化
    3. 读取对应源文件 `templates-data/core-instructions/{lang}.md` → 归一化
    4. 比对内容一致性
  - 参见 REV-003：`validateAgentsMdTemplate` 和 `validateCoreInstruction` 需从单语言硬编码改为遍历 `Object.keys`
  - 若某语言源文件不存在，标记为错误
