## 目标

① `plan stage add --workflow-mode <full|fast>`（值域 schema 派生、非法 exit 1 且不建阶段、缺省取 `config.yaml defaults.workflow_mode`）+ `StageSkeletonOverrides` 扩键 + 骨架 status.md 在「自动推进」行后增「**工作流模式**」行；② `stage set <id> --workflow-mode <v>`：字段缺失 → **插入**（裁定 H；锚点链：「自动推进」后 → 「执行模式」后 → 皆缺 = exit 1 不写盘），同值 no-op、非法值 exit 1 不写盘、`.bak` 仅在确认写入后生成；③ **新增单一插入写函数**（原子写 + 按阶段锁 + 结果返回；`FlowManager` 公共方法，供 op-003 `--sync-stages` 复用——**禁双实现**）；④ `flow.json stages.{id}.workflow_mode` 冗余字段在**写入点①②**同步（裁定 G：可选冗余、不参与级联；**仅在实际写入发生时写**，no-op 零写盘）。
