## 目标
将 `resolveTargetEncoding` 第⑤步（`win32 && !isTTY`）由「`chcp` 探测 → 代码页映射 GBK」改为**直接 `return 'utf8'`**，删除随之失效的 `chcp` 探测 / 代码页映射死代码，重写对应单测并新增回归断言（win32 非 TTY 无显式 → `utf8`），同步 `--help` i18n 帮助文案；`npm run build` 与门禁通过。

## 不可变约束（行为语义，禁止改动）
- ① `--json` 恒 UTF-8（最高优先，机器合同）；② 显式 `--encoding`；③ `OPENFEEL_ENCODING`；④ 非 win32 / TTY → `utf8`；⑤ **本次唯一变更点**。
- `utf8` 目标不包装、库侧 no-op、幂等安装、`--json` 旁路优先序、安装链路（`bin/openfeel.js`）**全部不变**。
- GBK 仅经 `--encoding gbk`（②）/ `OPENFEEL_ENCODING=gbk`（③）**显式**生效。
- 保留 5 步结构，**不合并** ④/⑤（最小 diff）。
