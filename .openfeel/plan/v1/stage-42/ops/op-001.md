## 目标（含反馈条目）

统一 `auto_advance` 级联口径为**四级有效链**：`status.md 覆盖 > 项目 config.yaml defaults > 全局 profile.yaml preferences（兜底） > 内置默认 disabled`；同时修正模板/文案中与实现不符的「优先使用全局画像」表述，并连带走连带修正陈旧注释。

**对应反馈**：`docs/phase-5/06-openfeel-tooling-feedback.md` 问题 #5（中）「`auto_advance` 配置优先级两处口径冲突」。
**对应决策**：版本级 P2（项目域优先、全局画像兜底）+ P2a（本阶段修的是**框架级「文档 vs 实现」不一致**）。

> 参见 kb/architecture.md #模板单源架构（改权威源 → `npm run build` 重生成，**禁手改生成段**）、kb/patterns.md #构建脚本多语言循环生成模式、#全局跨项目用户画像 YAML 配置模式、#i18n 键对称性校验模式。

## 关键设计决策

1. **级联层次（P2，写死）**：新增最低优先级层 `profileDefaults`；`effective = { ...profileDefaults, ...configDefaults, ...statusOverrides }`（后写覆盖前写）。**已显式声明 `auto_advance` 的项目实际值不变**（profile 仅兜底）。
2. **画像键范围**：profile 的 `preferences` 中与级联键重叠的**仅 `auto_advance`**（`user.lang/review_mode/communication/confirm_threshold` 不属于 config.yaml defaults 键集）。故 `profileDefaults` 只填 `auto_advance`；`preferences.auto_advance` 恒有值（`DEFAULT_PROFILE` 为 `disabled`），故 `effective.auto_advance` 恒存在。
3. **读取入口**：复用 `readProfile()`（`src/core/config.ts:181-206`，异常安全、缺失回填默认）。**循环依赖评估**：`config.ts` 导入 `node:fs`/`yaml`/`zod`/`global-paths`/`fs/*`/`workspace/identity`，**不导入 `flow-manager.ts`**（已实测），故 `flow-manager → config` 无环；实施后跑 `npx tsc --noEmit` 复核。
4. **文案修正走单源管线**：只改**权威源** `src/core/templates-data/opencode/agents/{zh-CN,en}/feel.md`，再 `npm run build` 重生成 `src/core/template-loader.ts` 的 4 处生成段（en 2 处、zh 2 处）。**禁止手改生成段**。
5. **陈旧注释修正（仅注释，不动值）**：`.openfeel/config.yaml:13`、`src/core/config.ts:314`(zh)/`:371`(en)。**注意环境漂移**（见「待裁定点」）：实测当前 `.openfeel/config.yaml` 三值为 `manual/disabled/false`，而现注释「部署模板默认 auto+enabled，仓库自身默认 manual+disabled」的**第一分句与权威模板不符**（`DEFAULT_CONFIG`/`CONFIG_TEMPLATE` 的默认值为 `manual/disabled/false`）。修正后注释**不得再声称任何具体基线**，只描述来源与可覆盖性。
6. **不得覆写本项目三值**：`execution_mode` / `auto_advance` / `test_enabled` 由环境基线决定，本 op 一律不改（含注释附近的值）。

### 改动 3：`src/core/flow-manager.ts` `buildCascadeConfig`（现 `:1550-1598`）接入 profile 层

- 现状（要点）：`configDefaults`/`statusOverrides`/`effective` 三张表；config.yaml 循环内 `configDefaults[key]=...; effective[key]=...`；status.md 匹配后 `statusOverrides[...]=...; effective[...]=...`；`return { configDefaults, statusOverrides, effective }`。
- 改后（结构）：
  ```ts
  /** 构建配置级联信息（优先级：profileDefaults < configDefaults < statusOverrides） */
  private buildCascadeConfig(): CascadeConfig {
    const profileDefaults: Record<string, string> = {};
    const configDefaults: Record<string, string> = {};
    const statusOverrides: Record<string, string> = {};

    // 最低优先级：全局画像 ~/.config/openfeel/profile.yaml 的 preferences.auto_advance（P2 兜底）
    const profile = readProfile();
    if (profile.preferences?.auto_advance) {
      profileDefaults['auto_advance'] = profile.preferences.auto_advance;
    }

    // 中优先级：项目 .openfeel/config.yaml 的 defaults 块（去掉原 effective[key] 赋值）
    const configPath = resolve(this.projectPath, '.openfeel', 'config.yaml');
    if (existsSync(configPath)) {
      try {
        const raw = readFileSync(configPath, 'utf-8');
        const config = parseYaml(raw) as Record<string, unknown>;
        if (config && typeof config === 'object' && config.defaults) {
          const defaults = config.defaults as Record<string, unknown>;
          for (const [key, value] of Object.entries(defaults)) {
            configDefaults[key] = String(value);
          }
        }
      } catch { /* 解析失败则用空值 */ }
    }

    // 最高优先级：当前 stage status.md（保持既有匹配逻辑，去掉原 effective[key] 赋值）
    if (this.data && this.data.pipeline.current.stage) {
      const stageId = this.data.pipeline.current.stage;
      const statusPath = this.findStatusPath(stageId);
      if (statusPath) {
        try {
          const content = readFileSync(statusPath, 'utf-8');
          const execMatch = content.match(/\*\*执行模式\*\*[：:]\s*(manual|auto)/);
          const autoMatch = content.match(/\*\*自动推进\*\*[：:]\s*(disabled|enabled)/);
          if (execMatch) { statusOverrides['execution_mode'] = execMatch[1]; }
          if (autoMatch) { statusOverrides['auto_advance'] = autoMatch[1]; }
        } catch { /* 读取失败则跳过 */ }
      }
    }

    // 级联合并（后写覆盖前写）
    const effective: Record<string, string> = { ...profileDefaults, ...configDefaults, ...statusOverrides };
    return { profileDefaults, configDefaults, statusOverrides, effective };
  }
  ```
- `verboseSummary`（`:1538` 调用处）无需改：其返回的 `cascade` 自动含 `profileDefaults`。
