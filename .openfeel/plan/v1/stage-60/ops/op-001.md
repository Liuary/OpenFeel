# op-001

- **阶段**：v1.1.2-stage-60
- **最多重试**：3

## 目标

给 CI 的 `publish` job 加并发控制，避免同一 push 触发的多个并行 workflow run 并发发布同一版本导致 npm registry 返回 `409 Cannot publish over previously staged version`（npm/cli#9889 竞态）。

## 涉及文件

- `.github/workflows/ci.yml`

## 关键改动点

- 在 `publish:` job 内、`if:` 之后、`env:` 之前新增：

  ```yaml
  concurrency:
    group: publish-${{ github.ref }}
    cancel-in-progress: false
  ```

- `concurrency.group` 使用 GitHub 表达式 `publish-${{ github.ref }}`（原样保留 `${{ }}`）。
- `cancel-in-progress: false`（排队串行，取消进行中的发布有风险）。
- 不改动其它 job / 步骤，不动 `build-and-test`，不动 `on:`。
