## 目标

版本 1.0.7 → 1.0.8 全链路同步：package.json、config.yaml（meta.version，方案 A = 框架版本）、config.ts 双语言模板常量、CHANGELOG、AGENTS.md 及 agents-md 版本声明，触发 CI npm publish（由 Feel 收尾统一提交）。

## ⚠️ 前置

1. **hard 依赖 op-002**：本 op 改 `AGENTS.md` + `agents-md/{zh-CN,en}.md` 的「版本声明」，与 op-002 共享文件，**必须待 op-002 落定后执行**（改动点不同，但避免并发覆盖）。
2. **config.yaml 编码**：实测为 UTF-8（无 BOM），非任务背景所述的 GBK。改前用 `Format-Hex` 或读字节确认首字节非 `EF BB BF`；改后**保留 UTF-8 无 BOM**，禁止用 GBK 写回。
3. **flow.json meta.version='1.0' 是内部格式**，本次**不改** flow.json。
4. 测试无硬编码版本：`test/` 下无 `1.0.0`/`1.0.7`/`1.0.8` 断言（实测 grep 无命中），改 config.ts 版本字面量不破坏测试。

## 实施步骤

### 改动 1：`package.json`

- `"version": "1.0.7"`（第 3 行）→ `"version": "1.0.8"`

### 改动 2：`.openfeel/config.yaml`

- `meta.version`（第 7 行）`  version: 1.0.0` → `  version: 1.0.8`（保留两个空格缩进与注释，仅改版本值）
- **编码要求**：改后确认仍为 UTF-8 无 BOM

### 改动 3：`src/core/config.ts` 双语言模板常量

> 计划/REV-003 方案 A：`meta.version` 语义 = OpenFeel 框架版本，须同步改 config.ts 硬编码模板，否则新项目 init 仍生成 1.0.0。

- `CONFIG_TEMPLATE_ZH` 中 `  version: 1.0.0`（约第 304 行）→ `  version: 1.0.8`
- `CONFIG_TEMPLATE_EN` 中 `  version: 1.0.0`（约第 361 行）→ `  version: 1.0.8`

> 注意：这是模板字符串内 `meta:` 块下的**字面量**（非 `${DEFAULT_CONFIG.xxx}` 插值），只改这两处 `version` 值；`defaults:` 块下的 `${DEFAULT_CONFIG.xxx}` 插值**不动**。

### 改动 4：`CHANGELOG.md` 新增 1.0.8 条目

在 `## [1.0.0] - 2026-08-07`（第 5 行）之前插入：

```markdown
## [1.0.8] - 2026-08-15

### Added
- 任务类型路由：AGENTS.md 新增「任务类型路由」节，非编码任务（调研/探索、选型讨论）成为一等公民，flow.json 不必为所有任务空转
- decisions.md 纳入框架标准：新增 `.openfeel/dev/decisions.md`（ADR 轻量格式，决策+理由+日期+状态），init 自动生成，core.md 会话自检纳入

### Changed
- Feel 日志纪律解耦：「必须记录的事件」改为「委托任意下游 Agent（含 general / explore / utility 等调研类）都须落公域日志」，删除「委托 Executor / 事务官」的排他性表述，明确不受任务类型豁免
- 轻量决策边界：Feel / Planner / AGENTS 三层统一定义——对话式选型（产出结论不产出 plan.md）由 Feel 直接处理，仅产出正式计划文档或达规模阈值才委托 Planner
- 版本号 1.0.7 → 1.0.8 全链路同步（package.json / config.yaml / config.ts / AGENTS 版本声明）
```

### 改动 5：`AGENTS.md`（根目录）版本声明

「版本管理」节末尾（第 122 行，原文 `当前项目处于 v0 开发阶段，正式版 v1 待功能完备后发布。`）改为：

```markdown
当前项目为 OpenFeel 正式版，当前版本 v1.0.8（见 package.json，W 级修订持续递增）。
```

> 该行前一句「Feel 启动新版本时默认使用四级版本递增（W+1），除非用户明确指定。」保持不动。

### 改动 6：模板源版本声明（agents-md zh/en，措辞与根目录分别适配）

- `src/core/templates-data/agents-md/zh-CN.md` 第 118 行原文 `当前项目处于 v0 开发阶段，正式版 v1 待功能完备后发布。` 改为：

```markdown
OpenFeel 框架已发布正式版 v1.0.x（当前 v1.0.8）。新项目经 openfeel init 部署本模板后，按自身需求设定起始版本号。
```

- `src/core/templates-data/agents-md/en.md` 第 118 行原文 `The project is currently in the v0 development stage; the official v1 will be released when features are complete.` 改为：

```markdown
The OpenFeel framework has released the official v1.0.x (currently v1.0.8). After deploying this template via openfeel init, new projects set their own starting version number as needed.
```

> **措辞区分**：根目录 AGENTS.md 描述「本仓库（OpenFeel 自身）当前版本 v1.0.8」；模板源 agents-md 描述「框架已发布 v1.0.x，新项目 init 后自定版本」——两者语义不同，勿互相复制。en 版为英文。
