## 心得建议

- **fast 快线的质量底线 = 计划审查不跳过**：需求变更把 `plan_review` 纳入 fast 链（reviewer 单轮必过），「快」不能牺牲审查——审查是框架硬性纪律，与「自动推进」无关。
- **模板批量改造用内容锚点，不用行号**：多 harness 多语言同步（37 份）时行号会因前序插入失效；「同语言跨 harness 逐字一致 + 按 harness 替换主语 + 零裸主语」是防漂移三律。
- **断言串以落文逐字为准**：markdown 粗体 `**` 会切断子串，方案层断言与责任 op 落文之间任何标记差异都致伪失败（0 命中）；先落文后取串、收口以「0 MISS」。
- **改模板源须穷举 build 全部注入点**：`templates-data/skills` 同时喂 `template-loader.ts` 与 `update.ts` 两份生成物，产出清单遗漏即破坏部署链。
